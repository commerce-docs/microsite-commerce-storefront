## Slot context

Each slot receives a context object (`ctx`) that provides:

- **`ctx.data`**: Current component data and state
- **`ctx.appendChild(element)`**: Method to add elements to the slot
- **`ctx.replaceWith(element)`**: Method to replace slot content
- **`ctx.onChange(callback)`**: Method to listen for data changes

## Best practices

1. **Element creation**: Always create DOM elements and append them using `ctx.appendChild()`
2. **CSS classes**: Use BEM naming convention for custom slot styles
3. **Event handling**: Add event listeners directly to created elements
4. **Data updates**: Use `ctx.onChange()` for dynamic content updates
5. **Performance**: Keep slot logic lightweight for better performance
