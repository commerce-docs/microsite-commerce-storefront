The default DROPIN_NAME dictionary includes the default English values for all labels and text common to the DROPIN_NAME drop-in component.

## Default keys and values

The dictionary file for DROPIN_NAME will be available at:
`@dropins/storefront-DROPIN_PACKAGE/i18n/en_US.json`

```json
{
  "DROPIN_PACKAGE": {
    "title": "DROPIN_NAME",
    "description": "Description for DROPIN_NAME component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-DROPIN_PACKAGE/i18n/en_US.json.d.ts?raw';
```
:::
