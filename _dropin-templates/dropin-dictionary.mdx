## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/DROPIN_KEY-dictionary.js"
export const DROPIN_VAR = CUSTOM_EXAMPLE;
```

Then import it in your initializer:

```javascript title="scripts/initializers/DROPIN_KEY.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from 'DROPIN_PACKAGE';
import { DROPIN_VAR } from '../config/dictionaries/DROPIN_KEY-dictionary.js';

const langDefinitions = {
  default: {
    ...DROPIN_VAR,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
