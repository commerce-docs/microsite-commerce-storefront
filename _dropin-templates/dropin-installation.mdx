## Step-by-step

Use the following steps to install the **DROPIN_NAME** component:

<Aside type="note">
These steps are specific for Edge Delivery Services projects, and may not necessarily be the same for other frameworks such as static HTML or React.
</Aside>

<Task>

### Install the packages

Install the required packages using npm:

```bash frame="none"
npm install @dropins/tools DROPIN_PACKAGE
```

<Aside type="tip">
All drop-in components require the `@dropins/tools` package. This package contains the libraries that drop-in components need to initialize and communicate, including `fetch-graphql`, `event-bus`, and `initializer` utilities.
</Aside>

</Task>

<Task>

### Map the packages

Add the drop-in to your `importmap` in the `head.html` file:

```json title="head.html"
<script nonce="aem" type="importmap">
{
  "imports": {
    "DROPIN_PACKAGE/": "/scripts/__dropins__/DROPIN_PACKAGE/",
    "@dropins/tools/": "/scripts/__dropins__/tools/"
  }
}
</script>
```

With the `importmap` defined, you can now import the required files from these packages into your block as described in the next step.

</Task>

<Task>

### Import the required files

Import the necessary components and utilities:

```js title="DROPIN_NAME.js"
// GraphQL Client
import * as mesh from '@dropins/tools/fetch-graphql.js';

// Component tools
import { initializers } from '@dropins/tools/initializer.js';

// Drop-in component provider
import { render as provider } from 'DROPIN_PACKAGE/render.js';

// Drop-in component API functions
import * as api from 'DROPIN_PACKAGE/api.js';

// Drop-in component containers
IMPORT_EXAMPLE
```

</Task>

<Task>

### Connect to the endpoint

Configure the GraphQL endpoint:

```js title="DROPIN_NAME.js"
// Set endpoint configuration
mesh.setEndpoint('https://<graphql-service-endpoint>/graphql');

// Set store code header
mesh.setFetchGraphQlHeader('store', '<default>');
```

<Aside type="note">
This setting is specific for GraphQL Mesh. Refer to the [Commerce GraphQL Service](https://developer.adobe.com/commerce/webapi/graphql/usage/headers/#request-headers) for direct connections.
</Aside>

</Task>

<Task>

### Register and load the drop-in

Mount the initializers after the page has loaded:

```js title="DROPIN_NAME.js"
// Register drop-in initializer
initializers.register(api.initialize, {});

// Mount initializers (must be called after all initializers are registered)
initializers.mountImmediately(initialize, { langDefinitions });
```

</Task>
