## Key Directories

### Blocks Directory

Contains both Content blocks (standard Edge Delivery) and Commerce blocks (drop-in integrations):

- **Content blocks**: Standard Edge Delivery components (cards, columns, header, footer, etc.)
- **Commerce blocks**: Drop-in integrations for e-commerce features (cart, checkout, product details, etc.)

Each block directory contains:
- `<block-name>.js` - JavaScript decorator and drop-in integration
- `<block-name>.css` - Block-specific styles

### Scripts Directory

Core JavaScript files that provide site functionality and commerce integrations:

- **`__dropins__/`** - Imported drop-in components (minified/optimized)
- **`initializers/`** - Drop-in configuration and initialization
  - `index.js` - Global initializers for all pages
  - Individual drop-in initializers (e.g., `cart.js`, `checkout.js`)
- **`aem.js`** - AEM site functions
- **`commerce.js`** - Commerce-specific functionality including template handling
- **`configs.js`** - Site configuration functions
- **`scripts.js`** - Core AEM functionality for loading blocks and lazy styles

### Styles Directory

CSS files for design tokens and global styles:

- `fonts.css` - Typography definitions
- `lazy-styles.css` - Deferred styles loaded after LCP
- `styles.css` - Global design tokens and base styles

### Tools Directory

Commerce-specific tooling:

- **`picker/`** - Commerce Picker for authoring
- **`sidekick/`** - Sidekick configuration

### Configuration Templates

Template files for site setup:

- `default-fstab.yaml` - Content source connection template
- `default-query.yaml` - Query index template
- `default-site.yaml` - Site configuration template
- `default-sitemap.yaml` - Sitemap template
- `demo-config.json` - Starter configuration for local development
