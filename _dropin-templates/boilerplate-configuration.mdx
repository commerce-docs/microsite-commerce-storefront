## Configuration Overview

The boilerplate uses multiple configuration files depending on your deployment stage:

- **`demo-config.json`** - Local development configuration
- **`.aem.live` config service** - Production configuration (site.yaml, sitemap.yaml, etc.)
- **`head.html`** - Import map and meta tags
- **Drop-in initializers** - Individual drop-in configuration in `scripts/initializers/`

## Head Configuration

The `head.html` file contains:

```html
<meta name="viewport" content="width=device-width, initial-scale=1"/>
<script type="module">
  // Import map for drop-ins
  import { setLibs } from './scripts/aem.js';
  setLibs('/libs');
</script>
<script type="importmap">
  {
    "imports": {
      "@dropins/tools/": "./scripts/__dropins__/tools/",
      // ... other drop-in mappings
    }
  }
</script>
<link rel="stylesheet" href="/styles/styles.css"/>
<link rel="icon" href="data:,">
```

**Key elements**:
- Import map for drop-in component resolution
- Global styles reference
- Viewport and responsive settings

## Demo Configuration (Local Development)

The `demo-config.json` file provides configuration for local development:

```json
{
  "commerce": {
    "storeCode": "main",
    "storeView": "default",
    "locale": "en_US",
    "currency": "USD"
  },
  "contentSource": {
    "type": "markup",
    "baseUrl": "https://main--aem-boilerplate-commerce--hlxsites.aem.page"
  }
}
```

## Production Configuration Templates

The boilerplate includes template configuration files:

### default-site.yaml

Site-level configuration template:

```yaml
# Site configuration
commerce:
  endpoint: https://your-commerce-instance.com/graphql
  storeCode: main
  storeView: default
  
# Feature flags
features:
  personalization: true
  recommendations: true
```

### default-fstab.yaml

Content source configuration:

```yaml
mountpoints:
  /: https://drive.google.com/drive/folders/YOUR_FOLDER_ID
```

### default-query.yaml

Content indexing configuration:

```yaml
indices:
  default:
    include:
      - /**
    exclude:
      - /drafts/**
```

### default-sitemap.yaml

Sitemap configuration for SEO:

```yaml
sitemaps:
  default:
    origin: https://main--aem-boilerplate-commerce--hlxsites.aem.live
    hreflang: true
```

## Drop-in Initializers

Configure individual drop-ins in `scripts/initializers/`:

### Example: cart.js

```javascript
import { initializers } from '@dropins/tools/initializer.js';

initializers.register('cart', async () => {
  // Cart drop-in initialization
  const { initialize } = await import('@dropins/storefront-cart/api.js');
  
  await initialize({
    // Configuration options
    models: {
      CartModel: {
        transformer: (data) => {
          // Custom data transformation
          return data;
        }
      }
    }
  });
});
```

## Environment-Specific Configuration

<Aside type="tip">
Use different configuration values for different environments:

- **Local**: `demo-config.json`
- **Preview**: Configure in AEM.page branch settings
- **Production**: Configure in AEM.live production settings
</Aside>

## Common Configuration Options

### Commerce Backend

- **Endpoint URL**: Your Adobe Commerce GraphQL endpoint
- **Store code**: Multi-store configuration
- **Store view**: Language/locale configuration
- **Authentication**: API keys and tokens (if required)

### Drop-in Features

- **Cart**: Guest cart, persistent cart, mini cart behavior
- **Checkout**: Payment methods, shipping methods, address validation
- **Product Discovery**: Facets, filters, sorting options
- **Personalization**: Target rules, audience segments

### Content Delivery

- **CDN configuration**: Edge Delivery Services CDN
- **CORS setup**: Cross-origin resource sharing for API calls
- **Cache headers**: Performance optimization
