## Quick example

The DROPIN_NAME drop-in is included in the <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="Commerce boilerplate" />. This example shows the basic pattern:

```js
// 1. Import initializer (handles all setup)
import '../../scripts/initializers/INITIALIZER_NAME.js';

// 2. Import the container you need
import CONTAINER_EXAMPLE from 'DROPIN_PACKAGE/containers/CONTAINER_EXAMPLE.js';

// 3. Import the provider
import { render as provider } from 'DROPIN_PACKAGE/render.js';

// 4. Render in your block
export default async function decorate(block) {
  await provider.render(CONTAINER_EXAMPLE, {
    // Configuration options - see Containers page
  })(block);
}
```
