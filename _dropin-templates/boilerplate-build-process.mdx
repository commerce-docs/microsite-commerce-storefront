## Overview

The AEM Commerce boilerplate uses Edge Delivery Services' build system, which automatically handles:

- **JavaScript bundling** - Modules and dependencies are automatically bundled
- **CSS optimization** - Stylesheets are minified and optimized
- **Asset optimization** - Images and fonts are automatically processed
- **Drop-in integration** - Drop-in components are pre-bundled in `scripts/__dropins__/`

## Build Phases

<Steps>

1. **Local Development**
   
   Run the local development server with:
   
   ```bash
   npm start
   ```
   
   The <Link href="https://www.npmjs.com/package/@adobe/aem-cli" text="AEM CLI" /> provides hot reloading and serves your content locally for testing.

2. **Content Authoring**
   
   Create and edit content using:
   - Document-based authoring (Google Docs, SharePoint, and more)
   - Universal Editor for visual editing
   - Commerce Picker for product/category selection

3. **Production Build**
   
   Edge Delivery Services automatically:
   - Bundles JavaScript modules
   - Optimizes CSS and removes unused styles
   - Compresses assets
   - Generates optimized HTML
   
   No manual build step required!

4. **Deployment**
   
   Push changes to your repository and Edge Delivery Services automatically deploys to:
   - `https://<branch>--<repo>--<owner>.aem.page` (preview)
   - `https://<branch>--<repo>--<owner>.aem.live` (production)

</Steps>

## Drop-in Components

Drop-in components in `scripts/__dropins__/` are pre-built and optimized packages that include:

- Minified JavaScript bundles
- CSS with design tokens
- Type definitions
- Container components

These are imported directly in your Commerce blocks without additional build steps.

## Performance Optimization

The boilerplate is optimized for Core Web Vitals:

- **Lazy loading** - Blocks and styles load on demand
- **Critical CSS** - Above-the-fold styles load first
- **Deferred JavaScript** - Non-critical scripts load after LCP
- **Image optimization** - Automatic WebP conversion and responsive images
- **Font optimization** - WOFF2 fonts with font-display: swap

## Configuration Files

### package.json

Defines dependencies and scripts:

```json
{
  "scripts": {
    "start": "aem up",
    "lint:js": "eslint .",
    "lint:css": "stylelint 'blocks/**/*.css' 'styles/*.css'"
  },
  "dependencies": {
    "@dropins/tools": "^TOOLS_VERSION",
    // ... drop-in packages
  }
}
```

### head.html

Includes essential resources:

- Drop-in import map
- Core AEM scripts
- Global styles
- Meta tags and icons

## Local Development Tips

<Aside type="tip">
Use the `aem up` command with these options:

- `--port 3000` - Custom port
- `--livereload false` - Disable live reload
- `--print-index` - Preview content index
</Aside>
