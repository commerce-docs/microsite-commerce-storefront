## Quote Management v1.3.0

**New features**
- **B2B company addresses**: Buyers can now select a company address book address, not just a personal customer address, when setting a quote's or quote template's shipping address — required once a company enables its address book, since the backend previously rejected customer addresses in that case ([#128](https://github.com/adobe-commerce/storefront-quote-management/pull/128)).

**Fixes**
- Fixed an ID-handling bug where an ID of `0`/`''` could be silently dropped, or a `null` ID sent to the backend instead of failing locally with a clear error ([#128](https://github.com/adobe-commerce/storefront-quote-management/pull/128)).
- Fixed the address display showing a literal `null` region label (for example "San Jose, null 95110") for company addresses without a region ([#128](https://github.com/adobe-commerce/storefront-quote-management/pull/128)).

## Quote Management v1.1.0

The Quote Management drop-in has been updated with the following changes:

- **Quote template expiration dates** - New `setQuoteTemplateExpirationDate` API enables managing expiration dates for quote templates, with a new modal component for setting dates through a user-friendly interface (<Link href={"https://github.com/adobe-commerce/storefront-quote-management/pull/78"} text={"#78"} />).
- **Catalog discount display** - Added `row_catalog_discount` field to display catalog discounts in quote item line items, providing better pricing transparency (<Link href={"https://github.com/adobe-commerce/storefront-quote-management/pull/80"} text={"#80"} />).
- **Dropdown selection fix** - Fixed dropdown selection behavior in ItemsQuotedTemplate for improved usability (<Link href={"https://github.com/adobe-commerce/storefront-quote-management/pull/81"} text={"#81"} />).

## Quote Management v1.0.0

**Initial release** of the Quote Management drop-in for B2B negotiable quote workflows. This drop-in enables comprehensive quote management:

**Quote Creation and Management**

- **Request quotes from cart** - B2B buyers can request negotiable quotes directly from their shopping cart, converting cart contents into a quote for negotiation (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/731"} text={"#731"} />).
- **Quote list management** - View and manage all active, submitted, and completed quotes with filtering and sorting capabilities (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/782"} text={"#782"} />).
- **Quote updates** - Handle quote updates and status changes throughout the negotiation lifecycle (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/901"} text={"#901"} />).

**Quote Templates**

- **Quote template list** - View and manage quote templates for recurring purchases, displaying template details and usage history (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/884"} text={"#884"} />).
- **Quote template details** - Detailed view of quote templates including product listings, pricing, and terms (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/892"} text={"#892"} />).
- **Create quotes from templates** - Generate new quotes from saved templates for streamlined repeat ordering (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1014"} text={"#1014"} />).

**Quote Checkout**

- **Quote-specific checkout flow** - Dedicated checkout containers for quote orders with quote summaries and special handling (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/890"} text={"#890"} />).
- **Quote ownership validation** - Checkout button is disabled for users who are not the quote owner, preventing unauthorized quote submission (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1014"} text={"#1014"} />).

**File Attachments**

- **File upload for quotes** - Attach supporting documents to quotes during creation and negotiation (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1002"} text={"#1002"} />).
- **File type restrictions** - File uploads are restricted to match Luma functionality, ensuring consistent file handling across platforms (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1002"} text={"#1002"} />).

**Address Management**

- **Save addresses during quote creation** - New addresses entered during quote creation are automatically saved to the customer's address book for future use (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/999"} text={"#999"} />).

**User Experience**

- **Dynamic quote minimum amount** - Quote interface displays dynamic minimum order amounts with enhanced user feedback when amounts aren't met (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/970"} text={"#970"} />).
- **Quotes menu navigation** - Fixed navigation issue where quotes menu incorrectly redirected to main account page (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/985"} text={"#985"} />).

**Testing**

- **Cypress E2E tests** - Comprehensive automated testing for quote management workflows (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1001"} text={"#1001"} />).

**Version Updates**

- **Beta to stable progression** - Updated through beta versions (alpha21, alpha22, beta1, beta2) to stable 1.0.0 release (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/906"} text={"#906"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/916"} text={"#916"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1009"} text={"#1009"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1013"} text={"#1013"} />).
