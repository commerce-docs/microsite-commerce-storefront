## Purchase Order v1.0.0

**Initial release** of the Purchase Order drop-in for B2B procurement workflows. This drop-in enables purchase order management and approval workflows:

**Core Features**

- **Purchase Order payment method** - New payment method for B2B checkout allowing customers to reference purchase orders during order placement (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/736"} text={"#736"} />).
- **Purchase Order details page** - Dedicated page displaying complete purchase order information including items, amounts, approval status, and history (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/826"} text={"#826"} />).
- **Approval workflow** - Complete approval workflow for purchase orders with status tracking and approval history (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/826"} text={"#826"} />).

**Permissions and Access**

- **Permission-based access control** - Purchase order features are only accessible to users with appropriate B2B permissions, with proper error handling for unauthorized access attempts (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/736"} text={"#736"} />).

**Company Context**

- **Company context handling** - Purchase orders automatically update when switching between companies, with proper context preservation and error handling (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/942"} text={"#942"} />).
- **Context change listeners** - Purchase order pages automatically respond to company context changes, refreshing data or redirecting as appropriate (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/966"} text={"#966"} />).

**Testing and Quality**

- **Comprehensive E2E testing** - Automated end-to-end Cypress tests cover purchase order workflows including creation, approval, and error scenarios (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/902"} text={"#902"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/931"} text={"#931"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/938"} text={"#938"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/964"} text={"#964"} />).

**Version Updates**

- **Beta version progression** - Updated through multiple beta versions (beta1 through final 1.0.0) incorporating feedback and bug fixes (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/900"} text={"#900"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/909"} text={"#909"} />).
