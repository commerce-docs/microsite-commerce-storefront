This suite builds on the January 2026 foundation with Document Authoring improvements, Universal Editor model v2 upgrade, and drop-in updates for B2C and B2B. For per-component version details, see the [changelog](/releases/changelog/).

<Aside type="caution" title="Breaking changes">
- **Cards List block removed**: The `cards-list` block has been removed. Use the `cards` block instead.
- **Fragment block behavior**: Fragment blocks now replace their content directly instead of the entire section wrapper, which may affect existing implementations.

</Aside>

## Highlights

- **Document Authoring and Universal Editor**: Commerce blocks include JSON definitions with semantic field names, model v2 component definitions, automated Sidekick configuration, and support for visual authoring in Universal Editor and Document Authoring.
- **Cart**: New `RowTotalFooter` slot for custom content after item row totals (loyalty points, rewards, custom pricing).
- **Checkout**: Discounted shipping methods show original price with strikethrough; PlaceOrder supports async validation.
- **User Account**: New translation keys for multi-line street address fields (`street`, `street_multiline_2`).
- **User Auth**: Custom API error message overrides; enhanced Adobe Commerce Optimizer support.
- **Order**: `gift_wrapping_available` field in product details for conditional gift options.
- **Product Details Page**: Improved validation; downloadable product options support.
- **B2B drop-ins**: All B2B components updated from v1.0.0 to v1.1.0 with SDK improvements and enhanced functionality.

## Updated boilerplate

### Infrastructure

- **GitHub Actions**: Workflow actions updated (checkout@v6, setup-node@v6).
- **Sidekick**: Configuration is now automated; no manual setup required.
- **Drop-in SDK upgrade**: `@dropins/tools` upgraded from ~1.6.0 to ~1.7.0 (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1113"} text={"#1113"} />).

### Document Authoring

- **Universal Editor model v2**: Upgraded component definitions (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).
- **Commerce block definitions**: JSON definitions for Account Header, Account Sidebar, Addresses, Cart, Checkout, Mini Cart, Orders List, Wishlist, and more (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).
- **Field naming**: Semantic names (`image`, `text`, `summary`) instead of CSS selector-based names (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).
- **Enrichment block**: Category enrichment reads URL path from PLP block configuration and preserves wrapper in Universal Editor for continued authoring (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).
- **PDP block**: `defaultSku` support in JSON definitions (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).
- **PLP block**: `urlpath` configuration for category detection; no longer requires dataset attributes (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1086"} text={"#1086"} />).

### Fixes and improvements

- **Fragment block**: Replaces content directly, preserves wrapper (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/576"} text={"#576"} />); handles external URLs correctly (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/577"} text={"#577"} />).
- **Header**: Null checks for missing navigation sections. Navigation closes on focusout for improved keyboard accessibility (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/581"} text={"#581"} />).
- **AEM Assets**: `createOptimizedPicture` handles protocol-relative URLs (`//`) (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/582"} text={"#582"} />).
- **PDP block**: Validates product data before rendering.
- **B2B address handling**: Uses `addressUid` to prevent duplicate address entries during checkout (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1112"} text={"#1112"} />).

## Updated Drop-in SDK

- **Custom content below row total** - Allow custom content below cart item row total price (<Link href={"https://github.com/adobe-commerce/StorefrontSDK/pull/162"} text={"#162"} />).
- **Price display fix** - Resolved issue with displaying prices.
- **RadioButton icon support** - Added icon support to the RadioButton component.
- **Picker component behavior** - Picker component is now disabled when only one option is available.
