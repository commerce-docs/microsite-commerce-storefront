A suite release is a tested combination of storefront and drop-in versions. It gives you a reliable starting point for a new implementation.

## Update an existing storefront

If you already scaffolded or cloned the storefront, you do not need to upgrade to a new suite release. Your project is independent and can continue using its existing code. Suite releases are not packages, so you cannot install or update them as dependencies.

To receive updates, update your drop-in packages (`@dropins/*` and `@adobe/*`) separately. These packages follow semantic versioning, so minor and patch releases are non-breaking by contract. Run `npm outdated` to check which dependencies have newer versions available.

<Aside type="tip" title="Looking for changes to a specific package?">
  Use the [changelog](/releases/changelog/) to browse every change by drop-in or package and
  version.
</Aside>
