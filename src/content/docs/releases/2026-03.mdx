This suite includes product details page video support, multi-store wishlist, a configurable PLP page size, custom product attributes on the PLP, Quick Order for B2B, checkout updates (custom shipping method rows and extensible shipping estimates), and boilerplate improvements for navigation, layout, and multi-website cart behavior. For per-component version details, see the [changelog](/releases/changelog/).

<Aside type="caution" title="Breaking changes">
There are no breaking changes in this release suite.
</Aside>

## Highlights

### Product details page video support

The [ProductGallery](/dropins/product-details/containers/product-gallery/) container now supports product videos out of the box. Merchants can display video alongside product images in the gallery carousel, improving product presentation and shopper engagement. Videos can be positioned before or after images. See the [ProductGallery configuration](/dropins/product-details/containers/product-gallery/#videos) for setup (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1100"} text={"#1100"} />).

### Multi-store wishlist

The Wishlist drop-in now supports multi-store deployments. Pass an optional `storeCode` during [initialization](/dropins/wishlist/initialization/) so wishlist data (localStorage, sessionStorage, and cookies) is scoped per store. This keeps guest and authenticated wishlists isolated between store views while remaining backward compatible for single-store or `'default'` store setups (<Link href={"https://github.com/adobe-commerce/storefront-wishlist/pull/73"} text={"#73"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1139"} text={"#1139"} />).

### Checkout shipping customization and GraphQL extensibility

The [ShippingMethods](/dropins/checkout/containers/shipping-methods/) container adds a `ShippingMethodItem` slot so you can replace the default per-method UI while keeping the selection wired to the API (<Link href={"https://github.com/adobe-commerce/storefront-checkout/pull/300"} text={"#300"} />). You can also extend the `estimateShippingMethods` payload at build time with `ESTIMATE_SHIPPING_METHOD_FRAGMENT` and `EstimateShippingModel` (<Link href={"https://github.com/adobe-commerce/storefront-checkout/pull/307"} text={"#307"} />). See [Extending the checkout drop-in](/dropins/checkout/extending/).

### Quick Order for B2B bulk ordering

B2B customers can add products to the cart by SKU or product name in bulk. The new [Quick Order](/dropins-b2b/quick-order/) drop-in has feature parity with Luma Quick Order and Grid Ordering for configurable products. It is integrated into the boilerplate and ready for use on B2B storefronts (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1125"} text={"#1125"} />, <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1156"} text={"#1156"} />).

### Configurable product listing page size

Product listing pages now allow merchants to control how many products appear per page. The page size is configurable via the block configuration and defaults to 9, giving store owners flexibility without code changes (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1143"} text={"#1143"} />). Custom product attributes can be added to the product listing (<Link href={"https://github.com/adobe-commerce/storefront-search-dropin/pull/89"} text={"#89"} />).

### Correct 404 responses for non-existent pages

Non-existent pages now return a proper server-rendered 404 response. Crawlers and tools receive the correct HTTP status, improving SEO and monitoring accuracy (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1134"} text={"#1134"} />).

### Layout and B2B enhancements

- Full-width sections and padding-based gutters in columns improve layout flexibility (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1133"} text={"#1133"} />).
- B2B: The View wishlist link now includes the store code prefix in PDP and Cart blocks (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1130"} text={"#1130"} />); cart state is cleared when users switch websites to prevent 403 errors (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1137"} text={"#1137"} />).

- **PDP block**: Merchants can display video alongside product images without custom code (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1100"} text={"#1100"} />).
- **PLP block**: Merchants can control how many products appear per page via the block configuration. Defaults to 9 (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1143"} text={"#1143"} />). - **URL manipulation**: URL handling moved to the boilerplate. Filter state resets to page 1 when filters change. Pathname handling works correctly with the store code in the URL (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1119"} text={"#1119"} />).
- **Wishlist**: Guest and authenticated wishlists stay isolated between store views in multi-website deployments (<Link href={"https://github.com/hlxsites/aem-boilerplate-commerce/pull/1139"} text={"#1139"} />).

- **B2B (Cart)**: B2B shoppers in multi-store setups navigate to the correct wishlist page. ## Updated Drop-in SDK

The Drop-in SDK (`@dropins/tools`) was upgraded to ~1.8.0 in this release. The upgrade includes internal build-pipeline improvements. There are no new user-facing SDK APIs in this release suite.
