The Storefront Compatibility B2B Package contains changes to the Adobe Commerce B2B codebase that enable drop-in component functionality. On [Adobe Commerce as a Cloud Service](https://experienceleague.adobe.com/en/docs/commerce/cloud-service/overview), it is installed and updated automatically.
<Badge tooltip="Applies to Adobe Commerce on Cloud projects (Adobe-managed PaaS infrastructure) and on-premises projects only." text="PaaS only" variant="note" href="https://experienceleague.adobe.com/en/docs/commerce/user-guides/product-solutions" />

<br/><br/>

Most of these changes enhance the Adobe Commerce B2B GraphQL schema. However, miscellaneous bug fixes are also included. The drop-in components require this package along with Storefront Compatibility Package.


## Installation

:::note[Note]
This Storefront Compatibility B2B Package is compatible with Adobe Commerce B2B version 1.5 and later. Fixes provided in this package will not be incorporated into future Adobe Commerce B2B releases. Earlier versions of Adobe Commerce B2B and Magento Open Source are not supported.
:::


<Tabs>
  <TabItem label="Cloud infrastructure">

Use this method to install the Storefront Compatibility B2B Package using the Cloud infrastructure.

    1. On your local workstation, change to the project directory for your Adobe Commerce on cloud infrastructure project.

    1. Check out the environment branch to update using the Adobe Commerce Cloud CLI.

       ```bash
       magento-cloud environment:checkout <environment-id>
       ```

    1. Add the Storefront Compatibility Package.

       Use the appropriate package version based on your Adobe Commerce version, go to the [Storefront Compatibility Installation](storefront-compatibility/install/).

       To check the latest version of the Storefront Compatibility Package, go to the [changelog](/releases/changelog/).

    1. Add the Storefront Compatibility B2B module.

       For Adobe Commerce 2.4.7 or later, run:
       ```bash
       composer require adobe-commerce/storefront-compatibility-b2b:1.0.1
       ```

       To check the latest version of the Storefront Compatibility B2B Package, go to the [changelog](/releases/changelog/).

    1. Update package dependencies.

       ```bash
       composer update "adobe-commerce/storefront-compatibility-b2b"
       ```

    1. Commit and push code changes for the `composer.json` and `composer.lock` files.

    1. Add, commit, and push the code changes for the `composer.json` and `composer.lock` files to the cloud environment

       ```bash
       git add -A
       git commit -m "Add module"
       git push origin <branch-name>
       ```

       Pushing the updates to the cloud environment initiates the [Commerce cloud deployment process](https://experienceleague.adobe.com/en/docs/commerce-cloud-service/user-guide/develop/deploy/process) to apply the changes. Check the deployment status from the [deploy log](https://experienceleague.adobe.com/en/docs/commerce-cloud-service/user-guide/develop/test/log-locations#deploy-log).

  </TabItem>
  
  <TabItem label="On premises">

Use this method to install the Storefront Compatibility B2B Package for an on-premises instance.

1. Add the Storefront Compatibility Package.

    Use the appropriate package version based on your Adobe Commerce version, go to the [Storefront Compatibility Installation](storefront-compatibility/install/).

    To check the latest version of the Storefront Compatibility Package, go to the [changelog](/releases/changelog/).

1. Use Composer to add the Storefront Compatibility B2B Package to your project:

    For Adobe Commerce 2.4.7 or later, run:
    ```bash
    composer require adobe-commerce/storefront-compatibility-b2b:1.0.1
    ```

   To check the latest version of the Storefront Compatibility B2B Package, go to the [changelog](/releases/changelog/).

1. Upgrade Adobe Commerce:

   ```bash
   bin/magento setup:upgrade
   ```

## Update the package

Use the following procedure to update patch versions of the Storefront Compatibility B2B Package.

1. Run the following command to update the package:

   ```bash
   composer update adobe-commerce/storefront-compatibility-b2b
   ```

1. Run the following commands to upgrade Adobe Commerce and clear the cache.

   ```bash
   bin/magento setup:upgrade && bin/magento cache:clean
   ```
