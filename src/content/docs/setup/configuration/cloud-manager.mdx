**Commerce Cloud Manager (CCM)** is the self-service portal for Adobe Commerce as a Cloud Service environments. You use it to view your environment status, retrieve Commerce API endpoints, and manage environment variables. This page focuses on the information and credentials you need before configuring your storefront.

<Aside type="note" title="ACCS only">
Commerce Cloud Manager applies to Adobe Commerce as a Cloud Service deployments. If you are using Adobe Commerce on cloud infrastructure (PaaS), manage your environment through the <Link href="https://experienceleague.adobe.com/en/docs/commerce-cloud-service/user-guide/overview" text="Cloud Console" /> instead.
</Aside>

## Access Commerce Cloud Manager

<Steps>

1. Sign in to the <Link href="https://experience.adobe.com" text="Adobe Experience Cloud" /> with your Adobe ID.

1. Select **Commerce** from the product switcher, or navigate directly to your organization's CCM instance.

1. Select the project and environment you want to configure.

</Steps>

Your account must have the **Owner**, **Developer**, or **Viewer** role on the project to access CCM. Contact your organization's system administrator if you do not see your Commerce project.

## Retrieve Commerce API endpoints

Your storefront's `config.json` (storefront configuration) requires the GraphQL endpoint URL for your Commerce environment. Retrieve it from CCM:

<Steps>

1. In Commerce Cloud Manager, select your environment.

1. Select **Settings** or **Environment details** (the exact label may vary by CCM version).

1. Copy the **GraphQL endpoint URL**. This is the value for `commerce-core-endpoint` in your storefront configuration.

1. If your project uses Catalog Service or Live Search, copy the **Catalog Service endpoint URL** as well. This is the value for `commerce-endpoint`.

</Steps>

<Aside type="tip" title="Config generator">
After retrieving your endpoints, use the <Link href="https://da.live/app/adobe-commerce/storefront-tools/tools/config-generator/config-generator" text="Config Generator tool" /> to generate a complete storefront configuration file pre-populated for your ACCS environment. See [Storefront configuration](/setup/configuration/commerce-configuration/) for all available fields.
</Aside>

## Environment variables and credentials

CCM manages environment-specific values such as API keys and integration tokens. The following are relevant to storefront setup:

<TableWrapper nowrap={[0]}>

| Credential | Where used | How to retrieve |
|-----------|-----------|-----------------|
| GraphQL endpoint URL | `config.json` → `commerce-core-endpoint` | CCM environment details |
| Catalog Service endpoint URL | `config.json` → `commerce-endpoint` | CCM environment details |
| Store view code | `config.json` → headers | Commerce Admin → Stores → All Stores |
| Website code | `config.json` → headers | Commerce Admin → Stores → All Stores |
| Commerce environment ID | `config.json` → analytics headers | CCM or Commerce Admin |

</TableWrapper>

## Manage environments

CCM supports multiple environments (production, staging, development) under a single project. Each environment has independent API endpoints. Your storefront configuration must reference the endpoints for the specific environment you are deploying to.

For a full guide to Commerce Cloud Manager features and environment management, see the <Link href="https://experienceleague.adobe.com/en/docs/commerce/cloud-service/overview" text="Adobe Commerce as a Cloud Service documentation" />.
