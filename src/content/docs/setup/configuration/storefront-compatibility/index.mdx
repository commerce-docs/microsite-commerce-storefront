The Storefront Compatibility Package extends Adobe Commerce with GraphQL and REST operations that storefront drop-ins need for cart, checkout, account, and order flows. Use the tables below to find the installation path for each package.

## Find your path

The B2C Storefront Compatibility Package supports Adobe Commerce 2.4.8 and 2.4.9. For new storefront projects, Adobe Commerce 2.4.9 is recommended. Magento Open Source is not supported. If you run Adobe Commerce 2.4.7, see [Adobe Commerce 2.4.7](/reference/storefront-compatibility/v247/) instead. For supported versions and end-of-life dates, see <Link href="https://experienceleague.adobe.com/en/docs/commerce-operations/release/versions" text="Adobe Commerce Software Lifecycle Policy" />.

### Storefront Compatibility B2B Package

B2B drop-ins need the Storefront Compatibility B2B Package (SCP-B2B) in addition to the B2C Storefront Compatibility Package. SCP-B2B extends core Adobe Commerce B2B with additional GraphQL APIs. That makes it a separate package with its own release lifecycle. Adobe Commerce B2B must be on your Commerce instance before you install the package. SCP-B2B supports Adobe Commerce 2.4.8 and 2.4.9 only. See [What you need](/setup/configuration/storefront-compatibility/b2b/#what-you-need) on the B2B package page for prerequisites.
