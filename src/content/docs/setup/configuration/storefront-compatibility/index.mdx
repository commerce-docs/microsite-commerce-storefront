The Storefront Compatibility Package adds backend GraphQL and REST changes that storefront drop-ins need. Who installs it depends on your Commerce backend. Use the table to find your path.

## Find your path

The Storefront Compatibility Package supports Adobe Commerce 2.4.8 and 2.4.9. Magento Open Source is not supported. If you run Adobe Commerce 2.4.7, see [Adobe Commerce 2.4.7](/reference/storefront-compatibility/v247/) instead. For supported versions and end-of-life dates, see <Link href="https://experienceleague.adobe.com/en/docs/commerce-operations/release/versions" text="Adobe Commerce Software Lifecycle Policy" />.

| If you use | Who installs the package? | What to do next |
|---|---|---|
| Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer | Adobe, automatically | [SCP for Adobe Commerce 2.4.9](/setup/configuration/storefront-compatibility/v249/) <br /> [B2B Compatibility Package](/setup/configuration/storefront-compatibility/b2b/) |
| Commerce PaaS or on-premises with Adobe Commerce Optimizer | You, with Composer | [Manual installation](/setup/configuration/storefront-compatibility/install/) |
| Commerce PaaS or on-premises without Adobe Commerce Optimizer | The package is not available on a PaaS-only license. Add Adobe Commerce Optimizer, then install it with Composer | [Backend options](/get-started/backends/) <br /> [Licensing requirements](/licensing/) |
