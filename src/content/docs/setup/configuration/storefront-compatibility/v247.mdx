The Storefront Compatibility Package contains changes to the Adobe Commerce 2.4.7 codebase that enable drop-in component functionality.

Most of these changes enhance the Adobe Commerce GraphQL schema. However, miscellaneous bugfixes are also included. The drop-in components require this package.

:::note[Note]
This Storefront Compatibility Package can be installed on Adobe Commerce 2.4.7 only. Fixes in this package are already included in Adobe Commerce 2.4.8. Lower versions of Adobe Commerce are not supported. Magento Open Source is not supported.
:::

## Major features

The Storefront Compatibility Package defines the following queries and mutations:

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/clear/"} text={"clearWishlist"} /> mutation - Allows all items to be removed from a wishlist in a single action.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/confirm-cancel-order/"} text={"confirmCancelOrder"} /> mutation - Cancels the specified order for a guest.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/confirm-return/"} text={"confirmReturn"} /> mutation - Confirms a guest or customer return request.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-group/"} text={"customerGroup"} /> query - Retrieves information about specified customer group.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-segments/"} text={"customerSegments"} /> query - Retrieves information about specified customer segment.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-external-customer-token/"} text={"exchangeExternalCustomerToken"} /> mutation - Authenticates users using an integration token and returns both the customer token and associated customer data.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/cart/mutations/estimate-totals/"} text={"estimateTotals"} /> mutation - Estimates totals for cart based on the address.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/generate-token/"} text={"generateCustomerToken"} /> mutation - Creates a new customer token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/queries/guest-order/"} text={"guestOrder query"} /> - Retrieves information about a guest order using an order number, email, and billing last name as input.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/queries/guest-order-by-token/"} text={"guestOrderByToken query"} /> - Retrieves information about a guest order based on an order token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/store/queries/recaptcha-form-config/"} text={"recaptchaFormConfig"} /> query - Returns information about the reCaptcha configuration for the specified form type.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/request-guest-order-cancel/"} text={"requestGuestOrderCancel"} /> mutation - Cancels the specified guest order.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/request-guest-return/"} text={"requestGuestReturn"} /> mutation - Requests a return for a specified order on behalf of a guest.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/resend-confirmation-email/"} text={"resendConfirmationEmail"} /> mutation - Resends a confirmation email to the specified customer upon request.
