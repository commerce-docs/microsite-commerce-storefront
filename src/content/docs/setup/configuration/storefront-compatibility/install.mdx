This page is for Commerce on Cloud or on-premises with Adobe Commerce Optimizer. Install the B2C Storefront Compatibility Package with Composer on your Commerce server. If you use [B2B drop-ins](/dropins-b2b/), also install the Storefront Compatibility B2B Package (SCP-B2B) on the same instance after the B2C package and after Adobe Commerce B2B is on the instance. Not sure this is your path? See [Find your path](/setup/configuration/storefront-compatibility/#find-your-path).

## Choose your B2C package

The package version must match your Adobe Commerce release. Use the version from this table in `composer require adobe-commerce/storefront-compatibility:VERSION`.

| Adobe Commerce | Package version | Reference |
|---|---|---|
| 2.4.9 (recommended) | `4.9.2` | [GraphQL and REST changes](/setup/configuration/storefront-compatibility/v249/) |
| 2.4.8 | `4.8.27` | [GraphQL changes](/reference/storefront-compatibility/v248/) |

<Aside type="note" title="Composer key requirements">
To access the latest Storefront Compatibility Package versions, your Composer key must have the Adobe Commerce Optimizer availability group assigned. Without it, Composer can only resolve older versions published under the external scope. This package is available only to Commerce on Cloud or on-premises customers with an Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer license, for both Adobe Commerce 2.4.8 and 2.4.9. If you installed the package on a PaaS-only instance before that requirement took effect, your existing installation is grandfathered in.
</Aside>

## Install the B2C package

<Tabs>
  <TabItem label="Commerce on Cloud">

<Steps>

1. Change to your Commerce project directory.

1. Check out the environment branch you want to update.

   ```bash
   magento-cloud environment:checkout <environment-id>
   ```

1. Add the package using the version from [Choose your B2C package](#choose-your-b2c-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility:4.9.2
   ```

   Use `4.8.27` for Adobe Commerce 2.4.8.

1. Update package dependencies.

   ```bash
   composer update adobe-commerce/storefront-compatibility
   ```

1. Commit and push so the cloud environment picks up `composer.json` and `composer.lock`.

   ```bash
   git add -A
   git commit -m "Add module"
   git push origin <branch-name>
   ```

   When the push finishes, check the <Link href={"https://experienceleague.adobe.com/en/docs/commerce-cloud-service/user-guide/develop/test/log-locations#deploy-log"} text={"Deploy log"} /> in the Cloud console to confirm the deployment succeeded.

</Steps>

  </TabItem>
  
  <TabItem label="On premises">

<Steps>

1. Add the package using the version from [Choose your B2C package](#choose-your-b2c-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility:4.9.2
   ```

   Use `4.8.27` for Adobe Commerce 2.4.8.

1. Apply the module to your Commerce instance.

   ```bash
   bin/magento setup:upgrade
   ```

</Steps>

  </TabItem>

</Tabs>

## Choose your B2B package

[B2B drop-ins](/dropins-b2b/) need SCP-B2B in addition to the B2C package. Adobe Commerce B2B must already be on your Commerce instance. SCP-B2B supports Adobe Commerce 2.4.8 and 2.4.9 only; it does not support Adobe Commerce 2.4.7.

Use the version from this table in `composer require adobe-commerce/storefront-compatibility-b2b:VERSION`. For GraphQL changes in the package, see [B2B Compatibility Package](/setup/configuration/storefront-compatibility/b2b/).

| Adobe Commerce | Package version |
|---|---|
| 2.4.9 (recommended) | `1.0.22` |
| 2.4.8 | `1.0.22` |

<Aside type="note" title="Composer key requirements">
To access the Storefront Compatibility B2B Package, your Composer key must have the Adobe Commerce Optimizer availability group assigned — the same requirement as the B2C package. This package is available only to Commerce on Cloud or on-premises customers with an Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer license. If you installed the package on a PaaS-only instance before that requirement took effect, your existing installation is grandfathered in.
</Aside>

## Install the B2B package

Install SCP-B2B only after the B2C Storefront Compatibility Package is on the instance.

<Tabs>
  <TabItem label="Commerce on Cloud">

<Steps>

1. Change to your Commerce project directory and check out the environment branch you want to update, if you have not already done so for the B2C package.

1. Add SCP-B2B using the version from [Choose your B2B package](#choose-your-b2b-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility-b2b:1.0.22
   ```

1. Update package dependencies.

   ```bash
   composer update adobe-commerce/storefront-compatibility-b2b
   ```

1. Commit and push so the cloud environment picks up `composer.json` and `composer.lock`.

   ```bash
   git add -A
   git commit -m "Add B2B compatibility package"
   git push origin <branch-name>
   ```

</Steps>

  </TabItem>

  <TabItem label="On premises">

<Steps>

1. Add SCP-B2B using the version from [Choose your B2B package](#choose-your-b2b-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility-b2b:1.0.22
   ```

1. Apply the module to your Commerce instance.

   ```bash
   bin/magento setup:upgrade
   ```

</Steps>

  </TabItem>

</Tabs>

## Update the packages

Use these steps after your initial Composer install to move to a newer patch version. Open the [changelog](/releases/changelog/) and filter for the **Storefront Compatibility Package** or **Storefront Compatibility B2B Package** before you update.

<Steps>

1. Update the B2C package:

   ```bash
   composer update adobe-commerce/storefront-compatibility
   ```

1. If you use B2B drop-ins, update SCP-B2B:

   ```bash
   composer update adobe-commerce/storefront-compatibility-b2b
   ```

1. Upgrade Commerce and clear the cache:

   ```bash
   bin/magento setup:upgrade && bin/magento cache:clean
   ```

</Steps>

## What's next

After you install the packages, [configure your storefront](/setup/configuration/commerce-configuration/) to connect to Commerce. Confirm any remaining items on the [Commerce on Cloud or on-premises checklist](/get-started/backends/#paas-required-packages-and-services) before you go live.
