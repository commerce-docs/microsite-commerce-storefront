This page is for Commerce PaaS or on-premises with Adobe Commerce Optimizer. You install the B2C Storefront Compatibility Package with Composer on your Commerce server. The B2B compatibility package is not available on this path. Not sure this is your path? See [Find your path](/setup/configuration/storefront-compatibility/#find-your-path).

## Choose your package

The package version must match your Adobe Commerce release. Use the version from this table in `composer require adobe-commerce/storefront-compatibility:VERSION`.

| Adobe Commerce | Package version | Reference |
|---|---|---|
| 2.4.9 (recommended) | `4.9.0` | [GraphQL and REST changes](/setup/configuration/storefront-compatibility/v249/) |
| 2.4.8 | `4.8.25` | [GraphQL changes](/reference/storefront-compatibility/v248/) |

## Install the package

<Tabs>
  <TabItem label="Commerce on Cloud (PaaS)">

<Steps>

1. Change to your Commerce project directory.

1. Check out the environment branch you want to update.

   ```bash
   magento-cloud environment:checkout <environment-id>
   ```

   Replace `<environment-id>` with your environment ID from the Cloud console or CLI.

1. Add the package using the version from [Choose your package](#choose-your-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility:4.9.0
   ```

   Use `4.8.25` for Adobe Commerce 2.4.8.

1. Update package dependencies.

   ```bash
   composer update "adobe-commerce/storefront-compatibility"
   ```

1. Commit and push so the cloud environment picks up `composer.json` and `composer.lock`.

   ```bash
   git add -A
   git commit -m "Add module"
   git push origin <branch-name>
   ```

   Replace `<branch-name>` with the branch that deploys to your target environment. When the push finishes, check the <Link href={"https://experienceleague.adobe.com/en/docs/commerce-cloud-service/user-guide/develop/test/log-locations#deploy-log"} text={"Deploy log"} /> in the Cloud console to confirm the deployment succeeded.

</Steps>

  </TabItem>
  
  <TabItem label="On premises">

<Steps>

1. Add the package using the version from [Choose your package](#choose-your-package).

   ```bash
   composer require adobe-commerce/storefront-compatibility:4.9.0
   ```

   Use `4.8.25` for Adobe Commerce 2.4.8.

1. Apply the module to your Commerce instance.

   ```bash
   bin/magento setup:upgrade
   ```

</Steps>

  </TabItem>

</Tabs>

## Update the package

Use these steps after your initial Composer install to move to a newer patch version. Open the [changelog](/releases/changelog/) and filter for the **Storefront Compatibility Package** before you update.

<Steps>

1. Update the package:

   ```bash
   composer update adobe-commerce/storefront-compatibility
   ```

1. Upgrade Commerce and clear the cache:

   ```bash
   bin/magento setup:upgrade && bin/magento cache:clean
   ```

</Steps>

## What's next

After you install the package, [configure your storefront](/setup/configuration/commerce-configuration/) to connect to Commerce. Confirm any remaining items on the [Commerce PaaS checklist](/get-started/backends/#paas-required-packages-and-services) before you go live.
