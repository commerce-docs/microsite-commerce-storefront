The Storefront Compatibility B2B Package adds backend GraphQL that [B2B drop-ins](/dropins-b2b/) need. It is not the same as Adobe Commerce B2B or the npm drop-ins in your storefront repo. On Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer, Adobe installs and updates this package automatically.

## What you need

<TableWrapper nowrap={[0]}>

| Item | Requirement |
|---|---|
| Commerce backend | Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer managed backends only. Adobe installs this package on Commerce automatically (no Composer). On Commerce PaaS or on-premises, you can install the B2C Storefront Compatibility Package with Composer when you hold an Adobe Commerce Optimizer license. However, the B2B package is not available for Composer install on Commerce PaaS or on-premises. See [Backend options](/get-started/backends/). |
| B2C compatibility package | Required on the same Commerce instance. See [Storefront Compatibility Package](/setup/configuration/storefront-compatibility/). |
| Adobe Commerce B2B | Separate extension and license on Commerce. Required on your instance before Adobe provisions this compatibility package. Contact your Adobe account representative to add it to your contract. |
| B2B drop-ins in your repo | You install with npm after the backend is ready. See [Licensing requirements](/licensing/). |

</TableWrapper>

Tested with Adobe Commerce `2.4.8` and `2.4.9` and Adobe Commerce B2B `1.5.2`. Magento Open Source is not supported. For tested drop-in versions, see the [release suite](/releases/).

## Major features

Adobe releases new GraphQL queries and mutations across minor versions in each package line. The list below summarizes the full `1.0.22` line; not every item was introduced in `1.0.22`, even though it is the latest release in the Storefront Compatibility B2B Package series. For version-specific changes, see the [changelog](/releases/changelog/) and filter for the Storefront Compatibility B2B Package.

The `1.0.22` package line adds the following GraphQL queries and mutations. [Quick Order](/dropins-b2b/quick-order/) uses core Commerce GraphQL and is not listed here.

#### Company hierarchy

Supports [Company Management](/dropins-b2b/company-management/) and [Company Switcher](/dropins-b2b/company-switcher/).

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/company/mutations/assign-child-company/"} text={"assignChildCompany"} /> mutation — Company administrators can assign a child company to a parent company within the company hierarchy.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/company/mutations/unassign-child-company/"} text={"unassignChildCompany"} /> mutation — Company administrators can unassign a child company from its parent company within the company hierarchy.

#### Requisition lists

Supports the [Requisition List](/dropins-b2b/requisition-list/) drop-in.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/requisition-list/queries/shared-requisition-list/"} text={"sharedRequisitionList"} /> query — Retrieves a read-only shared requisition list for B2B customers, including sender details and associated items, based on the provided token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/requisition-list/mutations/share-requisition-list-by-token/"} text={"shareRequisitionListByToken"} /> mutation — Generates a shareable storefront token that enables B2B customers to share a requisition list with colleagues within the same company.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/requisition-list/mutations/share-requisition-list-by-email/"} text={"shareRequisitionListByEmail"} /> mutation — Sends a requisition list to colleagues within the same company via email for B2B customers.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/requisition-list/mutations/import-shared-requisition-list/"} text={"importSharedRequisitionList"} /> mutation — Imports a shared requisition list into the current customer account based on the provided token.

#### Negotiable quotes

Supports [Quote Management](/dropins-b2b/quote-management/).

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/negotiable-quote/queries/templates/"} text={"negotiableQuoteTemplates"} /> query — Retrieves negotiable quote templates with sales rep, order, and pricing details.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/negotiable-quote/mutations/set-quote-template-expiration-date/"} text={"setQuoteTemplateExpirationDate"} /> mutation — Sets an expiration date on negotiable quote templates.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/negotiable-quote/mutations/place-order-v2/"} text={"placeNegotiableQuoteOrderV2"} /> mutation — Transforms a negotiable quote into an order and returns full order details, including an errors array for standardized response handling.

#### Purchase orders

Supports the [Purchase Order](/dropins-b2b/purchase-order/) drop-in.

- `approvePurchaseOrders` mutation — Approves one or more purchase orders pending the customer's action.
