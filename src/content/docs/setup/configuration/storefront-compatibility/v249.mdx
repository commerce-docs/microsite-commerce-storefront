The Storefront Compatibility Package contains changes to the Adobe Commerce 2.4.9 codebase that enable drop-in component functionality.

Most of these changes enhance the Adobe Commerce GraphQL schema. However, miscellaneous bugfixes are also included. The drop-in components require this package.

<Aside type="note" title="Version and compatibility requirements">
This Storefront Compatibility Package can be installed on Adobe Commerce 2.4.9 with a Commerce Optimizer license only. Lower versions of Adobe Commerce are not supported. Magento Open Source is not supported.
</Aside>

## Major features

The Storefront Compatibility Package defines the following queries, mutations, and schema extensions:

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-otp-customer-token/"} text={"exchangeOtpForCustomerToken"} /> mutation — Authenticates admins as customers for seller-assisted buying by exchanging a one-time password (OTP) and email for a customer token.

- **admin_assistance_actions** on the Customer type — Paginated log of administrator actions performed during seller-assisted buying sessions.

- **admin_assisted_order** on the CustomerOrder type — Identifies orders placed while an administrator was signed in as the customer.

- **shopping_assistance_enabled**, **shopping_assistance_checkbox_title**, and **shopping_assistance_checkbox_tooltip** on StoreConfig — Expose Login as Customer configuration to the storefront.

- **quantity** on ProductInterface — Quantity of available stock.

- **is_salable**, **backorder_message**, and **not_available_message** on cart line items — Salability checks and customer-facing availability messages at checkout.

- **items_v2** on Wishlist — Paginated wishlist items.

- **returns** on CustomerOrder — Customer return requests on an order.

- **product** on OrderItemInterface — Product data on order line items.
