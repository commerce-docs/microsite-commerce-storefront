The Storefront Compatibility Package adds backend changes that storefront drop-ins need on Adobe Commerce 2.4.9. The `4.9.2` line is mostly GraphQL schema extensions and REST endpoints, plus bug fixes. Many compatibility changes from earlier package lines are already in Adobe Commerce 2.4.9 core, but drop-in components still require this package.

<Aside type="note" title="Version and compatibility requirements">
Adobe Commerce 2.4.9 only. Magento Open Source and earlier Adobe Commerce versions are not supported.

On Adobe Commerce as a Cloud Service, Adobe installs and updates this package automatically. On Commerce on Cloud or on-premises with Adobe Commerce Optimizer, you install the current package line with Composer. See [Manual installation](/setup/configuration/storefront-compatibility/install/).
</Aside>

## Major features

Adobe releases new GraphQL queries, mutations, and REST endpoints across minor versions in each package line. The list below summarizes the full `4.9.2` line, though not every item was introduced in `4.9.2` — it is simply the latest release in the 4.9.x series. For version-specific changes, see the [changelog](/releases/changelog/) and filter for the Storefront Compatibility Package.

The `4.9.2` package line adds the following GraphQL queries and mutations:

#### Login as Customer and seller-assisted buying

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-otp-customer-token/"} text={"exchangeOtpForCustomerToken"} /> mutation — Authenticates admins as customers for seller-assisted buying by exchanging a one-time password (OTP) and email for a customer token.

#### REST endpoints

The `4.9.2` line also adds or extends these REST APIs:

- `GET /V1/customerSegments/search` — Retrieves customer segments for integration or IMS token callers.

- `GET /V1/customerGroups/search` — Adds a `uid` extension attribute on each customer group in the response.

- `GET /V1/customers/:customerId` — Adds an `assistance_allowed` extension attribute that indicates whether the customer enabled admin assistance for Login as Customer.

- `POST /V1/customer/:customerId/otp` — Generates a one-time password in Admin for seller-assisted buying and Login as Customer workflows.
