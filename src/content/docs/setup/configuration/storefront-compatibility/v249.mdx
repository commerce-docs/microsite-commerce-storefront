The Storefront Compatibility Package adds backend changes that storefront drop-ins need on Adobe Commerce 2.4.9. This package provides mostly GraphQL schema extensions and REST endpoints, plus bug fixes.

<Aside type="note" title="Version and compatibility requirements">
Adobe Commerce 2.4.9 only. Magento Open Source and earlier Adobe Commerce versions are not supported.

On Adobe Commerce as a Cloud Service, Adobe installs and updates this package automatically. On Commerce on Cloud or on-premises with Adobe Commerce Optimizer, you can install the current package line with Composer. See [Manual installation](/setup/configuration/storefront-compatibility/install/).
</Aside>

## Major features

Adobe releases new GraphQL queries, mutations, and REST endpoints across minor versions in each package line. For version-specific changes, see the [changelog](/releases/changelog/) and filter for the Storefront Compatibility Package.

## GraphQL APIs

This package provides the following GraphQL queries and mutations:

#### Login as Customer and seller-assisted buying

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-otp-customer-token/"} text={"exchangeOtpForCustomerToken"} /> mutation — Authenticates admins as customers for seller-assisted buying by exchanging a one-time password (OTP) and email for a customer token.

#### Persistent Shopping Cart and Customer

Adds the following fields to the `storeConfig` query:

- `share_customer_accounts_scope` — Indicates whether customer accounts are shared across all websites or scoped to a single website.
- `persistent_enabled` — Indicates whether persistent shopping cart and wishlist settings are enabled for the store.
- `persistent_shopping_cart` — Indicates whether the persistent shopping cart is enabled.
- `persistent_options_wishlist` — Indicates whether the persistent wishlist is enabled.

#### Free Gift Selection

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/cart/mutations/select-free-gift/"} text={"selectFreeGift"} /> mutation — Selects a free gift for an eligible cart promotion.

#### Product Alerts

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/queries/is-subscribed-product-alert-price/"} text={"isSubscribedProductAlertPrice"} /> query — Checks whether a customer is subscribed to price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/queries/is-subscribed-product-alert-stock/"} text={"isSubscribedProductAlertStock"} /> query — Checks whether a customer is subscribed to stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/subscribe-product-alert-price/"} text={"subscribeProductAlertPrice"} /> mutation — Subscribes a customer to price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/subscribe-product-alert-stock/"} text={"subscribeProductAlertStock"} /> mutation — Subscribes a customer to stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-price/"} text={"unsubscribeProductAlertPrice"} /> mutation — Unsubscribes a customer from price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-price-all"} text={"unsubscribeProductAlertPriceAll"} /> mutation — Unsubscribes a customer from all price alerts.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-stock/"} text={"unsubscribeProductAlertStock"} /> mutation — Unsubscribes a customer from stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-stock-all"} text={"unsubscribeProductAlertStockAll"} /> mutation — Unsubscribes a customer from all stock alerts.

## REST endpoints
 
This package also provides following REST APIs:

- `GET /V1/customerSegments/search` — Retrieves customer segments for integration or IMS token callers.

- `GET /V1/customerGroups/search` — Adds a `uid` extension attribute on each customer group in the response.

- `GET /V1/customers/:customerId` — Adds an `assistance_allowed` extension attribute that indicates whether the customer enabled admin assistance for Login as Customer.

- `POST /V1/customer/:customerId/otp` — Generates a one-time password in Admin for seller-assisted buying and Login as Customer workflows.
