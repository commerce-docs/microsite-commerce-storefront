The Storefront Compatibility Package adds backend changes that storefront drop-ins need on Adobe Commerce 2.4.9. The `4.9.0` line is mostly GraphQL schema extensions and REST endpoints, plus bug fixes. Many compatibility changes from earlier package lines are already in Adobe Commerce 2.4.9 core. Drop-in components still require this package.

<Aside type="note" title="Version and compatibility requirements">
Adobe Commerce 2.4.9 only. Magento Open Source and earlier Adobe Commerce versions are not supported.

On Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer, Adobe installs and updates this package automatically. On Commerce PaaS or on-premises, you must have an Adobe Commerce Optimizer license and install `4.9.0` with Composer. See [Manual installation](/setup/configuration/storefront-compatibility/install/).
</Aside>

## Major features

The `4.9.0` package line adds the following GraphQL queries, mutations, and schema extensions:

#### Login as Customer and seller-assisted buying

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-otp-customer-token/"} text={"exchangeOtpForCustomerToken"} /> mutation — Authenticates admins as customers for seller-assisted buying by exchanging a one-time password (OTP) and email for a customer token.

- `admin_assistance_actions` on the `Customer` type — Paginated log of administrator actions performed during seller-assisted buying sessions.

- `admin_assisted_order` on the `CustomerOrder` type — Identifies orders placed while an administrator was signed in as the customer.

- `shopping_assistance_enabled`, `shopping_assistance_checkbox_title`, and `shopping_assistance_checkbox_tooltip` on `StoreConfig` — Expose Login as Customer configuration to the storefront.

#### Catalog and cart availability

- `quantity` on `ProductInterface` — Quantity of available stock.

- `only_x_left_in_stock` on `ProductInterface` — Low-stock threshold message data for a product.

- `is_salable`, `backorder_message`, and `not_available_message` on cart line items — Salability checks and customer-facing availability messages at checkout.

#### Wishlist, orders, and returns

- `items_v2` on `Wishlist` — Paginated wishlist items.

- `returns` on `CustomerOrder` — Customer return requests on an order.

- `product` on `OrderItemInterface` — Product data on order line items.

#### REST endpoints

The `4.9.0` line also adds or extends these REST APIs:

- `GET /V1/customerSegments/search` — Retrieves customer segments for integration or IMS token callers.

- `GET /V1/customerGroups/search` — Adds a `uid` extension attribute on each customer group in the response.

- `GET /V1/customers/:customerId` — Adds an `assistance_allowed` extension attribute that indicates whether the customer enabled admin assistance for Login as Customer.

- `POST /V1/customer/:customerId/otp` — Generates a one-time password in Admin for seller-assisted buying and Login as Customer workflows.

GraphQL operations documented for the `4.8.25` package on [Adobe Commerce 2.4.8](/reference/storefront-compatibility/v248/) are not listed here when they are not part of the `4.9.0` package modules. Adobe Commerce 2.4.9 core includes many compatibility changes from earlier package lines.
