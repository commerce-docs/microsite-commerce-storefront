Complete this checklist before starting the [Create a storefront](/get-started/create-storefront/) guide. The steps below apply specifically to Adobe Commerce as a Cloud Service (ACCS) and Adobe Commerce Optimizer (ACO) deployments. PaaS customers should verify access to the services described in [Prerequisites](/get-started/prerequisites/).

## Adobe Experience Cloud access

Your organization must have an active Adobe Experience Cloud contract that includes entitlements for all required services. Provisioning is managed through the Adobe Admin Console.

- Confirm your Adobe organization ID (IMS Org ID) is active in the <Link href="https://adminconsole.adobe.com" text="Adobe Admin Console" />.
- Verify that your user account has been added to the correct product profiles for Edge Delivery Services, Adobe Commerce, and Adobe I/O.
- Confirm that your organization has been provisioned for Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer (depending on your license).

See [Adobe Experience Cloud access](/setup/configuration/experience-cloud-access/) for Admin Console setup and entitlement verification steps.

## Commerce Cloud Manager access

Adobe Commerce as a Cloud Service projects are managed through the Commerce Cloud Manager (CCM). Verify the following before starting storefront setup:

- Your user account has the **Owner** or **Developer** role in the CCM project for your environment.
- Your Commerce environment has been created and is in the **Active** state in CCM.
- You have retrieved the Commerce GraphQL endpoint URL from CCM.

See [Commerce Cloud Manager](/setup/configuration/cloud-manager/) for how to access CCM and retrieve your environment details.

## Adobe Developer Console and App Builder

Several storefront integrations (API Mesh, Data Connection, Commerce Eventing) require an App Builder project in the Adobe Developer Console.

- Your organization has App Builder entitlement in the <Link href="https://developer.adobe.com/console" text="Adobe Developer Console" />.
- A Developer Console workspace has been created for your Commerce project.
- Your user account has **Developer** or **Admin** access to the project.

See [App Builder setup](/setup/configuration/app-builder/) for project creation and workspace configuration.

## API Mesh

If your storefront uses API Mesh to aggregate Commerce and third-party APIs, verify the following:

- API Mesh is enabled on your Adobe Developer Console project.
- You have the `@adobe/aio-cli-plugin-api-mesh` CLI plugin installed.
- Your mesh configuration file is prepared for your Commerce environment.

See [API Mesh configuration](/setup/configuration/api-mesh/) for setup steps.

## Edge Delivery Services access

- Your Adobe account team has provisioned Edge Delivery Services for your organization.
- You have access to create new sites in the <Link href="https://da.live" text="DA.live" /> Document Author environment.
- The AEM Code Sync GitHub App can be installed on your GitHub organization (check with your GitHub org admin if Code Sync requires approval).

## GitHub

- A GitHub organization or personal account is available for creating the boilerplate repository.
- You have sufficient permissions to create repositories and install GitHub Apps.

<Aside type="tip" title="GitHub Enterprise users">
If your organization uses GitHub Enterprise with SAML SSO, ensure Code Sync can be authorized for SSO access before starting setup.
</Aside>
