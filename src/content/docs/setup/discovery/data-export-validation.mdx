Data export synchronizes data between your Adobe Commerce instance and [storefront services](/get-started/architecture/#storefront-services). Storefront services supply the data that drop-in components need to run correctly.

## When to run validation

Run validation after your Commerce environment is active and services are provisioned—for example, after you retrieve endpoints from [Commerce Cloud Manager](/setup/configuration/cloud-manager/). Run validation before you treat catalog search and product APIs as production-ready in a proof of concept or cutover. Early validation helps you avoid debugging storefront issues that are actually sync or export gaps.

## Expected validation results

You should see sync jobs complete without persistent errors, and you should be able to query product data through the same APIs the storefront uses. Use the [Data Management Dashboard](https://experienceleague.adobe.com/en/docs/commerce-admin/systems/data-transfer/data-dashboard) to monitor progress for each service. For troubleshooting and field-level behavior, see the [_SaaS Data Export Guide_](https://experienceleague.adobe.com/en/docs/commerce/saas-data-export/overview).

## Run GraphQL smoke tests

Use GraphQL to confirm that products have synchronized and that product lookup and search return results as expected. See [GraphQL queries](https://developer.adobe.com/commerce/webapi/graphql/schema/catalog-service/queries/products/) and the [Postman sample collection](https://github.com/magento/adobe-commerce-catalog-service) for example queries.

You can also send requests to **Adobe Commerce as a Cloud Service** and **Adobe Commerce Optimizer** endpoints from these in-site playgrounds: <Link href="/playgrounds/commerce-services/" text="Commerce Services playground" /> and <Link href="/playgrounds/commerce-optimizer/" text="Commerce Optimizer playground" />.

## Validate large or complex catalogs

For large or complex catalogs, contact the Adobe team on [Discord](https://discord.com/channels/1131492224371277874/1220042081209421945) to confirm that exported data is correct. Adobe might ask for a database dump or direct access. If you hit an unsupported scenario, contact the Adobe team so it can be considered for a future release.

For more information, see [Discovery overview](/setup/discovery/).
