## Overview

The **Personalization** drop-in provides **1** pre-built container component for integrating into your storefront.

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

- [Targeted block](/dropins/personalization/containers/targeted-block/)


<Aside type="tip">
The TargetedBlock container enables dynamic content personalization based on Adobe Target segments and experiences.
</Aside>
