## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/personalization-dictionary.js"
export const personalizationDictionary = {
    "Personalization": {
      "Component": {
        "heading": "My Custom Heading",
        "buttonText": "Click Me"
      }
    }
  };
```

Then import it in your initializer:

```javascript title="scripts/initializers/personalization.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-personalization';
import { personalizationDictionary } from '../config/dictionaries/personalization-dictionary.js';

const langDefinitions = {
  default: {
    ...personalizationDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
