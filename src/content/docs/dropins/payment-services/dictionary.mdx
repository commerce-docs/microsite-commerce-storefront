## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/payment-services-dictionary.js"
export const paymentServicesDictionary = {
  "PaymentServices": {
    "CreditCard": {
      "formFields": {
        "cvv": {
          "invalidError": "Custom string",
          "missingError": "Custom string"
        }
      }
    }
  }
};
```

Then import it in your initializer:

```javascript title="scripts/initializers/payment-services.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-payment-services';
import { paymentServicesDictionary } from '../config/dictionaries/payment-services-dictionary.js';

const langDefinitions = {
  default: {
    ...paymentServicesDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
