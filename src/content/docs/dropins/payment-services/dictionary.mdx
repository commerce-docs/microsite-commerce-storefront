## How to override keys

Choose your approach based on your needs:

### Option 1: Override specific keys (recommended)

**Best for**: Customizing a few labels, changing brand terminology, or making targeted updates.

1. Find the keys you want to customize in the sections above
2. Create a custom dictionary file with just those keys
3. Pass it to the drop-in's `initialize()` function

### Example: Custom dictionary

```javascript title="custom-dictionary.js"
// Create your custom dictionary file
export const customDictionary = {
  "PaymentServices": {
    "CreditCard": {
      "formFields": {
        "cvv": {
          "invalidError": "Custom Enter valid cvv.",
          "label": "Custom ",
          "missingError": "Custom This field is requir..."
        }
      }
    }
  }
};
```

```javascript title="initialize-dropin.js"
import { initialize } from '@dropins/storefront-payment-services';
import { customDictionary } from './custom-dictionary';

// Initialize with custom dictionary
await initialize({
  langDefinitions: {
    en_US: customDictionary
  }
});
```

<Aside type="tip">
**Why this is better**: Only override what you need. Your custom dictionary stays small and maintainable, making updates easier when the drop-in releases new versions.
</Aside>

### Option 2: Download complete dictionary

**Best for**: Full translations to other languages, or extensive customization of many labels.

You can download and modify the complete dictionary file:

```json title="en_US.json" showLineNumbers

        "methodNotLoaded": "Failed to load payment method. Please try again later."

```

<Aside type="note">
**Download tip**: Copy the entire JSON above, save it as `custom-en_US.json`, then modify the values you need. You can also [view this file in the source repository](git@github.com:adobe-commerce/storefront-payment-services/blob/main/src/i18n/en_US.json).
</Aside>

**Example: Using complete dictionary**

```javascript title="initialize-with-full-dict.js"
import { initialize } from '@dropins/storefront-payment-services';
import customDictionary from './custom-en_US.json';

await initialize({
  langDefinitions: {
    en_US: customDictionary
  }
});
```

<Aside type="caution">
**Maintenance consideration**: With a full dictionary, you'll need to manually merge updates when the drop-in releases new keys. Consider using Option 1 for easier maintenance.
</Aside>
