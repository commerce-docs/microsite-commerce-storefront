The **Payment Services dictionary** contains all user-facing text, labels, and messages displayed by this drop-in. By customizing the dictionary, you can:

- **Localize** the drop-in for different languages and regions
- **Customize** labels and messages to match your brand voice
- **Override** default text without modifying the drop-in's source code

Dictionaries use the **i18n (internationalization)** pattern, where each text string is identified by a unique key path.

## How to customize

### Step 1: Create a custom dictionary file

Create a JavaScript or JSON file in your project to store your customizations. Common locations:

- `src/config/custom-dictionary.js` (recommended for modular projects)
- `scripts/i18n/en_US.json` (if you have an i18n folder)
- Anywhere in your project that makes sense for your structure

**Example: Only override specific keys you want to change**

```javascript title="src/config/custom-dictionary.js"
// You only need to include the keys you're customizing
export const customDictionary = {
    "PaymentServices": {
      "CreditCard": {
        "formFields": {
          "cvv": {
            "invalidError": "Custom Enter valid cvv.",
            "missingError": "Custom This field is required."
          }
        }
      }
    }
  };
```

<Aside type="tip">
**Partial overrides**: You don't need to copy the entire dictionary! The drop-in will deep-merge your custom values with the defaults. Only include keys you want to change.
</Aside>

### Step 2: Import and load your custom dictionary

Pass your custom dictionary to the drop-in's `initialize()` function using the `langDefinitions` option:

```javascript title="src/main.js"
import { initialize } from '@dropins/storefront-payment-services';
import { customDictionary } from './config/custom-dictionary.js';

await initialize({
  langDefinitions: {
    en_US: customDictionary
  }
});
```

### Step 3: Test your changes

Your custom values will now appear in the UI instead of the defaults. The drop-in automatically merges your overrides with the default dictionary.
