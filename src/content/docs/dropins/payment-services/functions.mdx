## submitCreditCard

The `submitCreditCard` function validates and submits the currently-rendered [`CreditCard`](/dropins/payment-services/containers/credit-card/) container's form.

```ts
async function submitCreditCard(): Promise<void>
```

The returned promise resolves only once the payment flow finishes successfully, and rejects with a [`PaymentServicesError`](#paymentserviceserror) in any of these cases:

<TableWrapper nowrap={[0]}>

  | `code` | When it happens |
  | --- | --- |
  | `payment-services/credit-card-form-not-rendered` | No [`CreditCard`](/dropins/payment-services/containers/credit-card/) container is currently rendered on the page. |
  | `payment-services/credit-card-form-invalid` | The form has one or more invalid fields; the first invalid field is focused automatically. |
  | `payment-services/unknown-error` | Any other error during the payment flow. This may be a localized error (see [`localized`](/dropins/payment-services/functions/#paymentserviceserror) below) safe to show directly to the shopper. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns `Promise<void>`.

### Example

```js
import * as paymentsApi from '@dropins/storefront-payment-services/api.js';

const $placeOrderButton = document.getElementById('place-order');

$placeOrderButton.onclick = () => {
  paymentsApi.submitCreditCard()
    .then(() => {
      console.log('Credit card submitted successfully.');
    })
    .catch((error) => {
      if (error.code === 'payment-services/credit-card-form-invalid') {
        return;
      }
      console.error(error.code, error.message);
    });
};
```
