The Payment Services drop-in provides functionality through:

- **Containers** - Pre-built UI components that you can integrate into your storefront. Check the Containers section for available components.
- **Events** - Event-driven communication for state management and integration. See the [Events documentation](/dropins/payment-services/events/) for details.
- **Configuration** - Setup and configuration through Adobe Commerce admin panel.

<Aside type="tip">
If you need programmatic control, consider reaching out to Adobe Commerce support or checking the latest drop-in releases for new API functions.
</Aside>
