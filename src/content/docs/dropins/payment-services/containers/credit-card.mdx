The `CreditCard` container renders a form for entering credit card details during checkout.

## Configuration

The `CreditCard` container provides the following configuration options:

<TableWrapper nowrap={[0, 1, 2]}>
| Option | Type | Req? | Description |
|--------|------|------|-------------|
| `getCartId` | function | No | Returns a promise that resolves to the shopper’s cart ID. <Aside type="caution" title="Deprecated as of version 4.2.1">The API function [submitCreditCard](/dropins/payment-services/functions/#submitcreditcard) reads the cart ID from the [cart/data](/dropins/cart/events/#cartdata-emits-and-listens) event instead of a callback. Make sure that event has fired at least once with the shopper's cart before calling `submitCreditCard()`.</Aside> |
| `creditCardFormRef` | object | No | Reference to the credit card form. Initially, `{ current: null }` should be passed. After rendering, the container sets `current` to the `validate: () => boolean` and `submit: () => Promise<void>` object, which parent containers can use to programmatically validate and submit the form. Any error during the payment flow propagates to `onError` and causes the promise returned by `submit()` to be rejected. <Aside type="caution" title="Deprecated as of version 4.2.1">Validate and submit the credit card form using the [submitCreditCard](/dropins/payment-services/functions/#submitcreditcard) API function instead. There's no direct replacement for standalone validation: calling `submitCreditCard()` on an invalid form rejects with a `payment-services/credit-card-form-invalid` error and automatically focuses the first invalid field.</Aside> |
| `onSuccess` | function | No | Called when the payment completes successfully. Receives `{ cartId: string }`. <Aside type="caution" title="Deprecated as of version 4.2.1">Await the promise returned by the API function [submitCreditCard](/dropins/payment-services/functions/#submitcreditcard) instead. It resolves only when the payment flow finishes successfully, but it doesn't provide the cart ID like `onSuccess` does. Capture the cart ID from the latest [cart/data](/dropins/cart/events/#cartdata-emits-and-listens) event payload at the time you call `submitCreditCard()`. That's the cart the payment order is submitted for.</Aside> |
| `onError` | function | No | Called when the payment flow fails or is aborted. Receives `{ name: string, message: string }`, containing localized, user-facing error details. These values can be translated using `PaymentServices.CreditCard.errors` [language definitions](/dropins/payment-services/dictionary/). <Aside type="caution" title="Deprecated as of version 4.2.1">Await and catch the promise rejection from the API function [submitCreditCard](/dropins/payment-services/functions/#submitcreditcard) instead. Unlike `onError`, not every rejection is localized and user-facing: check that [error.localized](/dropins/payment-services/functions/#paymentserviceserror) is `true` before showing `error.name` or `error.message` to the shopper. Localized errors can still be translated using `PaymentServices.CreditCard.errors` [language definitions](/dropins/payment-services/dictionary/).</Aside> |
</TableWrapper>

## Slots

This container exposes no customizable slots.

## Usage

The following example demonstrates how to render a credit card form and submit it using the [submitCreditCard](/dropins/payment-services/functions/#submitcreditcard) API function:

```js
import * as paymentsApi from '@dropins/storefront-payment-services/api.js';
import CreditCard from '@dropins/storefront-payment-services/containers/CreditCard.js';
import { render as PaymentServices } from '@dropins/storefront-payment-services/render.js';

const $content = document.createElement('div');
const $placeOrderButton = document.getElementById('place-order');

PaymentServices.render(CreditCard)($content);

$placeOrderButton.onclick = () => {
  paymentsApi.submitCreditCard()
    .then(() => {
      console.log('Credit card submitted successfully.');
    })
    .catch((error) => {
      if (error.code === 'payment-services/credit-card-form-invalid') {
        return;
      }
      console.error(error.code, error.message);
    });
};
```
