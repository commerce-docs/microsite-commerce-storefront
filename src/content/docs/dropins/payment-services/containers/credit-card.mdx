The `CreditCard` container renders a form for entering credit card details during checkout.

## Configuration

The `CreditCard` container provides the following configuration options:

<TableWrapper nowrap={[0, 1, 2]}>
| Option | Type | Req? | Description |
|--------|------|------|-------------|
| `getCartId` | function | No | Returns a promise that resolves to the shopper’s cart ID. <Aside type="caution" title="Deprecated as of version 4.2.1">Provide the cart ID with a [cart/data](/dropins/cart/events/#cartdata-emits-and-listens) event instead.</Aside> |
| `creditCardFormRef` | object | No | Reference to the credit card form. Initially, `{ current: null }` should be passed. After rendering, the container sets `current` to the `validate: () => boolean` and `submit: () => Promise<void>` object, which parent containers can use to programmatically validate and submit the form. Any error during the payment flow propagates to `onError` and causes the promise returned by `submit()` to be rejected. <Aside type="caution" title="Deprecated as of version 4.2.1">Validate and submit the credit card form using the [`submitCreditCard()`](/dropins/payment-services/functions/#submitcreditcard) API function instead.</Aside> |
| `onSuccess` | function | No | Called when the payment completes successfully. Receives `{ cartId: string }`. <Aside type="caution" title="Deprecated as of version 4.2.1">Await the promise returned by API function [`submitCreditCard()`](/dropins/payment-services/functions/#submitcreditcard) instead. It resolves only if the payment order was submitted successfully, but it doesn't return the cart ID. One can read the cart ID from the [cart/data](/dropins/cart/events/#cartdata-emits-and-listens) event instead. </Aside> |
| `onError` | function | No | Called when the payment flow fails or is aborted. Receives `{ name: string, message: string }`, containing localized, user-facing error details. These values can be translated using `PaymentServices.CreditCard.errors` [language definitions](/dropins/payment-services/dictionary/). <Aside type="caution" title="Deprecated as of version 4.2.1">Catch promise rejection from API function [`submitCreditCard()`](/dropins/payment-services/functions/#submitcreditcard) instead.</Aside> |
</TableWrapper>

## Slots

This container exposes no customizable slots.

## Usage

The following example demonstrates how to render a credit card form and submit it using the [`submitCreditCard`](/dropins/payment-services/functions/#submitcreditcard) API function:

```js
import * as paymentsApi from '@dropins/storefront-payment-services/api.js';
import CreditCard from '@dropins/storefront-payment-services/containers/CreditCard.js';
import { render as PaymentServices } from '@dropins/storefront-payment-services/render.js';

const $content = document.createElement('div');
const $placeOrderButton = document.getElementById('place-order');

PaymentServices.render(CreditCard)($content);

$placeOrderButton.onclick = () => {
  paymentsApi.submitCreditCard()
    .then(() => {
      console.log("Credit card submitted successfully.")
    })
    .catch((error) => {
      if (error.code === "payment-services/invalid-credit-card-form") {
        return;
      }
      console.error(error.code, error.message);
    })
};
```
