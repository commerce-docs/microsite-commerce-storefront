The **Payment Services** drop-in provides pre-built container components for integrating into your storefront.

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [ApplePay](/dropins/payment-services/containers/apple-pay/) | The `ApplePay` container renders a button that macOS/iOS users can use to check out using Apple Pay. |
| [CreditCard](/dropins/payment-services/containers/credit-card/) | The `CreditCard` container renders a credit card form that shoppers can use to enter credit card details during the checkout process. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
