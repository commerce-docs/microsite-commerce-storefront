The `PayPalButtons` container renders a set of checkout buttons that enable shoppers to pay using <Link href="https://www.paypal.com/" text="PayPal" /> — including PayPal, Venmo, Pay Later, and debit/credit card, depending on which funding sources are enabled for the merchant.

## Configuration

The `PayPalButtons` container provides the following configuration options:

<TableWrapper nowrap={[0, 1, 2]}>
| Option | Type | Req? | Description |
|--------|------|------|-------------|
| `location` | string | Yes | Location where the PayPal buttons are rendered. Must be either `CHECKOUT` or `PRODUCT_DETAIL`. |
| `onButtonClick` | function | No | Called when the shopper clicks a PayPal button. Receives a `showPaymentSheet` function, which must be called synchronously to begin the PayPal checkout and show the payment sheet. If not provided, clicking the button automatically triggers the payment sheet. |
| `onSuccess` | function | No | Called when the payment completes successfully. Receives `{ cartId: string }`. If the function returns a promise, it is awaited before marking the payment as successful. If the promise rejects, the payment is marked as failed and the error is passed to `onError` (if provided). |
| `onError` | function | No | Called when the payment flow fails or is aborted. Receives `{ name: string, message: string }`, containing localized, user-facing error details. These values can be translated using `PaymentServices.PayPalButtons.errors` [language definitions](/dropins/payment-services/dictionary/). |
| `hidden` | boolean | No | Whether the buttons are hidden. Set to `true` to hide the PayPal buttons. Default: `false`. |
| `disabled` | boolean | No | Whether the buttons are disabled. Set to `true` to disable the PayPal buttons. Default: `false`. |
</TableWrapper>

## Slots

This container does not expose any customizable slots.

## Usage

### Checkout page example

The following example demonstrates how to use the `PayPalButtons` container on the checkout page.

```js
import PayPalButtons from '@dropins/storefront-payment-services/containers/PayPalButtons.js';
import { render as PaymentServices } from '@dropins/storefront-payment-services/render.js';
import * as orderApi from '@dropins/storefront-order/api.js';
import { PaymentLocation } from '@dropins/storefront-payment-services/api.js';

const $content = document.createElement('div');
PaymentServices.render(PayPalButtons, {
  location: PaymentLocation.CHECKOUT,
  onSuccess: ({ cartId }) => orderApi.placeOrder(cartId),
  onError: (error) => { console.error(error) },
})($content);
```

### Product details page example

On the product details page, the `PayPalButtons` container builds its own shadow cart from the product details drop-in's <Link href="https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpdata-emits-and-listens" text="pdp/data" /> and <Link href="https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpvalues-emits-and-listens" text="pdp/values" /> events.

<Aside type="note">
  On the product details page, the `PayPalButtons` container supports simple, configurable, bundle, virtual, and downloadable products.
</Aside>

The following example demonstrates how to use the `PayPalButtons` container on a product details page.

```js
import PayPalButtons from '@dropins/storefront-payment-services/containers/PayPalButtons.js';
import { render as PaymentServices } from '@dropins/storefront-payment-services/render.js';
import * as orderApi from '@dropins/storefront-order/api.js';
import { PaymentLocation } from '@dropins/storefront-payment-services/api.js';

const $content = document.createElement('div');
PaymentServices.render(PayPalButtons, {
  location: PaymentLocation.PRODUCT_DETAIL,
  onSuccess: ({ cartId }) => orderApi.placeOrder(cartId),
  onError: (error) => { console.error(error) },
})($content);
```
