## Event details

The following sections provide detailed information about each event, including its direction, event payload, and usage examples.

### `authenticated` (listens)

Fired by the [User Auth](/dropins/user-auth/events/#authenticated-emits) drop-in when the user's authentication state changes. Used to determine whether the shopper is a guest customer.

#### Event payload

```typescript
boolean
```

`true` when the shopper is authenticated, `false` when signed out.

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('authenticated', (isAuthenticated) => {
  console.log('authenticated event received:', isAuthenticated);
});
```

---

### `cart/data` (listens)

Fired by the [Cart](/dropins/cart/events/#cartdata-emits-and-listens) drop-in when cart data is available or changes. Used by various payment method containers to retrieve the cart ID and other cart data at checkout. The event must have fired at least once with a non-null payload before the shopper initiates payment (for example, clicks a payment button).

#### Event payload

```typescript
CartModel | null
```

See [`CartModel`](/dropins/cart/events/#cartmodel) for the full type definition.

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('cart/data', (payload) => {
  console.log('cart/data event received:', payload);
});
```

---

### `checkout/initialized` (listens)

Fired by the [Checkout](/dropins/checkout/events/) drop-in when the checkout page is first loaded. The `GooglePay` container uses this event as a fallback when `checkout/updated` has not yet been received — for example, when the shopper opens the Google Pay payment sheet without having interacted with the checkout form.

#### Event payload

```typescript
CheckoutData | null
```

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('checkout/initialized', (payload) => {
  console.log('checkout/initialized event received:', payload);
});
```

---

### `checkout/updated` (listens)

Fired by the [Checkout](/dropins/checkout/events/#checkoutupdated-emits-and-listens) drop-in when the checkout state is updated. Used by the `GooglePay` container to determine the selected shipping method and billing address when the shopper clicks the Google Pay button. If `checkout/updated` has not yet been received, the container falls back to `checkout/initialized`.

At least one `checkout/updated` or `checkout/initialized` event must have been emitted on the event bus before clicking the Google Pay button.

#### Event payload

```typescript
Cart | NegotiableQuote | null
```

See [`Cart`](/dropins/checkout/events/#cart) and [`NegotiableQuote`](/dropins/checkout/events/#negotiablequote) for the full type definitions.

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('checkout/updated', (payload) => {
  console.log('checkout/updated event received:', payload);
});
```

### `pdp/data` (listens)

Fired by the [Product Details](https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpdata-emits-and-listens) drop-in with product data for the page. The `GooglePay` container listens to this event, together with [`pdp/values`](#pdpvalues-listens), to build a shadow cart when the shopper clicks the Google Pay button on the `PRODUCT_DETAIL` location.

Both events must have been emitted at least once on the event bus before clicking the Google Pay button.

#### Event payload

```typescript
PdpDataModel
```

See [`PdpDataModel`](https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpdata-emits-and-listens) for the full type definition.

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('pdp/data', (payload) => {
  console.log('pdp/data event received:', payload);
});
```

---

### `pdp/values` (listens)

Fired by the [Product Details](https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpvalues-emits-and-listens) drop-in with the shopper's currently selected product SKU, quantity, and options. The `GooglePay` container listens to this event, together with [`pdp/data`](#pdpdata-listens), to build a shadow cart when the shopper clicks the Google Pay button on the `PRODUCT_DETAIL` location.

Both events must have been emitted at least once on the event bus before clicking the Google Pay button.

#### Event payload

```typescript
PdpValuesModel
```

See [`PdpValuesModel`](https://experienceleague.adobe.com/en/tools/commerce-storefront/dropins/product-details/events/#pdpvalues-emits-and-listens) for the full type definition.

#### Example

```js
import { events } from '@dropins/tools/event-bus.js';

events.on('pdp/values', (payload) => {
  console.log('pdp/values event received:', payload);
});
```
