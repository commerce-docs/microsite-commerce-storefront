Drop-ins are pre-built, customizable UI components that provide complete commerce functionality for your storefront. Each drop-in handles a specific aspect of the shopping experience, from browsing products to completing checkout.

<TableWrapper nowrap={[0]}>

| Item | Description |
|------|-------------|
| [Cart](/dropins/cart/) | Provides editable controls to help you view, update, and merge the products in your cart and mini-cart, including image thumbnails, pricing. |
| [Checkout](/dropins/checkout/) | Provides customizable controls to help complete a purchase. |
| [Order](/dropins/order/) | Provides tools to manage and display order-related data across various pages and scenarios. |
| [Payment Services](/dropins/payment-services/) | Renders the credit card form and the Apple Pay button. |
| [Personalization](/dropins/personalization/) | Provides tools to display content conditionally, based on Adobe Commerce customer groups, segments, and cart price rules. |
| [Product Details Page](/dropins/product-details/) | Renders detailed information about your products, including descriptions, specifications, options, pricing, and images. |
| [Product Discovery](/dropins/product-discovery/) | Enables you to display and customize product search results, category listings, and faceted navigation. |
| [Recommendations](/dropins/recommendations/) | Enables you to suggest products to customers based on their browsing patterns and behaviors. |
| [User Account](/dropins/user-account/) | Provides account management features. |
| [User Authentication](/dropins/user-auth/) | Provides user authentication to allow customers to sign up, log in, and log out. |
| [Wishlist](/dropins/wishlist/) | Lets customers store products they are interested in purchasing later. |

</TableWrapper>
