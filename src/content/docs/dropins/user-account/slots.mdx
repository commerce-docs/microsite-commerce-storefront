## Using slots

This example customizes the `AddressFormActions` slot in `AddressForm`:

```js
import { render as provider } from '@dropins/storefront-account/render.js';
import AddressForm from '@dropins/storefront-account/containers/AddressForm.js';

provider.render(AddressForm, {
  slots: {
    AddressFormActions: (ctx) => {
      const div = document.createElement('div');
      div.className = 'address-form__address-form-actions';
      div.textContent = 'Custom AddressFormActions';
      ctx.appendChild(div);
    }
  }
})(document.querySelector('.address-form'));
```
