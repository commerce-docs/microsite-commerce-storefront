User Account containers manage account information, addresses, and order history:

- **Customer Information** displays and edits profile
- **Addresses** and **Address Form** manage addresses
- **Orders List** shows order history
- **Address Validation** ensures accuracy

Integrate containers into account dashboards or profile pages.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [CustomerInformation](/dropins/user-account/containers/customer-information/) | Profile information: name, email, and contact details. |
| [Addresses](/dropins/user-account/containers/addresses/) | Manage shipping and billing addresses. |
| [AddressForm](/dropins/user-account/containers/address-form/) | Add or edit customer addresses. |
| [AddressValidation](/dropins/user-account/containers/address-validation/) | Validate addresses for accurate delivery. |
| [OrdersList](/dropins/user-account/containers/orders-list/) | Order history with details and status. |

</TableWrapper>
