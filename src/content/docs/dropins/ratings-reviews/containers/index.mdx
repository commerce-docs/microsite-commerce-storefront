The Ratings and Reviews drop-in includes three containers. `Review` and `Pagination` work together to show a product's approved reviews, while `WriteReview` lets shoppers submit a new review.

Containers are ready-made UI components that manage how data appears and how the UI responds. Customize them with configuration options (props), [slots](/dropins/ratings-reviews/slots/), and [CSS](/dropins/ratings-reviews/styles/).

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [Review](/dropins/ratings-reviews/containers/review/) | Shows one page of approved reviews with loading, empty, unavailable, and error states. |
| [Pagination](/dropins/ratings-reviews/containers/pagination/) | Shows page controls for the review list and requests other pages. |
| [WriteReview](/dropins/ratings-reviews/containers/write-review/) | Shows a review form with star ratings. Signed-out shoppers see a sign-in prompt when guest reviews are turned off. After submission, shoppers see a message that the review is waiting for approval. |

</TableWrapper>

Call [`getProductReviews`](/dropins/ratings-reviews/functions/#getproductreviews) from your block to load the first page. `Review` and `Pagination` do not make this initial request. Use the same `scope` for both containers and the function so they update from the same [review events](/dropins/ratings-reviews/events/).

<Aside type="tip" title="Average ratings on product pages">
The average rating below the product name comes from the Product Details drop-in's [`ProductRating`](/dropins/product-details/containers/product-rating/) container, not from this drop-in.
</Aside>
