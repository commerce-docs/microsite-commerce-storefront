The Ratings and Reviews drop-in provides two containers that work together to show a product's approved reviews. Containers are pre-built UI components that combine data, state, and presentation. Customize them through props, [slots](/dropins/ratings-reviews/slots/), and [CSS](/dropins/ratings-reviews/styles/).

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [Review](/dropins/ratings-reviews/containers/review/) | Shows one page of approved reviews with loading, empty, unavailable, and error states. |
| [Pagination](/dropins/ratings-reviews/containers/pagination/) | Shows page controls for the review list and requests other pages. |

</TableWrapper>

Neither container fetches the first page. Your block calls [`getProductReviews`](/dropins/ratings-reviews/functions/#getproductreviews), and both containers update from the [events](/dropins/ratings-reviews/events/) it publishes. Give both containers and the function the same `scope` so they share one review list.

<Aside type="tip" title="Average ratings on catalog pages">
The average rating below the product name comes from the Product Details drop-in's [`ProductRating`](/dropins/product-details/containers/product-rating/) container, not from this drop-in.
</Aside>
