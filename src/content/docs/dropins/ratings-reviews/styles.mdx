Customize the review list and page controls with CSS in your Product Reviews block. The drop-in uses design tokens, shared CSS variables such as `--spacing-medium` and `--color-neutral-700`. Changes to these variables carry through to the drop-in's styles. For tokens, breakpoints, and general guidance, see [CSS customization](/dropins/all/styling/).

## Block styles

The Product Reviews block from the [quick start](/dropins/ratings-reviews/quick-start/) uses this stylesheet to control section spacing and hidden states:

```css title="blocks/product-reviews/product-reviews.css"
/* Separates the reviews section from the content above it. */
.product-reviews {
  margin-block-start: var(--spacing-xxbig);
}

/* Keeps the block hidden while reviews are turned off or loading has not started. */
.product-reviews[hidden] {
  display: none;
}

.product-reviews .product-reviews__pagination {
  min-width: 0;
  margin-block: var(--spacing-medium);
}

/* Removes the pagination spacing when there is only one page. */
.product-reviews .product-reviews__pagination:has(.ratingsreviews-pagination[hidden]) {
  display: none;
}
```

- `.product-reviews`: The block wrapper. The block sets its `hidden` attribute until reviews can load.
- `.product-reviews__list`: The element that holds the `Review` container.
- `.product-reviews__pagination`: The element that holds the `Pagination` container. The CSS hides this element when the container is hidden.

## Responsive layout

Review rows respond to the width of the `Review` container, not the browser window. The wrapper defines a CSS container named `ratingsreviews-review`. Container queries apply layout rules based on that width:

- *At least 900 pixels*: Each row places the author in a narrow column beside the review content.
- *Below 900 pixels*: The author appears above the content. This layout also applies in narrow containers, such as a sidebar or modal.

## Customization examples

Add these rules to `blocks/product-reviews/product-reviews.css`.

```css title="blocks/product-reviews/product-reviews.css"
/* Shows the error state in a highlighted panel. */
.product-reviews .ratingsreviews-review[data-state='error'] .ratingsreviews-review__status {
  padding: var(--spacing-small);
  border-radius: var(--shape-border-radius-1);
  background-color: var(--color-alert-200);
}

/* Changes the filled star color. The star fill uses the text color (currentcolor). */
.product-reviews .ratingsreviews-star-rating__fill {
  color: var(--color-brand-500);
}

/* Uses the side-by-side row layout on narrower containers. */
@container ratingsreviews-review (width >= 600px) {
  .product-reviews .ratingsreviews-review-item {
    grid-template-columns: minmax(0, 1fr) minmax(0, 3fr);
  }
}
```

- *Error state*: The `data-state='error'` selector adds padding and a highlighted background to the status message.
- *Star color*: The fill uses `currentcolor`, which takes its value from the CSS `color` property. Changing that property changes the filled star color.
- *Row layout*: The container query starts the side-by-side layout at a container width of 600 pixels instead of the default 900 pixels.

Use your browser's developer tools to inspect the SDK header, divider, and page controls that the containers render.
