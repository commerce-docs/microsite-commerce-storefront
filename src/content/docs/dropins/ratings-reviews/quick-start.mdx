After you complete this quick start, your product pages show a **Reviews** section below the product details. The section lists approved reviews, 20 per page, with page controls when a product has more reviews.

The integration has four parts: the drop-in package, an import map entry, an initializer, and the Product Reviews block. If your storefront already has `scripts/initializers/ratings-reviews.js` and `blocks/product-reviews/`, skip to [Check the result](#check-the-result).

## Before you begin

- Turn on product reviews and approve at least one review in the Admin. See [Before you begin](/dropins/ratings-reviews/#before-you-begin) on the overview page.
- Run your storefront locally. See [Run your storefront locally](/get-started/run-locally/).

## Add the drop-in to your storefront

<Steps>

1. Install the drop-in package from the root of your storefront project.

   ```bash
   # Adds the package to package.json with an exact version.
   npm install @dropins/storefront-ratings-reviews
   # Copies the drop-in files into scripts/__dropins__/ for the browser.
   npm run install:dropins
   ```

   The storefront template disables npm install scripts for security, so `npm run install:dropins` copies the files. After it finishes, the `scripts/__dropins__/storefront-ratings-reviews/` folder exists.

1. In `head.html`, add the drop-in to the existing import map.

   ```html
   <script nonce="aem" type="importmap">
     {
       "imports": {
         "@dropins/storefront-pdp/": "/scripts/__dropins__/storefront-pdp/",
         "@dropins/storefront-ratings-reviews/": "/scripts/__dropins__/storefront-ratings-reviews/",
         "@dropins/storefront-recommendations/": "/scripts/__dropins__/storefront-recommendations/"
       }
     }
   </script>
   ```

   Add only the `@dropins/storefront-ratings-reviews/` line and keep your other entries. The import map lets block code import `@dropins/storefront-ratings-reviews/...` paths.

1. Create the initializer at `scripts/initializers/ratings-reviews.js`.

   ```js
   import { initializers } from '@dropins/tools/initializer.js';
   import { initialize, setEndpoint } from '@dropins/storefront-ratings-reviews/api.js';
   import { initializeDropin } from './index.js';
   import { CORE_FETCH_GRAPHQL, fetchPlaceholders } from '../commerce.js';

   // Loads label overrides from the placeholders/ratings-reviews.json sheet.
   const labels = await fetchPlaceholders('placeholders/ratings-reviews.json');

   await initializeDropin(async () => {
     // Reviews and review settings come from Commerce GraphQL, not Catalog Service.
     setEndpoint(CORE_FETCH_GRAPHQL);

     // Fetches the store's review settings once, then stores them in the drop-in config.
     return initializers.mountImmediately(initialize, {
       langDefinitions: {
         default: { ...labels },
       },
     });
   })();
   ```

   `CORE_FETCH_GRAPHQL` carries your Commerce GraphQL endpoint and store headers. The [initialization](/dropins/ratings-reviews/initialization/) page explains each option.

1. Create the block script at `blocks/product-reviews/product-reviews.js`.

   ```js
   import { config, getProductReviews } from '@dropins/storefront-ratings-reviews/api.js';
   import { render as reviewsRenderer } from '@dropins/storefront-ratings-reviews/render.js';
   import { Review } from '@dropins/storefront-ratings-reviews/containers/Review.js';
   import { Pagination } from '@dropins/storefront-ratings-reviews/containers/Pagination.js';
   import { readBlockConfig } from '../../scripts/aem.js';
   import { getProductSku } from '../../scripts/commerce.js';
   // Runs the initializer before the block reads the review settings.
   import '../../scripts/initializers/ratings-reviews.js';

   export default async function decorate(block) {
     const { sku: authoredSku } = readBlockConfig(block);
     block.replaceChildren();
     block.hidden = true;
     // Keeps the block hidden and skips requests when reviews are turned off.
     if (config.getConfig()?.isProductReviewsEnabled !== true || !block.isConnected) return;
     // An authored sku row wins; otherwise use the SKU of the current product page.
     const sku = authoredSku?.trim() || getProductSku();
     if (!sku) throw new Error('A product SKU is required to display product reviews.');

     // A unique scope keeps this list's events separate from other review lists on the page.
     const scope = `product-reviews-${crypto.randomUUID()}`;
     const fragment = document.createRange().createContextualFragment(`
       <div class="product-reviews__list"></div>
       <div class="product-reviews__pagination"></div>
     `);
     const reviews = fragment.querySelector('.product-reviews__list');
     const pagination = fragment.querySelector('.product-reviews__pagination');
     block.appendChild(fragment);
     block.hidden = false;

     await Promise.all([
       reviewsRenderer.render(Review, { scope })(reviews),
       reviewsRenderer.render(Pagination, { scope })(pagination),
     ]);

     if (!block.isConnected) return;
     // Not awaited, so slow reviews never delay the rest of the page.
     getProductReviews(sku, { pageSize: 20, currentPage: 1, scope }).catch((error) => {
       console.error('[Product Reviews] Failed to load reviews:', error);
     });
   }
   ```

   The containers do not fetch data. `getProductReviews()` publishes [events](/dropins/ratings-reviews/events/), and both containers update from the events for their `scope`. `Pagination` requests later pages by itself.

1. Create the block styles at `blocks/product-reviews/product-reviews.css`.

   ```css
   /* Separates the reviews section from the content above it. */
   .product-reviews {
     margin-block-start: var(--spacing-xxbig);
   }

   /* Keeps the block hidden while reviews are turned off or loading has not started. */
   .product-reviews[hidden] {
     display: none;
   }

   .product-reviews .product-reviews__pagination {
     min-width: 0;
     margin-block: var(--spacing-medium);
   }

   /* Removes the pagination spacing when there is only one page. */
   .product-reviews .product-reviews__pagination:has(.ratingsreviews-pagination[hidden]) {
     display: none;
   }
   ```

1. Place the block on product pages. Choose one option:

   - **Author the block**: Add a Product Reviews block to your product page template or any other page. See [Product Reviews block](/merchants/blocks/product-reviews/).
   - **Add it automatically**: Append the block to product pages that the storefront builds from the page SKU. Follow [Add reviews to product pages automatically](#add-reviews-to-product-pages-automatically).

</Steps>

## Add reviews to product pages automatically

Product pages that the storefront builds from SKU metadata do not have an authored block table. To add reviews to those pages, extend the auto-blocking code that builds the Product Details block.

<Steps>

1. In `scripts/commerce.js`, add a function that appends a Product Reviews section to the page.

   ```js
   /**
    * Appends a product-reviews section unless reviews are already authored.
    * @param {Element} main The main element
    */
   export function buildProductRatingsAndReviews(main) {
     // Respects an authored Product Reviews block, so the page never shows two lists.
     if (main.querySelector('.product-reviews')) return;
     const section = document.createElement('div');
     section.append(buildBlock('product-reviews', { elems: [] }));
     main.append(section);
   }
   ```

   `scripts/commerce.js` already imports `buildBlock` from `./aem.js`.

1. In `scripts/scripts.js`, import the function and call it right after `buildPDPBlock(main)`.

   ```js
   import {
     buildPDPBlock,
     // Add this import next to buildPDPBlock.
     buildProductRatingsAndReviews,
     getProductSku,
     loadCommerceEager,
     loadCommerceLazy,
   } from './commerce.js';

   function buildAutoBlocks(main) {
     try {
       // ...existing auto-blocking code...
       const pdpBlock = document.querySelector('.product-details');
       if (metaSku && !pdpBlock) {
         buildPDPBlock(main);
         // Adds the reviews section at the end of the page.
         buildProductRatingsAndReviews(main);
       }
     } catch (error) {
       console.error('Auto Blocking failed', error);
     }
   }
   ```

   Keep your existing imports and auto-blocking code. Only the two marked additions are new.

</Steps>

This automatic placement applies only when the storefront builds the Product Details block itself. If a page has an authored Product Details block, add the Product Reviews block to that page or template too.

## Check the result

Open a product page for a product with approved reviews.

- You see a **Reviews** heading followed by the reviews.
- Each review shows the reviewer's name, stars or *Not rated*, the date, the title, and the text.
- Products with more than 20 approved reviews show page controls below the list.

If the reviews section does not appear, check these common causes:

<TableWrapper nowrap={[0]}>

| What you see | Likely cause | What to do |
| --- | --- | --- |
| No reviews section and no errors | Product reviews are turned off for the store | Turn on **Product Reviews** in the Admin, then reload the page. |
| Console error `[Ratings Reviews] Failed to fetch store config:` | The initializer could not load review settings, so reviews stay off | Check the Commerce GraphQL endpoint and store headers in your storefront configuration. |
| Console error `A product SKU is required to display product reviews.` | The block could not find a SKU | Add a `sku` row to the authored block, or place the block on a product page. |
| *No reviews on this page.* | The product has no approved reviews | Approve a review in the Admin. |
| *Unable to load reviews.* with a **Try again** button | The `reviews` request failed | Confirm that your Commerce GraphQL endpoint provides the `reviews` query. |

</TableWrapper>

## Quick reference

- **Package**: `@dropins/storefront-ratings-reviews`
- **Initializer**: `import '../../scripts/initializers/ratings-reviews.js';`
- **Containers**: `import { Review } from '@dropins/storefront-ratings-reviews/containers/Review.js';` and `import { Pagination } from '@dropins/storefront-ratings-reviews/containers/Pagination.js';`
- **Provider**: `import { render } from '@dropins/storefront-ratings-reviews/render.js';`
- **API functions**: `import { getProductReviews } from '@dropins/storefront-ratings-reviews/api.js';`
