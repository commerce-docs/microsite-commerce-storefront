Order containers enable customers to view order history, track shipments, and manage returns. These containers provide comprehensive post-purchase experiences:

- **Order Status** and **Shipping Status** show order progress
- **Order Search** helps customers find orders
- **Returns** containers handle return requests
- **Customer Details** and **Cost Summary** display order information

Each container focuses on specific aspects of order management and can be composed for complete order experiences.
