Order containers display order history, shipment tracking, and returns:

- **Order Status** and **Shipping Status** show progress
- **Order Search** finds orders
- **Returns** handle return requests
- **Customer Details** and **Cost Summary** display information

Compose containers for complete order management experiences.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [OrderStatus](/dropins/order/containers/order-status/) | Current status and order details. |
| [OrderSearch](/dropins/order/containers/order-search/) | Search and find order history. |
| [ShippingStatus](/dropins/order/containers/shipping-status/) | Shipping and delivery information with tracking. |
| [CustomerDetails](/dropins/order/containers/customer-details/) | Customer information for the order. |
| [OrderCostSummary](/dropins/order/containers/order-cost-summary/) | Pricing breakdown: subtotal, shipping, taxes, and total. |
| [OrderProductList](/dropins/order/containers/order-product-list/) | Products in order with quantities and pricing. |
| [CreateReturn](/dropins/order/containers/create-return/) | Initiate return requests for eligible items. |
| [ReturnsList](/dropins/order/containers/returns-list/) | Return requests with status and details. |
| [OrderReturns](/dropins/order/containers/order-returns/) | Order returns and refund status. |
| [OrderCancelForm](/dropins/order/containers/order-cancel-form/) | Request order cancellation. |

</TableWrapper>
