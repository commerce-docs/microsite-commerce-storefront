## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/user-auth-dictionary.js"
export const userAuthDictionary = {
  "Auth": {
    "PasswordValidationMessage": {
      "chartTwoSymbols": "Custom string",
      "chartThreeSymbols": "Custom string"
    }
  }
};
```

Then import it in your initializer:

```javascript title="scripts/initializers/user-auth.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-auth';
import { userAuthDictionary } from '../config/dictionaries/user-auth-dictionary.js';

const langDefinitions = {
  default: {
    ...userAuthDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```

**Need more?** See the [Dictionary customization guide](/dropins/all/dictionaries/) for multi-language support and deep-merge behavior, or [Labels](/dropins/all/labeling/) for the boilerplate placeholder system.
