User Auth containers handle authentication, registration, and password management:

- **Sign In** and **Sign Up** authenticate and register customers
- **Reset Password** and **Update Password** manage passwords
- **Auth Combine** unifies authentication interfaces
- **Success Notification** confirms actions

Customize and integrate containers into authentication flows.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [SignIn](/dropins/user-auth/containers/sign-in/) | Login with email and password. |
| [SignUp](/dropins/user-auth/containers/sign-up/) | New customer registration and account creation. |
| [AuthCombine](/dropins/user-auth/containers/auth-combine/) | Unified sign-in and sign-up interface. |
| [ResetPassword](/dropins/user-auth/containers/reset-password/) | Request password reset via email. |
| [UpdatePassword](/dropins/user-auth/containers/update-password/) | Change account password securely. |
| [SuccessNotification](/dropins/user-auth/containers/success-notification/) | Confirmation for successful authentication. |

</TableWrapper>
