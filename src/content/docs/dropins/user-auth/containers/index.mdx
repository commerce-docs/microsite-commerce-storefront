User Auth containers handle customer authentication, registration, and password management. These containers provide complete authentication workflows:

- **Sign In** and **Sign Up** handle authentication and registration
- **Reset Password** and **Update Password** manage password changes
- **Auth Combine** unifies authentication interfaces
- **Success Notification** confirms auth actions

Each container can be customized and integrated into your storefront's authentication flow.
