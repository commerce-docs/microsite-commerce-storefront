Using slots provides the deepest level of customization for drop-in components. Slots are built-in extension points in the drop-in. A slot provides a place in the drop-in component to add your own UI components and functions. This architecture makes it easy to change the default look, layout, and behavior. Let's learn how slots work.

## Big Picture

<Diagram caption="What is a slot?">![What is a slot?](@images/slots/what-is-a-slot.svg)</Diagram>

The following functions are available to all slots:

<Callouts>

1. `prependSibling`: A function to prepend a new HTML element before the slot's content.
1. `prependChild`: A function to prepend a new HTML element to the slot's content.
1. `replaceWith`: A function to replace the slot's content with a new HTML element.
1. `appendChild`: A function to append a new HTML element to the slot's content.
1. `appendSibling`: A function to append a new HTML element after the slot's content.
1. `remove`: A function to remove the slot from the DOM.
1. `getSlotElement`: A function to get a slot element.
1. `onChange`: A function to listen to changes in the slot's context.
1. `dictionary`: JSON Object for the current locale. If the locale changes, the `dictionary` values change to reflect the values for the selected language.

</Callouts>

## Vocabulary

<Vocabulary>

### Container

Component that manages or encapsulates other components. Containers handle logic, fetch data, manage state, and pass data to the UI components that are rendered on the screen.

### Slot

Component that provides placeholders to add other components. You can use a drop-in component's built-in slots to add or remove UI components and functions. Or you can add your own additional slots.

### Component

In web development, this term is overused. That's why we need to be specific about the kind of component we are talking about. Here's a few examples of components from top-to-bottom: a **drop-in component** can contain multiple **container components** that can contain multiple **slot components** that can contain multiple **UI components**.

</Vocabulary>

## Common slots

Several drop-in containers share slot names with compatible signatures, enabling you to create reusable slot implementations that work across multiple drop-ins. The following sections identify these common slots and show you how to leverage them for consistent customization across your storefront.

### Common slots overview

A slot is considered "common" when the same slot name appears in containers from two or more different drop-ins. The following table shows all common slots and where they're used:

<TableWrapper>

| Slot Name | Drop-ins | Containers |
|-----------|----------|------------|
| **Actions** | Cart, Product Details | 2 containers |
| **Content** | Checkout, Product Details | 2 containers |
| **Footer** | Cart, Product Discovery, Recommendations | 4 containers |
| **Heading** | Cart, Checkout, Recommendations | 4 containers |
| **Price** | Cart, Recommendations | 2 containers |
| **Quantity** | Cart, Product Details | 2 containers |
| **Sku** | Cart, Recommendations | 2 containers |
| **SwatchImage** | Cart, Product Details | 2 containers |
| **Thumbnail** | Cart, Recommendations | 5 containers |
| **Title** | Product Details, Recommendations | 2 containers |

</TableWrapper>

### Common slot details

The following sections describe each common slot in detail, including its usage, type signature, and example implementations.

#### Actions

The Actions slot provides action buttons and controls.

**Used in:**
- **Cart**: CartSummaryTable (cart actions)
- **Product Details**: ProductDetails (product actions)

**Type signature:**

```typescript
Actions?: SlotProps<{ /* context varies by drop-in */ }>;
```

#### Content

The Content slot provides generic content area customization.

**Used in:**
- **Checkout**: PlaceOrder
- **Product Details**: ProductDetails (also includes GalleryContent, InfoContent)

**Type signature:**

```typescript
// Checkout
Content?: SlotProps<ContentSlotContext>;

// Product Details
Content?: SlotProps<DefaultSlotContext>;
```

#### Footer

The Footer slot customizes footer content in container sections, often for action buttons or navigation.

**Used in:**
- **Cart**: MiniCart, CartSummaryList
- **Product Discovery**: SearchResults (with search context)
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Cart & Recommendations - Simple footer
Footer?: SlotProps;

// Product Discovery - Footer with search context
Footer?: SlotProps<{ 
  products: Product[]; 
  variables: SearchVariables | null;
}>;
```

**Example implementation:**

```javascript
// Simple footer that works in Cart and Recommendations
provider.render(MiniCart, {
  slots: {
    Footer: (ctx) => {
      const footer = document.createElement('div');
      footer.className = 'custom-footer';
      footer.innerHTML = '<p>Need help? <a href="/support">Contact support</a></p>';
      ctx.appendChild(footer);
    }
  }
});
```

#### Heading

The Heading slot customizes section titles and headers across multiple drop-ins.

**Used in:**
- **Cart**: MiniCart, CartSummaryList  
- **Checkout**: LoginForm (with context)
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Cart & Recommendations - Simple heading
Heading?: SlotProps;

// Checkout - Heading with login context  
Heading?: SlotProps<{ /* login context */ }>;
```

**Example implementation:**

```javascript
// Custom heading that works across drop-ins
const customHeading = (ctx) => {
  const heading = document.createElement('h2');
  heading.className = 'custom-heading';
  heading.textContent = 'Your Cart';
  ctx.replaceWith(heading);
};

// Works in both:
provider.render(MiniCart, {
  slots: { Heading: customHeading }
});

provider.render(ProductList, {
  slots: { Heading: customHeading }
});
```

#### Price

The Price slot customizes price display for cart items and recommended products.

**Used in:**
- **Cart**: CartSummaryTable
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Cart - Price for cart item
Price?: SlotProps<{ 
  item: CartModel['items'][number];
}>;

// Recommendations - Price for product
Price?: SlotProps<{ /* product context */ }>;
```

**Example implementation:**

```javascript
// Custom price display with currency symbol
provider.render(ProductList, {
  slots: {
    Price: (ctx) => {
      const { item } = ctx;
      const price = document.createElement('div');
      price.className = 'custom-price';
      price.innerHTML = `
        <span class="currency">$</span>
        <span class="amount">${item.price.final.amount.value}</span>
      `;
      ctx.replaceWith(price);
    }
  }
});
```

#### Quantity

The Quantity slot customizes quantity selectors in different contexts.

**Used in:**
- **Cart**: CartSummaryTable (cart item quantity management)
- **Product Details**: ProductDetails (product quantity selection)

**Type signature:**

```typescript
// Cart - Quantity with cart context
Quantity?: SlotProps<{ /* cart item quantity management */ }>;

// Product Details - Quantity with product context
Quantity?: SlotProps<DefaultSlotContext>;
```

#### Sku

The Sku slot customizes SKU display for products and cart items.

**Used in:**
- **Cart**: CartSummaryTable
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Cart - SKU for cart item
Sku?: SlotProps<{ 
  item: CartModel['items'][number];
}>;

// Recommendations - SKU for product
Sku?: SlotProps<{ /* product context */ }>;
```

**Example implementation:**

```javascript
// Custom SKU display with label
provider.render(CartSummaryTable, {
  slots: {
    Sku: (ctx) => {
      const { item } = ctx;
      const skuElement = document.createElement('div');
      skuElement.className = 'custom-sku';
      skuElement.innerHTML = `<strong>SKU:</strong> ${item.sku}`;
      ctx.replaceWith(skuElement);
    }
  }
});
```

#### SwatchImage

The SwatchImage slot customizes product option swatch images.

**Used in:**
- **Cart**: GiftOptions
- **Product Details**: ProductOptions

**Type signature:**

```typescript
SwatchImage?: SlotProps<{ /* swatch data */ }>;
```

#### Thumbnail

The Thumbnail slot is the most widely used common slot, appearing in five containers across Cart and Recommendations drop-ins.

**Used in:**
- **Cart**: MiniCart, CartSummaryGrid, CartSummaryList, CartSummaryTable
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Cart - Cart item thumbnail
Thumbnail?: SlotProps<{
  item: CartModel['items'][number];
  defaultImageProps: ImageProps;
}>;

// Recommendations - Product thumbnail  
Thumbnail?: SlotProps<{
  item: any;  // Product type
  defaultImageProps: ImageProps;
}>;
```

**Key insight:** Both signatures provide `item` and `defaultImageProps`, making them highly compatible. The item type differs (cart item vs. product), but the structure remains consistent.

**Example implementation:**

```javascript
// Reusable thumbnail with SKU badge
const customThumbnail = (ctx) => {
  const { item, defaultImageProps } = ctx;
  
  const container = document.createElement('div');
  container.className = 'custom-thumbnail';
  
  const img = document.createElement('img');
  img.src = defaultImageProps.src;
  img.alt = defaultImageProps.alt;
  img.loading = defaultImageProps.loading;
  img.width = defaultImageProps.width;
  img.height = defaultImageProps.height;
  
  const badge = document.createElement('span');
  badge.className = 'sku-badge';
  badge.textContent = item.sku;
  
  container.appendChild(img);
  container.appendChild(badge);
  ctx.replaceWith(container);
};

// Works in both Cart and Recommendations:
provider.render(MiniCart, {
  slots: { Thumbnail: customThumbnail }
});

provider.render(ProductList, {
  slots: { Thumbnail: customThumbnail }
});
```

#### Title

The Title slot customizes product titles in different contexts.

**Used in:**
- **Product Details**: ProductDetails
- **Recommendations**: ProductList

**Type signature:**

```typescript
// Product Details
Title?: SlotProps<DefaultSlotContext>;

// Recommendations - Adds product URL
Title?: SlotProps<{ 
  item: any;
  productUrl: string;
}>;
```

### Best practices for common slots

<Steps>

1. **Start with simple slots**

   Begin your slot customization with Footer and Heading slots. These have the simplest signatures and work across the most drop-ins with minimal adaptation.

2. **Leverage default properties**

   Many common slots provide `defaultImageProps` or similar objects. Use these as a starting point to maintain functionality while customizing the presentation:

   ```javascript
   const { defaultImageProps } = ctx;
   // Use defaultImageProps.src, defaultImageProps.alt, etc.
   ```

3. **Create slot libraries**

   Build a library of reusable slot implementations for your storefront:

   ```javascript
   // slots/thumbnail.js
   export const customThumbnail = (ctx) => { /* ... */ };

   // slots/heading.js  
   export const customHeading = (ctx) => { /* ... */ };
   
   // Use across multiple containers
   import { customThumbnail, customHeading } from './slots';
   ```

4. **Test across drop-ins**

   When creating a common slot implementation, test it in all containers where the slot appears to ensure compatibility.

5. **Handle item type differences**

   For slots like Thumbnail, Price, and Sku, be aware that the `item` type differs between cart items and products. Access properties that exist in both types for maximum reusability.

</Steps>

### Drop-in compatibility

The following shows which drop-ins share the most common slots, indicating strong compatibility for shared slot implementations:

**Cart ↔ Recommendations** (6 shared slots)
- Footer, Heading, Price, Sku, Thumbnail, Title (context compatible)
- **Best candidate** for reusable slot implementations

**Cart ↔ Product Details** (4 shared slots)  
- Actions, Quantity, SwatchImage
- Requires more adaptation due to context differences

**Checkout ↔ Product Details** (2 shared slots)
- Content, Heading
- Moderate adaptation needed
