This container provides a header component for the requisition list view with actions such as rename and delete. It displays the requisition list name and provides quick access to common actions.

## Example

The following example demonstrates how to render the `RequisitionListHeader` container:

```javascript
import { render as provider } from '@dropins/storefront-requisition-list/render.js';
import RequisitionListHeader from '@dropins/storefront-requisition-list/containers/RequisitionListHeader.js';

const requisitionList = {
  uid: 'MQ==',
  name: 'My Requisition List',
  description: 'Description',
  items_count: 5,
  updated_at: '2025-01-01T00:00:00Z',
};

provider.render(RequisitionListHeader, {
  requisitionList,
  routeRequisitionListGrid: () => '/requisition-lists',
  onUpdate: (updatedList) => {
    console.log('Requisition list updated:', updatedList);
  },
  enrichConfigurableProducts: enrichConfigurableProducts,
});
```

## Features

- Display requisition list name
- Rename action
- Delete action with confirmation
- Navigate back to requisition list grid
- Alert notifications for actions
