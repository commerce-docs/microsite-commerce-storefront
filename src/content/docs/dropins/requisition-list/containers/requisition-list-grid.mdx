This container displays and manages multiple requisition lists in a grid layout. It provides functionality to create new requisition lists, rename existing ones, delete lists, and navigate to individual requisition list details.

## Example

The following example demonstrates how to render the `RequisitionListGrid` container:

```javascript
import { render as provider } from '@dropins/storefront-requisition-list/render.js';
import RequisitionListGrid from '@dropins/storefront-requisition-list/containers/RequisitionListGrid.js';

provider.render(RequisitionListGrid, {
  routeRequisitionListDetails: (uid) => `/requisition-lists/${uid}`,
});
```

## Features

- Display all requisition lists in a grid layout
- Create new requisition lists
- Rename existing requisition lists
- Delete requisition lists with confirmation
- Navigate to individual requisition list details
- Pagination support for large numbers of requisition lists
- Empty state when no requisition lists exist
