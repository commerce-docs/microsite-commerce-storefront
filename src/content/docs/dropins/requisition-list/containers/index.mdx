Requisition List containers enable B2B customers to create and manage multiple lists of products for purchasing. The following containers provide the building blocks for complete requisition list experiences.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [RequisitionListGrid](/dropins/requisition-list/containers/requisition-list-grid/) | Display and manage multiple requisition lists in a grid layout. |
| [RequisitionListView](/dropins/requisition-list/containers/requisition-list-view/) | View and manage items within a specific requisition list. |
| [RequisitionListForm](/dropins/requisition-list/containers/requisition-list-form/) | Create or edit requisition list name and description. |
| [RequisitionListHeader](/dropins/requisition-list/containers/requisition-list-header/) | Header component for requisition list view with actions. |
| [RequisitionListSelector](/dropins/requisition-list/containers/requisition-list-selector/) | Select an existing requisition list or create a new one when adding products. |

</TableWrapper>
