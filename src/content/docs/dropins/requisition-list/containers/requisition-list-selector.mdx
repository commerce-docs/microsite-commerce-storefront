This container provides a selector interface for choosing an existing requisition list or creating a new one when adding products. It's typically used on product detail pages or in product listing contexts.

<Diagram caption="RequisitionListSelector container">
  ![RequisitionListSelector container](@images/dropins/requisition-list/requisition-list-selector.png)
</Diagram>

## Configurations

The `RequisitionListSelector` container provides the following configuration options:

<OptionsTable
compact
    options={[
        ['Options', 'Type', 'Req?', 'Description'],
        ['sku', 'string', 'Yes', 'The SKU of the product to add to the requisition list.'],
        ['selectedOptions', 'Array<string>', 'No', 'Array of selected option UIDs for configurable products.'],
        ['quantity', 'number', 'No', 'Quantity of the product to add. Defaults to 1.'],
        ['canCreate', 'boolean', 'No', 'Whether the user can create a new requisition list. Defaults to true.'],
        ['beforeAddProdToReqList', 'function', 'No', 'Callback function called before adding the product to the requisition list. Can be used for validation or other pre-processing.'],
    ]}
/>

## Example

The following example demonstrates how to render the `RequisitionListSelector` container:

```javascript
import { render as provider } from '@dropins/storefront-requisition-list/render.js';
import RequisitionListSelector from '@dropins/storefront-requisition-list/containers/RequisitionListSelector.js';

provider.render(RequisitionListSelector, {
  sku: 'product-sku',
  quantity: 1,
  selectedOptions: ['option-uid-1'],
  canCreate: true,
  beforeAddProdToReqList: async () => {
    // Perform any validation or pre-processing
    console.log('Adding product to requisition list...');
  },
});
```

## Features

- Display list of existing requisition lists
- Select an existing requisition list to add products to
- Create a new requisition list option
- Add products to selected requisition list
- Alert notifications for success and error states
