This container provides a form for creating new requisition lists or updating existing ones. It includes validation for the requisition list name and supports optional descriptions.

<Diagram caption="RequisitionListForm container">
  ![RequisitionListForm container](@images/dropins/requisition-list/requisition-list-form.png)
</Diagram>

## Configurations

The `RequisitionListForm` container provides the following configuration options:

<OptionsTable
compact
    options={[
        ['Options', 'Type', 'Req?', 'Description'],
        ['mode', 'string', 'Yes', 'The form mode: "create" or "update".'],
        ['requisitionListUid', 'string', 'No', 'The unique identifier (UID) of the requisition list to update. Required when mode is "update".'],
        ['defaultValues', 'object', 'No', 'Default values for the form fields. Should include "name" and optionally "description".'],
        ['onSuccess', 'function', 'No', 'Callback function called when the form is successfully submitted. Receives the created or updated requisition list.'],
        ['onError', 'function', 'No', 'Callback function called when form submission fails. Receives an error message.'],
        ['onCancel', 'function', 'Yes', 'Callback function called when the user cancels the form.'],
    ]}
/>

## Example

The following example demonstrates how to render the `RequisitionListForm` container:

```javascript
import { render as provider } from '@dropins/storefront-requisition-list/render.js';
import RequisitionListForm from '@dropins/storefront-requisition-list/containers/RequisitionListForm.js';

provider.render(RequisitionListForm, {
  mode: 'create',
  defaultValues: {
    name: '',
    description: '',
  },
  onSuccess: (newList) => {
    console.log('Requisition list created:', newList);
    // Navigate to the new requisition list
  },
  onError: (message) => {
    console.error('Error creating requisition list:', message);
  },
  onCancel: () => {
    // Close the form or navigate away
  },
});
```

## Features

- Create new requisition lists
- Update existing requisition lists
- Form validation for name (required, minimum length, character restrictions)
- Optional description field
- Success and error callbacks
- Cancel functionality
