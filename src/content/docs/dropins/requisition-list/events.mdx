## Event details


### `requisitionList/alert` (emits and listens)

Triggered when an alert or notification is triggered, such as when a requisition list operation succeeds or fails.

#### Event payload

```typescript
RequisitionListAlertPayload | null
```

See [`RequisitionListAlertPayload`](#requisitionlistalertpayload) for full type definition.



#### Usage

```javascript
import { events } from '@dropins/tools/event-bus.js';

const requisitionListAlertListener = events.on('requisitionList/alert', (data) => {
  console.log('requisitionList/alert event received:', data);
  // Add your custom logic here
});

// Later, when you want to stop listening
requisitionListAlertListener.off();
```

### `requisitionList/data` (emits and listens)

Emitted when requisition list data is updated or retrieved. This event is triggered after operations like adding items, removing items, updating quantities, or creating/updating requisition lists.

#### Event payload

```typescript
RequisitionList | null
```

See [`RequisitionList`](#requisitionlist) for full type definition.



#### Usage

```javascript
import { events } from '@dropins/tools/event-bus.js';

const requisitionListDataListener = events.on('requisitionList/data', (data) => {
  console.log('requisitionList/data event received:', data);
  // Add your custom logic here
});

// Later, when you want to stop listening
requisitionListDataListener.off();
```

### `requisitionList/initialized` (emits)

Emitted when the requisition list component completes initialization. This indicates the requisition list is ready to display lists and accept user interactions.

#### Event payload

```typescript
StoreConfigModel | null
```

See [`StoreConfigModel`](#storeconfigmodel) for full type definition.



#### Usage

```javascript
import { events } from '@dropins/tools/event-bus.js';

const requisitionListInitializedListener = events.on('requisitionList/initialized', (data) => {
  console.log('requisitionList/initialized event received:', data);
  // Add your custom logic here
});

// Later, when you want to stop listening
requisitionListInitializedListener.off();
```

### `requisitionLists/data` (emits)

Emitted when the list of requisition lists changes. This event is triggered after operations like creating or deleting requisition lists.

#### Event payload

```typescript
RequisitionList[] | null
```

See [`RequisitionList`](#requisitionlist) for full type definition.



#### Usage

```javascript
import { events } from '@dropins/tools/event-bus.js';

const requisitionListsDataListener = events.on('requisitionLists/data', (data) => {
  console.log('requisitionLists/data event received:', data);
  // Add your custom logic here
});

// Later, when you want to stop listening
requisitionListsDataListener.off();
```

## Data Models

The following data models are used in event payloads for this drop-in.

### RequisitionList

Used in: [`requisitionList/data`](#requisitionlistdata-emits-and-listens), [`requisitionLists/data`](#requisitionlistsdata-emits).

```ts
interface RequisitionList {
  uid: string;
  name: string;
  description?: string;
  items_count: number;
  updated_at: string;
  items: Item[];
  page_info?: PageInfo;
}
```

### RequisitionListAlertPayload

Used in: [`requisitionList/alert`](#requisitionlistalert-emits-and-listens).

```ts
interface RequisitionListAlertPayload {
  action: string;
  message?: string;
  type?: 'success' | 'error' | 'info' | 'warning';
}
```

### StoreConfigModel

Used in: [`requisitionList/initialized`](#requisitionlistinitialized-emits).

```ts
interface StoreConfigModel {
  requisitionListEnabled: boolean;
  requisitionListMaxNumber?: number;
}
```
