## addProductsToRequisitionList

The `addProductsToRequisitionList` function allows you to add products to a requisition list. This function is typically used when a user wants to save products to a requisition list for later purchase. The function calls the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/b2b/requisition-list/" text="addProductsToRequisitionList" /> mutation.

```ts
const addProductsToRequisitionList = async (
  requisitionListUid: string,
  requisitionListItems: Array<RequisitionListItemsInput>
): Promise<RequisitionList | null>
```

<TableWrapper nowrap={[0,1]}

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `requisitionListUid` | `string` | Yes | The unique identifier (UID) of the requisition list to add products to. |
| `requisitionListItems` | `Array<RequisitionListItemsInput>` | Yes | An array of products to add to the requisition list. Each item must include `sku` and `quantity`. For configurable products, include `selected_options` or `entered_options` as needed. |

</TableWrapper>

### Events

## addRequisitionListItemsToCart

The `addRequisitionListItemsToCart` function adds selected items from a requisition list to the cart. This function is useful for bulk adding products from a requisition list to the shopping cart.

```ts
const addRequisitionListItemsToCart = async (
  requisitionListUid: string,
  requisitionListItemUids: Array<string>
): Promise<Array<string> | null>
```

<TableWrapper nowrap={[0,1]}

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `requisitionListUid` | `string` | Yes | The unique identifier (UID) of the requisition list containing the items to add. |
| `requisitionListItemUids` | `Array<string>` | Yes | An array of requisition list item UIDs to add to the cart. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns `Array<string> | null`. Returns `null` if the operation succeeds, and an array with error codes otherwise. Possible error codes are:
- `OUT_OF_STOCK`: One or more products do not have sufficient stock.
- `UNAVAILABLE_SKU`: One or more products were not found.
- `OPTIONS_UPDATED`: One or more products have updated options.
- `LOW_QUANTITY`: One or more products do not have the requested quantity available.
