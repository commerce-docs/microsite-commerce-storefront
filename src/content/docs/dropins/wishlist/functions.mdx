## addProductsToWishlist

The `addProductsToWishlist` function allows you to add products to a user's wishlist. This function is typically used when a user wants to save a product for later purchase. The function calls the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/add-products/" text="addProductsToWishlist" /> mutation.

Pass an optional `wishlistId` to add to a specific list instead of the active (default) one—for example, a separate "Save for Later" list. For an authenticated shopper, `wishlistId` is the server list id; for a guest, it is a reserved local key (such as `save-for-later`). When you omit `wishlistId`, the product is added to the active wishlist.

```ts
const addProductsToWishlist = async (
  items: {
    sku: string;
    quantity: number;
    optionsUIDs?: string[];
    enteredOptions?: { uid: string; value: string }[];
  }[],
  wishlistId?: string,
  options?: { scope?: string }
): Promise<Wishlist | null>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `sku` | `string` | Yes | The product identifier (SKU) for the product. For configurable products (like a shirt available in multiple colors and sizes), use the child product SKU that represents the specific variant selected by the customer (for example, \`MS09-M-Blue\` for a medium blue shirt). |
| `quantity` | `number` | Yes | The number of items. This value must be a positive number. |
| `optionsUIDs` | `string[]` | No | An array of option UIDs for configurable products—the selected options (such as color or size) that identify the variant. Use the product query to retrieve available option UIDs for a product. |
| `wishlistId` | `string` | No | Target a specific list instead of the active one. Omit it to add to the active wishlist. |
| `options.scope` | `string` | No | Event channel to broadcast the updated list on, so a container rendered with the same `scope` refreshes. See [Render an additional wishlist](/dropins/wishlist/tutorials/render-additional-wishlist/). |

</TableWrapper>

### Events

When you omit `wishlistId`, emits the [`wishlist/data`](/dropins/wishlist/events/#wishlistdata-emits-and-listens) event for the active wishlist. When you target a specific list with `wishlistId`, the active-list event is not emitted; instead, if you pass `options.scope`, the updated list is broadcast on that scope so a matching container refreshes.

### Returns

Returns [`Wishlist`](#wishlist) or `null`. When targeting a specific list, returns that list's updated data.

## createWishlist

The `createWishlist` function creates an additional named wishlist beyond the shopper's default one, using the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/create-wishlist/" text="createWishlist" /> mutation. Use it to provision an extra list that lives alongside the shopper's normal wishlist.

<Aside type="note">
Multiple wishlists must be enabled for the store. Creating a list fails if it would exceed the configured maximum number of wishlists.
</Aside>

```ts
type WishlistVisibility = 'PUBLIC' | 'PRIVATE';

const createWishlist = async (
  name: string,
  visibility?: WishlistVisibility
): Promise<Wishlist | null>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `name` | `string` | Yes | The name of the wishlist to create. Use this same name to find and reuse the list later (for example, with [`getWishlists`](#getwishlists)). |
| `visibility` | `WishlistVisibility` | No | `PRIVATE` (default) or `PUBLIC`. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns the created [`Wishlist`](#wishlist), or `null`.

## getWishlistById

The `getWishlistById` function returns a customer's wishlist by ID, using the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer/" text="customer" /> query, with the contents defined by the `wishlist_v2` object.

Pass an optional `scope` to broadcast the result on a dedicated event channel, so a container rendered with the same `scope` can display this list without disturbing the shopper's active wishlist. See [Render an additional wishlist](/dropins/wishlist/tutorials/render-additional-wishlist/).

```ts
const getWishlistById = async (
  wishlistId: string,
  pageSize?: number,
  currentPage?: number,
  options?: { scope?: string }
): Promise<void | Wishlist | null>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `wishlistId` | `string` | Yes | The unique identifier of the wishlist to retrieve. For a guest, this is the reserved local key of the list. |
| `pageSize` | `number` | No | Number of items per page. |
| `currentPage` | `number` | No | The page of items to retrieve. |
| `options.scope` | `string` | No | Event channel to broadcast the result on. When set, the `wishlist/data` event is scoped to this channel instead of the active wishlist's. |

</TableWrapper>

### Events

Emits the [`wishlist/data`](/dropins/wishlist/events/#wishlistdata-emits-and-listens) event with the retrieved wishlist. When `options.scope` is set, the event is broadcast on that scope so it does not overwrite the active wishlist.

### Returns

Returns `void | Wishlist | null`. See [`Wishlist`](#wishlist).

## mergeWishlists

The `mergeWishlists` function allows you to merge a wishlist from local storage with one belonging to a registered user. This is useful when a user wants to synchronize both local and remote wishlists into one wishlist after logging in.

Pass an optional `listKey` to merge a specific guest list (stored under that key) instead of the default guest wishlist—for example, the guest "Save for Later" list. Items are deduplicated by SKU and selected options.

```ts
const mergeWishlists = async (
  wishlist: Wishlist,
  listKey?: string
): Promise<Wishlist | null>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `wishlist` | [`Wishlist`](#wishlist) | Yes | The registered user's server wishlist to merge the local items into. |
| `listKey` | `string` | No | The local-storage key of the guest list to merge. Omit it to merge the default guest wishlist. |

</TableWrapper>

### Events

Emits the [`wishlist/data`](/dropins/wishlist/events/#wishlistdata-emits-and-listens) event with the merged wishlist information.

### Returns

Returns [`Wishlist`](#wishlist) or `null`.

## removeProductsFromWishlist

The `removeProductsFromWishlist` function allows you to remove products from a user's wishlist. The function calls the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/remove-products/" text="removeProductsFromWishlist" /> mutation.

Pass an optional `wishlistId` to remove from a specific list instead of the active one. When you omit it, products are removed from the active wishlist.

```ts
const removeProductsFromWishlist = async (
  items: Array<Item>,
  wishlistId?: string,
  options?: { scope?: string }
): Promise<Wishlist | null>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `items` | `Array<Item>` | Yes | An array of wishlist item identifiers to remove from the wishlist. |
| `wishlistId` | `string` | No | Target a specific list instead of the active one. Omit it to remove from the active wishlist. |
| `options.scope` | `string` | No | Event channel to broadcast the updated list on, so a container rendered with the same `scope` refreshes. See [Render an additional wishlist](/dropins/wishlist/tutorials/render-additional-wishlist/). |

</TableWrapper>

### Events

When you omit `wishlistId`, emits the [`wishlist/data`](/dropins/wishlist/events/#wishlistdata-emits-and-listens) event for the active wishlist. When you target a guest list with `wishlistId` and pass `options.scope`, the updated list is broadcast on that scope. Removals from an authenticated specific list are non-emitting; refresh that container yourself (the drop-in `Wishlist` container does this page-aware when given a `wishlistId`).

### Returns

Returns [`Wishlist`](#wishlist) or `null`. When targeting a specific list, returns that list's updated data.

## updateProductsInWishlist

The `updateProductsInWishlist` function allows you to update the quantity of products in a user's wishlist. The function calls the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/update-products/" text="updateProductsInWishlist" /> mutation.

```ts
const updateProductsInWishlist = async (
  items: { wishlistItemId: string; quantity: number; description: string; selectedOptions?: string[]; enteredOptions?: { uid: string; value: string }[]; }[]
): Promise<Wishlist | null>
```

<TableWrapper nowrap={[0]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `wishlistItemId` | `string` | Yes | The unique identifier of the wishlist item to update. This ID is returned in the wishlist data structure when you retrieve a wishlist (not the product SKU). Each item in a wishlist has its own unique ID, even if multiple items reference the same product. |
| `quantity` | `number` | Yes | The new quantity for the item. This replaces the current quantity (it does not increment). For example, setting this to \`2\` will change the quantity to 2, regardless of the previous value. This value must be a positive number. |
| `description` | `string` | Yes | A text description. |
| `selectedOptions` | `string[]` | No | An array of option UIDs to update the selected product options for configurable products. For example, if a customer wants to change the size from \*\*Medium\*\* to \*\*Large\*\*, you would provide the UID for the Large option. These are the same type of option UIDs used when selecting product options. |
| `enteredOptions` | `{ uid: string; value: string }[]` | No | An array of custom options that allow text input for customizable products. Each object contains a \`uid\` (the unique identifier for the custom option field from the product data) and a \`value\` (the text the customer entered). These are typically used for personalization like engravings or custom messages. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns [`Wishlist`](#wishlist) or `null`.

## Data Models

The following data models are used by functions in this drop-in.

### StoreConfigModel

The `StoreConfigModel` object is returned by the following functions: [`getStoreConfig`](#getstoreconfig).

```ts
interface StoreConfigModel {
  wishlistIsEnabled: boolean;
  wishlistMaxNumber: number;
  wishlistMultipleListIsEnabled: boolean;
}
```

### Wishlist

The `Wishlist` object is returned by the following functions: [`addProductsToWishlist`](#addproductstowishlist), [`createWishlist`](#createwishlist), [`getWishlistById`](#getwishlistbyid), [`getWishlists`](#getwishlists), [`initializeWishlist`](#initializewishlist), [`mergeWishlists`](#mergewishlists), [`removeProductsFromWishlist`](#removeproductsfromwishlist), [`resetWishlist`](#resetwishlist), [`updateProductsInWishlist`](#updateproductsinwishlist).

```ts
interface Wishlist {
  id: string;
  name?: string;
  updated_at: string;
  sharing_code: string;
  items_count: number;
  items: Item[];
}
```
