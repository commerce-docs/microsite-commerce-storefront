## addProductsToWishlist

The `addProductsToWishlist` function allows you to add products to a user's wishlist.
This function is typically used when a user wants to save a product for later purchase.

### Example usage

### Signature

```ts
export const addProductsToWishlist = async (
  items: [
    {
      sku: string;
      quantity: number;
      optionsUIDs?: string[]; // should be the options available for the product
      enteredOptions?: { uid: string; value: string }[]; // refer to both selected and entered options
    }
  ]
): Promise<Wishlist | null>
```

### Usage

### Add Simple Product to Wishlist

```js
addProductsToWishlist(
    [{
        sku: 'VA19-GO-NA',
        quantity: 1
    }]
);
```

### Add Configurable Product to Wishlist

```js
addProductsToWishlist(
    [{
        sku: 'VSW01',
        quantity: 1,
        optionsUIDs: [
            'Y29uZmlndXJhYmxlLzE1Ny8zMQ==',
            'Y29uZmlndXJhYmxlLzE5MC80NA=='
        ]
    }]
);
```

### Add Bundle Product to Wishlist
```js
addProductsToWishlist(
    [{
        sku: 'VA24',
        quantity: 1,
        optionsUIDs: [
          'YnVuZGxlLzEvMS8x',
          'YnVuZGxlLzIvMy8x',
          'YnVuZGxlLzMvNS8x',
          'YnVuZGxlLzQvNy8x'
        ]
    }]
);
```
