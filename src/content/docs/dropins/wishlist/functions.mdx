## addProductsToWishlist

The `addProductsToWishlist` function allows you to add products to a user's wishlist. This function is typically used when a user wants to save a product for later purchase.

```ts
const addProductsToWishlist = async (
  items: [
    {
      sku: string;
      quantity: number;
      optionsUIDs?: string[]; // should be the options available for the product
      enteredOptions?: { uid: string; value: string }[]; // refer to both selected and entered options

  ]
): Promise<Wishlist | null>
```
