## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/product-details-dictionary.js"
export const productDetailsDictionary = {
  "PDP": {
    "Product": {
      "Incrementer": {
        "label": "Custom string"
      },
      "OutOfStock": {
        "label": "Custom string"
      }
    }
  }
};
```

Then import it in your initializer:

```javascript title="scripts/initializers/product-details.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-pdp';
import { productDetailsDictionary } from '../config/dictionaries/product-details-dictionary.js';

const langDefinitions = {
  default: {
    ...productDetailsDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
