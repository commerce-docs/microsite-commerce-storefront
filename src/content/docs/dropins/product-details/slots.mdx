## Using slots

This example customizes the `Attributes` slot in `ProductAttributes`:

```js
import { render as provider } from '@dropins/storefront-pdp/render.js';
import ProductAttributes from '@dropins/storefront-pdp/containers/ProductAttributes.js';

provider.render(ProductAttributes, {
  slots: {
    Attributes: (ctx) => {
      const div = document.createElement('div');
      div.className = 'product-attributes__attributes';
      div.textContent = 'Custom Attributes';
      ctx.appendChild(div);
    }
  }
})(document.querySelector('.product-attributes'));
```
