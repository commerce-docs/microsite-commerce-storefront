The `ProductPrice` container displays the price of a product on the product details page. It includes special prices, regular prices, and tier pricing if they are available and visible.

The container receives initial product data during [initialization](/dropins/product-details/initialization/) to preload the component and, being event-driven, updates with data emitted to `pdp/data` within the event scope.

## Tier pricing

The `ProductPrice` container automatically displays tier pricing information when available in the product data. Tier pricing shows quantity-based discounts, encouraging customers to purchase larger quantities for better per-unit prices.

When a product has tier pricing configured, the container displays each tier below the main price in the following format:

> Buy \{quantity\} for \{price\} each and save \{percent\}%

For example:
- Buy 5 for $15.00 each and save 25%
- Buy 10 for $13.00 each and save 35%

The tier pricing is retrieved from the `tiers` field on the product's price data, which includes:
- `tier.amount`: The discounted price per unit at this tier
- `tier.currency`: The currency code
- `quantity`: The minimum quantity required to receive this tier price

The savings percentage is calculated automatically by comparing the tier price to the regular product price.

## Example

The following example demonstrates how to configure the `ProductPrice` container:

```js
return productRenderer.render(ProductPrice, {
  scope: 'modal', // optional
});
```
