Product Details containers display product information, images, pricing, and purchase options. The following containers provide the building blocks for complete product detail pages.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [ProductGallery](/dropins/product-details/containers/product-gallery/) | Product images and media with zoom, thumbnails, and navigation. |
| [ProductHeader](/dropins/product-details/containers/product-header/) | Product name, SKU, and key identifiers. |
| [ProductPrice](/dropins/product-details/containers/product-price/) | Pricing including special prices, tier pricing, and discounts. |
| [ProductDescription](/dropins/product-details/containers/product-description/) | Full product descriptions with rich content. |
| [ProductShortDescription](/dropins/product-details/containers/product-short-description/) | Concise product summary for quick overview. |
| [ProductOptions](/dropins/product-details/containers/product-options/) | Select variants like size, color, and configurable options. |
| [ProductQuantity](/dropins/product-details/containers/product-quantity/) | Quantity selector for adding to cart. |
| [ProductAttributes](/dropins/product-details/containers/product-attributes/) | Specifications, technical details, and attributes. |
| [ProductGiftCardOptions](/dropins/product-details/containers/product-giftcard-options/) | Customize gift cards with amounts and messages. |

</TableWrapper>
