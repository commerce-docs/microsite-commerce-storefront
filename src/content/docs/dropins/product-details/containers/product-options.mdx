The `ProductOptions` container manages and displays product options on the product details page.

The container receives initial product data during [initialization](/dropins/product-details/initialization/) to preload the component and, being event-driven, updates with data emitted to `pdp/data` within the event scope.

## ProductOptions configurations

The `ProductOptions` container provides the following configuration options:

<OptionsTable
  compact
  options={[
    ['Option', 'Type', 'Req?', 'Description'],
    ['hideSelectedValue', 'boolean', 'No', 'Hides the selected value of the option.'],
    ['onValues', 'function', 'No', 'A callback function that receives the selected option UIDs.'],
    ['onErrors', 'function', 'No', 'A callback function that receives any errors encountered during option selection.'],
    ['slots', 'object', 'No', 'An object containing slot overrides for the Swatches component.'],
    ['scope', 'string', 'No', 'Unique identifier for the PDP context. Only containers rendered with this scope will respond to product events.'],
  ]}
/>

## Example

The following example demonstrates how to configure the `ProductOptions` container:

```js
return productRenderer.render(ProductOptions, {
  hideSelectedValue: false,
  onValues: (optionsUIDs) => {
    console.log('Selected options:', optionsUIDs);
  },
  onErrors: (errors) => {
    console.error('Option errors:', errors);
  },
});
```

## Slots

The `ProductOptions` container provides the following slots for customization:

### Swatches

The `Swatches` slot allows you to customize or extend the entire product options/swatches UI.

**Slot context:**

<OptionsTable
  compact
  options={[
    ['Property', 'Type', 'Description'],
    ['data', 'ProductModel | null', 'The current product data containing options and other product information.'],
    ['optionsUIDs', 'string[]', 'Array of currently selected option UIDs.'],
  ]}
/>

**Example:**

```js
return productRenderer.render(ProductOptions, {
  slots: {
    Swatches: (ctx) => {
      const size = ctx.getSlotElement('product-swatch--fashion_size');

      // Add link to Sizes
      if (size) {
        // Create Size Link
        const link = document.createElement('a');
        link.href = '#';
        link.addEventListener('click', (e) => {
          e.preventDefault();
          console.log('Size Chart');
        });
        // append inside size
        size.appendChild(link);
      }
    },
  },
});
```

### SwatchImage

The `SwatchImage` slot allows you to customize how swatch images are rendered for image-based options.

**Slot context:**

<OptionsTable
  compact
  options={[
    ['Property', 'Type', 'Description'],
    ['data', 'ProductModel | null', 'The current product data containing options and other product information.'],
    ['optionsUIDs', 'string[]', 'Array of currently selected option UIDs.'],
    ['defaultImageProps', 'ImageProps', 'Default image properties including src, alt, width, height, and other image attributes.'],
    ['imageSwatchContext', 'ImageNodeRenderProps["imageSwatchContext"]', 'Context object containing information about the specific image swatch being rendered.'],
  ]}
/>

**Example:**

```js
return productRenderer.render(ProductOptions, {
  slots: {
    SwatchImage: (ctx) => `
      <div class="custom-swatch-image">
        <img 
          src="${ctx.defaultImageProps.src}" 
          alt="${ctx.defaultImageProps.alt}"
          width="${ctx.defaultImageProps.width}"
          height="${ctx.defaultImageProps.height}"
        />
      </div>
    `,
  },
});
```
