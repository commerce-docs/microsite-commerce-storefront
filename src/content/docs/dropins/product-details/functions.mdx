## getProductsData

The `getProductsData` function fetches multiple products by their SKUs in a single request. Each item can include optional configuration such as selected option UIDs and a flag to pre-select the first available option. Useful for bulk product data retrieval, such as in Quick Order or product list pages.

```ts

  items: ProductDataItem[],
```

## getRefinedProduct

The `getRefinedProduct` function returns refined product data with specific options selected. This is used for configurable products where options have been chosen. The function calls the <Link href="https://developer.adobe.com/commerce/webapi/graphql/schema/catalog-service/queries/refine-product" text="refineProduct" /> query.

For configurable products, the returned [`ProductModel`](#productmodel) always keeps the parent product’s `name` and `sku`. When refinement resolves to a simple variant (`SimpleProductView`), the model also includes `variantSku` and `variantName` for that variant so you can display or forward the child SKU and title (for example from the [`ProductHeader`](/dropins/product-details/containers/product-header/) container).

```ts

  sku: string,
  optionUIDs: string[],
```

## isSubscribedStockAlert

The `isSubscribedStockAlert` function checks whether the currently authenticated shopper is subscribed to a back-in-stock alert for a given SKU. Use it to render the correct state of a "Notify me" control on the product details page. This is typically paired with [`subscribeStockAlert`](#subscribestockalert).

<Aside type="note">
Stock alerts require an authenticated shopper and the product alerts feature to be enabled in the Commerce backend. This function is served by Commerce Core, so the drop-in must be pointed at the Commerce Core GraphQL endpoint.
</Aside>

```ts
interface IsSubscribedStockAlertResult {
  isSubscribed: boolean;
  message?: string;
}

const isSubscribedStockAlert = async (
  sku: string
): Promise<IsSubscribedStockAlertResult>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `sku` | `string` | Yes | The SKU of the product to check the subscription status for. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns a `Promise<IsSubscribedStockAlertResult>` with `isSubscribed` set to `true` when the shopper is already subscribed.

## subscribeStockAlert

The `subscribeStockAlert` function subscribes the currently authenticated shopper to a back-in-stock alert for a given SKU. The shopper is notified when the product is available again. Use [`isSubscribedStockAlert`](#issubscribedstockalert) first to determine whether the shopper is already subscribed. For a complete example, see [Add a "Notify me" CTA](/dropins/product-details/tutorials/notify-me-cta/).

<Aside type="note">
Stock alerts require an authenticated shopper and the product alerts feature to be enabled in the Commerce backend. This function is served by Commerce Core, so the drop-in must be pointed at the Commerce Core GraphQL endpoint.
</Aside>

```ts
interface SubscribeStockAlertResult {
  success: boolean;
  message?: string;
}

const subscribeStockAlert = async (
  sku: string
): Promise<SubscribeStockAlertResult>
```

<TableWrapper nowrap={[0,1]}>

| Parameter | Type | Req? | Description |
|---|---|---|---|
| `sku` | `string` | Yes | The SKU of the product to subscribe to. |

</TableWrapper>

### Events

Does not emit any drop-in events.

### Returns

Returns a `Promise<SubscribeStockAlertResult>`. On success, `success` is `true` and `message` contains the confirmation text. The promise rejects when the subscription cannot be created.
