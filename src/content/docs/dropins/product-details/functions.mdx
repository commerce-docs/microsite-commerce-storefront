## getFetchedProductData

It uses the Adobe Commerce event bus to either return the most recent `pdp/data` event payload immediately, or wait for the next event if none exists.

### Signature

```ts
getFetchedProductData(options?: { scope?: string }): Promise<ProductModel | null>
```

### Usage

### Basic Usage

```ts
// Get product data from the default scope
const productData = await getFetchedProductData();

if (productData) {
  console.log('Product name:', productData.name);
  console.log('SKU:', productData.sku);
  console.log('Price:', productData.prices.final.amount);
}
```

### With Scope

```ts
// Get product data from a specific scope
const productData = await getFetchedProductData({ scope: 'quickview' });

if (productData) {
  // Use the product data
  renderProductDetails(productData);
}
```

## setProductConfigurationValues

It uses a callback pattern to determine the new configuration state based on the previous state, then emits a `pdp/values` event with the updated values.

### Signature

```ts
setProductConfigurationValues(
  callback: (prev: ValuesModel) => ValuesModel,
  options?: { scope?: string }
): void
```

### Usage

### Basic Usage

```ts
// Set a specific quantity
setProductConfigurationValues((prev) => ({
  ...prev,
  quantity: 2
}));

// Set a specific SKU
setProductConfigurationValues((prev) => ({
  ...prev,
  sku: 'ABC-123'
}));
```

### Update Multiple Values

```ts
// Update multiple configuration values
setProductConfigurationValues((prev) => ({
  ...prev,
  sku: 'XYZ-789',
  quantity: 5,
  optionsUIDs: ['option1', 'option2']
}));
```

### Conditional Updates

```ts
// Update based on some condition
setProductConfigurationValues((prev) => {
  if (prev.quantity > 10) {
    return { ...prev, quantity: 10 };
  }
  return prev;
});
```

### With Scope

```ts
// Set configuration values for a specific scope
setProductConfigurationValues(
  (prev) => ({ ...prev, quantity: 3 }),
  { scope: 'quickview' }
);
```
