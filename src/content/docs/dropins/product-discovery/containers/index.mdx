Product Discovery containers display search results, category listings, and product listing pages. The following containers provide the building blocks for complete search and discovery experiences.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [SearchResults](/dropins/product-discovery/containers/search-results/) | Product search results with configurable layouts and product information. |
| [Facets](/dropins/product-discovery/containers/facets/) | Filtering options to refine search results by attributes and categories. |
| [SortBy](/dropins/product-discovery/containers/sort-by/) | Sort product results by price, name, relevance, and other criteria. |
| [Pagination](/dropins/product-discovery/containers/pagination/) | Navigate multiple pages of product results with pagination controls. |

</TableWrapper>
