## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/product-discovery-dictionary.js"
export const productDiscoveryDictionary = {
  "Search": {
    "PLP": {
      "noResults": "Custom string",
      "searchError": "Custom string"
    }
  }
};
```

Then import it in your initializer:

```javascript title="scripts/initializers/product-discovery.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-product-discovery';
import { productDiscoveryDictionary } from '../config/dictionaries/product-discovery-dictionary.js';

const langDefinitions = {
  default: {
    ...productDiscoveryDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
