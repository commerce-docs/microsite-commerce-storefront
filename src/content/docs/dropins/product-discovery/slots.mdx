Use Product Discovery slots to add content to a container or replace part of its UI. For example, you can change a filter label or add a star rating below a product name. Each slot receives a context object, `ctx`, with data and methods for changing its content. For methods shared by all slots, see [Extending drop-in components](/dropins/all/extending/).

The basic examples append a text label to show where each slot appears. They keep the default slot content. Replace the sample text with your own content. In each example, `block` is the element passed to your storefront block's `decorate` function. Add the code to your existing `provider.render()` call rather than rendering the same container twice.

<TableWrapper nowrap={[0]}>

| Container | Slots |
|-----------|-------|
| [`Facets`](#facets-slots) | `Facet`, `FacetHeading`, `SelectedFacets`, `Facets`, `FacetBucket`, `FacetBucketLabel` |
| [`SearchResults`](#searchresults-slots) | `ProductActions`, `ProductPrice`, `ProductName`, `ProductImage`, `NoResults`, `Header`, `Footer` |

</TableWrapper>

<Aside type="tip" title="Update slot content safely">
Create an element and add it with `ctx.appendChild()` when the slot mounts. To update that element inside `ctx.onChange()`, use standard DOM methods instead of calling slot methods again. See [Slots best practices](/dropins/all/slots/#best-practice-for-dynamic-slot-content) for an example.
</Aside>

## Facets slots

The `Facets` container displays search filters, such as color and price. Use its slots to customize a filter group, an individual option, or the selected filters.

```typescript
interface FacetsProps {
  slots?: {
    Facet?: SlotProps<{ data: SearchFacet }>;
    FacetHeading?: SlotProps<{ data: SearchFacet }>;
    SelectedFacets?: SlotProps<{ data: SearchFacet[] }>;
    Facets?: SlotProps<{ data: SearchFacet[] }>;
    FacetBucket?: SlotProps<{ data: FacetBucket }>;
    FacetBucketLabel?: SlotProps<{ data: FacetBucket }>;
  };
}
```

### Facet slot

Use `Facet` to customize one filter group, including its heading and options. `ctx.data` contains the group's `SearchFacet` data.

#### Example

```js title="blocks/product-list-page/product-list-page.js"
import { render as provider } from '@dropins/storefront-product-discovery/render.js';
import { Facets } from '@dropins/storefront-product-discovery/containers/Facets.js';

await provider.render(Facets, {
  slots: {
    Facet: (ctx) => {
      // Keep the existing filter controls and append content after them.
      const element = document.createElement('div');
      element.innerText = 'Custom Facet';
      ctx.appendChild(element);
    }
  }
})(block);
```

## SearchResults slots

Use `SearchResults` slots to customize product cards, content above or below the results, and messages when no results are available.

The product card slots share `SlotDefaultContext`. Read the current product from `ctx.product` and the search parameters from `ctx.variables`. `ProductImage` also provides `ctx.defaultImageProps` with the default image settings. `Header` and `Footer` receive the full product array in `ctx.products` instead of a single product.

```typescript
type SlotDefaultContext = {
  product: Product;
  variables: SearchVariables | null;
};

interface SearchResultsProps {
  slots?: {
    ProductActions?: SlotProps<SlotDefaultContext>;
    ProductPrice?: SlotProps<SlotDefaultContext>;
    ProductName?: SlotProps<SlotDefaultContext>;
    ProductImage?: SlotProps<SlotDefaultContext & { defaultImageProps: ImageProps }>;
    NoResults?: SlotProps<{ error: string | null; variables: SearchVariables | null }>;
    Header?: SlotProps<{ products: Product[]; variables: SearchVariables | null }>;
    Footer?: SlotProps<{ products: Product[]; variables: SearchVariables | null }>;
  };
}
```

### ProductActions slot

Use `ProductActions` to add actions to each product card. `ctx.product` contains the product for that card.

#### Example

```js title="blocks/product-list-page/product-list-page.js"
import { render as provider } from '@dropins/storefront-product-discovery/render.js';
import { SearchResults } from '@dropins/storefront-product-discovery/containers/SearchResults.js';
```

### Show star ratings on product cards

Use the `ProductName` slot to add an average star rating and approved review count below each product name. The following example renders the rating with the SDK `StarRating` component, with text such as *4.5 (12)*. This is a customization, not behavior included in the default product listing block.

<Aside type="note" title="SDK requirement">
Use this example only with an SDK build that exports `StarRating` from `@dropins/tools/components.js`.
</Aside>

The rating comes from two Catalog Service product attributes:

- `ac_rating_summary`: The average rating on a scale from `0` to `100`. Divide it by 20 to get a rating from `0` to `5` stars.
- `ac_review_count`: The number of approved reviews.

Both attributes must be enabled for product listings. This setting is off by default. If cards show no ratings, follow [Catalog attributes](/dropins/ratings-reviews/#catalog-attributes) to enable it. For how review data reaches the catalog, see the [Ratings and Reviews overview](/dropins/ratings-reviews/#how-it-works).

```js title="blocks/product-list-page/product-list-page.js"
import { render as provider } from '@dropins/storefront-product-discovery/render.js';
import SearchResults from '@dropins/storefront-product-discovery/containers/SearchResults.js';
import { StarRating, provider as UI } from '@dropins/tools/components.js';

// ac_rating_summary is a 0-100 percentage; products without ac_review_count get no rating.
const getReviewSummary = (product) => {
  const getValue = (name) => product.attributes?.find((attr) => attr.name === name)?.value;
  const reviewCount = Number.parseInt(getValue('ac_review_count'), 10);
  if (!Number.isSafeInteger(reviewCount) || reviewCount < 0) return null;

  // Converts the percentage to a 0-5 star value and keeps it in range.
  const rating = Math.min(Math.max(Number(getValue('ac_rating_summary')) / 20 || 0, 0), 5);
  const $rating = document.createElement('div');
  $rating.className = 'product-discovery-product-rating';
  // Renders, for example, five stars followed by "4.5 (12)".
  UI.render(StarRating, {
    rating,
    reviewCount,
    showCount: true,
    valueDisplay: 'value',
    countDisplay: 'parentheses',
  })($rating);
  return $rating;
};

await provider.render(SearchResults, {
  slots: {
    ProductName: (ctx) => {
      const $rating = getReviewSummary(ctx.product);
      // Keeps the default product name and adds the rating after it.
      if ($rating) ctx.appendChild($rating);
    },
  },
})(block);
```

The example:

- Reads the rating attributes from `ctx.product`.
- Converts the average rating to a value from `0` to `5` and keeps it within that range.
- Keeps the default product name and appends the rating after it.

Products without a valid `ac_review_count` show no rating. A product whose count is `0` shows the *No reviews* label instead of a numeric rating and count. To hide ratings for those products too, return `null` when `reviewCount` is less than `1`.

Add these rules to `blocks/product-list-page/product-list-page.css` to size the stars for product cards:

```css title="blocks/product-list-page/product-list-page.css"
/* Adds space between the product name and the rating. */
.block.product-list-page .product-discovery-product-rating {
  margin-block-start: var(--spacing-xxsmall);
}

/* Uses smaller stars on product cards. */
.block.product-list-page .product-discovery-product-rating .dropin-star-rating__star svg {
  height: 16px;
  width: 16px;
}
```

The first rule adds space above the rating. The second sizes the star icons to 16 pixels.

```js title="blocks/product-list-page/product-list-page.js"
      ctx.appendChild(element);
    }
  }
})(block);
```
