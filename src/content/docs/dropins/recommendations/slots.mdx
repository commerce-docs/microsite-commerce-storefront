## Using slots

This example customizes the `Heading` slot in `ProductList`:

```js
import { render as provider } from '@dropins/storefront-recommendations/render.js';
import ProductList from '@dropins/storefront-recommendations/containers/ProductList.js';

provider.render(ProductList, {
  slots: {
    Heading: (ctx) => {
      const div = document.createElement('div');
      div.className = 'product-list__heading';
      div.textContent = 'Custom Heading';
      ctx.appendChild(div);
    }
  }
})(document.querySelector('.product-list'));
```
