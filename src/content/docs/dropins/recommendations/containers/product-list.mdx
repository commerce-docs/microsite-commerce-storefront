The `ProductList` container manages and displays a list of recommended products based on the current product. Its behavior is driven by configuration options such as `currentSku`, `pageType`, and `routing` through `routeProduct` callbacks.

</Diagram>

## Configurations

The `ProductList` container provides the following configuration options:

  options={[

    ['userPurchaseHistory', 'array', 'No', 'User Purchase History for recommendation context.'],
    ['userViewHistory', 'array', 'No', 'User View History for recommendation context.'],
    ['routeProduct', 'function', 'No', 'Callback function that returns a product URL.'],
    ['pageType', 'function', 'No', 'Page type where recommendations are rendered (e.g., Product, Cateogy, Cart)'],
    ['hideHeading', 'function', 'No', 'Hide recommendations heading text.'],
    ['slots', 'function', 'No', 'Slots for default heading, thumbnail, price, and footer.'],
  ]}
/>

The `RecommendationUnitModel` object has the following shape:

```js
export interface RecommendationUnitModel {
  displayOrder: number;
  pageType: PageType;
  title: string;
  items: Item[];
  totalProducts: number;
  typeId: string;
  unitId: string;
  unitName: string;
}

export type PageType = 'CMS' | 'Cart' | 'Checkout' | 'Product';

export interface Item {
  uid: string;
  sku: string;
  name: string;
  urlKey: string;
  images: ItemImage[];
  price: FinalPrice;
  priceRange?: {
    minimum?: FinalPrice;
    maximum?: FinalPrice;
  };
  visibility: string;
  queryType: string;
  itemType: string;
}

interface ItemImage {
  label: string;
  roles: string[];
  url: string;
}

export interface Price {
  value: number | null;
  currency: string | null;
}

export interface FinalPrice {
  final?: {
    amount?: Price;
  };
}

export interface RecommendationsResponse {
  results: RecommendationUnitModel[];
  totalResults: number;
}

export interface GraphQLResponse {
  errors?: Array<{ message: string }>;
  data?: {
    recommendations: RecommendationsResponse;
  };
}

```
## Supported Slots

The `Recommendations` container supports the following slots:

* Heading
* Footer
* Title
* SKU
* Price
* Thumbnail
* Action Button (Add To Cart / View Product)
