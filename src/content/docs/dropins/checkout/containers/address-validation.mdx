The `AddressValidation` container displays a suggested shipping address (for example, returned by a third‑party address verification service) alongside the currently entered address, and lets the shopper choose which one to use.

Typical usage is to invoke this container from a modal during the place‑order flow after you call your own address verification service.

## AddressValidation configurations

The `AddressValidation` container provides the following configuration options:

  compact
  options={[
    ['Option', 'Type', 'Req?', 'Description'],
    ['suggestedAddress', 'CartAddressInput | null', 'No', 'Address suggestion to present to the shopper.'],
    ['handleSelectedAddress', 'function', 'No', 'Async callback fired when the shopper selects an address. Receives the selection and the chosen address.'],
  ]}
/>

### AddressValidationProps interface

The `AddressValidation` container receives an object that implements the following interface:

```ts
interface AddressValidationProps {
  suggestedAddress: Partial<CartAddressInput> | null;
  handleSelectedAddress?: (payload: {
    selection: 'suggested' | 'original';
    address: CartAddressInput | null | undefined;
  }) => void;
}
```

- `suggestedAddress` is the normalized address to propose to the shopper.
- `handleSelectedAddress` is called when the shopper chooses either the suggested or original address. Use it to persist the selection or continue the checkout flow.

## CartAddressInput type

The `CartAddressInput` type used by this container has the following shape:

```ts
interface CartAddressInput {
  city: string;
  countryCode: string;
  postcode: string;
  region: string;
  street: string[];
}
```

<Aside type="tip" title="Get the current address">
The container automatically listens to checkout events and maps the current shipping address into a `CartAddressInput`. You only need to pass the `suggestedAddress` when you have one.
</Aside>

<Aside type="note" title="Normalization">
Ensure your address verification service output is transformed to `CartAddressInput` (fields such as `street`, `city`, `region`, `countryCode` or `postcode`) before passing it to the container. If a property is not provided, the default data from the original address will be used.
</Aside>
