## Usage

The following example demonstrates how to use the `PurchaseOrder` container:

```js
import { render as provider } from '@dropins/storefront-checkout/render.js';
import { PurchaseOrder } from '@dropins/storefront-checkout/containers/PurchaseOrder.js';

await provider.render(PurchaseOrder, {
```
