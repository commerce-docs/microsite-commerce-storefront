## How to customize

Override any keys above by creating a custom dictionary file:

```javascript title="scripts/config/dictionaries/checkout-dictionary.js"
export const checkoutDictionary = {
  "Checkout": {
    "AddressValidation": {
      "title": "Custom string",
      "subtitle": "Custom string"
    }
  }
};
```

Then import it in your initializer:

```javascript title="scripts/initializers/checkout.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-checkout';
import { checkoutDictionary } from '../config/dictionaries/checkout-dictionary.js';

const langDefinitions = {
  default: {
    ...checkoutDictionary,
  },
};

await initializers.mountImmediately(initialize, { langDefinitions });
```
