Cart containers display shopping cart information, pricing summaries, and cart management features. These modular components enable you to build complete cart experiences:

- **MiniCart** shows a compact cart preview
- **Cart Summary** variants display cart contents in different layouts
- **Order Summary** shows pricing and totals
- **Empty Cart** provides messaging when cart is empty
- **Estimate Shipping**, **Coupons**, **Gift Cards**, and **Gift Options** extend cart functionality

Each container can be used independently or composed together to create your desired cart experience.
