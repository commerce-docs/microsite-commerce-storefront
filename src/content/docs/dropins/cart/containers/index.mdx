Cart containers display shopping cart information, pricing, and management features. The following containers provide the building blocks for complete cart experiences.

<TableWrapper nowrap={[0]}>

| Container | Description |
|-----------|-------------|
| [CartSummaryGrid](/dropins/cart/containers/cart-summary-grid/) | Cart items in responsive grid layout with images and details. |
| [CartSummaryList](/dropins/cart/containers/cart-summary-list/) | Cart items in vertical list with detailed product information. |
| [CartSummaryTable](/dropins/cart/containers/cart-summary-table/) | Cart items in table with columns for details, quantity, and pricing. |
| [Coupons](/dropins/cart/containers/coupons/) | Apply promotional codes and discount coupons. |
| [EmptyCart](/dropins/cart/containers/empty-cart/) | Messaging and call-to-action when cart is empty. |
| [EstimateShipping](/dropins/cart/containers/estimate-shipping/) | Estimate shipping costs by destination. |
| [GiftCards](/dropins/cart/containers/gift-cards/) | Apply gift cards as payment method. |
| [GiftOptions](/dropins/cart/containers/gift-options/) | Add gift messages, wrapping, and gift options. |
| [MiniCart](/dropins/cart/containers/minicart/) | Compact cart preview with product count and cart access. |
| [OrderSummary](/dropins/cart/containers/order-summary/) | Order totals including subtotal, taxes, shipping, and discounts. |
| [OrderSummaryLine](/dropins/cart/containers/order-summary-line/) | Individual line items for order summary like shipping and tax. |

</TableWrapper>
