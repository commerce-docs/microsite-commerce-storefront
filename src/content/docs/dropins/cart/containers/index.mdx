Cart containers display shopping cart information, pricing, and management features:

- **MiniCart** shows compact cart preview
- **Cart Summary** displays cart contents in grid, list, or table layouts
- **Order Summary** shows pricing and totals
- **Empty Cart** displays when cart is empty
- **Estimate Shipping**, **Coupons**, **Gift Cards**, and **Gift Options** extend functionality

Use containers independently or compose them for complete cart experiences.
