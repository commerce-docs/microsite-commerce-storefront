Use Universal Editor and AEM Cloud Service translation workflows to translate your storefront content—including page content, drop-in labels, and UI text—into multiple languages. This guide shows you how to create and manage localized versions of your storefront content using AEM Cloud Service translation projects.

<Aside type="note" title="What this guide covers">

This guide shows you how to translate content using Universal Editor and AEM Cloud Service translation workflows, including:
- Page content (product descriptions, marketing copy, landing pages)
- Drop-in labels (placeholder JSON files like `cart.json`, `checkout.json`, `pdp.json`)
- Content blocks and components managed in AEM Cloud Service

**Before translating**, complete the [multistore setup](/setup/configuration/multistore-setup/) to create the folder structure, configure store views, and set up currency and headers. Then use this guide to translate the content in those folders.

</Aside>

<Aside type="tip" title="Choosing your authoring tool">

This guide covers localization workflows for Universal Editor and AEM Cloud Service. If you're using Document Authoring Tool (da.live) instead, see [Localization (Document Authoring Tool)](/merchants/multistore/content-localization/) for the da.live Translation app workflow.

</Aside>

## Big picture

Universal Editor provides in-context editing capabilities for content managed in AEM Cloud Service. When localizing content with Universal Editor, you work directly with pages and components in the Universal Editor interface, and translations are managed through AEM Cloud Service translation workflows.

The localization process involves:

1. **Content Authoring**: Create and edit content in Universal Editor
2. **Translation Project Creation**: Set up translation projects in AEM Cloud Service
3. **Translation Workflow**: Use AEM Cloud Service translation services to translate content
4. **Content Publishing**: Publish translated content to Edge Delivery Services
5. **Verification**: Review and verify translated content in Universal Editor

<Aside type="caution" title="Workflow verification needed">

The specific workflow steps for Universal Editor localization with Edge Delivery Services may vary based on your AEM Cloud Service configuration and integration setup. This guide provides general guidance based on standard AEM Cloud Service translation workflows. Verify these steps with your implementation team or Adobe support to ensure accuracy for your specific setup.

</Aside>

## Step-by-step

These steps describe how to translate the default English store to another language. In this example, we will translate the default English store to French (`fr`).

<Tasks>

<Task>
### Access content in Universal Editor

<Steps>
1. Open your storefront in Universal Editor by navigating to the page URL and activating Universal Editor mode.
1. Identify the content pages and components that need translation.
1. Note the structure of your content, including:
   - Page content and blocks
   - Placeholder JSON files location (typically in `placeholders` folders)
   - Content components that contain translatable text

</Steps>

<Aside type="note">

Universal Editor allows you to edit content directly on the rendered page. For translation workflows, you may need to access the AEM Cloud Service authoring interface to manage translation projects, depending on your configuration.

</Aside>

</Task>

<Task>
### Create language copies or translation projects

<Steps>
1. In AEM Cloud Service, navigate to your storefront content structure.
1. Select the pages or content you want to translate.
1. Choose one of the following approaches:
   - **Create Language Copy**: Use AEM's language copy feature to create language-specific versions of your content
   - **Translation Project**: Create a translation project to manage the translation workflow
1. If creating a language copy:
   - Right-click the content and select **Create** → **Language Copy**
   - Select the target language(s)
   - Choose whether to create the structure only or include translations
1. If creating a translation project:
   - Navigate to **Tools** → **General** → **Translation Projects**
   - Select **Create** → **Translation Project**
   - Follow the project creation wizard

</Steps>

</Task>

<Task>
### Translate content using AEM Cloud Service translation workflows

<Steps>
1. If using a translation project, add content to the project:
   - Open the translation project
   - Select **Add** → **Pages** or **Add** → **Assets**
   - Browse and select the content items to translate
   - Include placeholder JSON files if they need translation
1. Configure translation settings:
   - Select translation method (machine translation, human translation, or no translation)
   - Choose translation service provider if using machine translation
   - Set up translation workflows and reviewers if using human translation
1. Start the translation process:
   - Review the content items and target languages
   - Select **Start** to begin translation
   - Monitor progress in the translation project dashboard

</Steps>

<Aside type="note">

AEM Cloud Service supports multiple translation service providers including Microsoft Translator, Google Cloud Translation, and custom translation connectors. The specific services available depend on your organization's configuration. For more information, see [AEM Cloud Service Translation and Localization](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/sites/administering/reusing-content/translation/overview).

</Aside>

</Task>

<Task>
### Review and edit translations in Universal Editor

<Steps>
1. Once translations are available, open the translated content in Universal Editor.
1. Review translated pages and components directly in the Universal Editor interface.
1. Make edits directly in Universal Editor if translations need correction:
   - Click on text elements to edit them
   - Use Universal Editor's in-context editing to update translations
   - Save changes as you work
1. For translation projects, approve or reject translations in the project dashboard.
1. Request revisions for translations that need changes.

</Steps>

<Aside type="note">

Universal Editor's in-context editing allows you to see exactly how translated content will appear to users, making it easier to verify translations and make adjustments. This is a key advantage over document-based editing workflows.

</Aside>

</Task>

<Task>
### Publish translated content

<Steps>
1. After reviewing and approving translations, publish the translated content.
1. The publishing process depends on your AEM Cloud Service configuration:
   - Content may automatically sync to Edge Delivery Services
   - You may need to manually trigger publishing workflows
   - Publishing may occur through AEM Cloud Service publishing workflows
1. Verify that translated content appears in the correct Edge Delivery Services folder structure:
   - Check that content is in the correct locale folders (e.g., `/fr/` for French)
   - Verify placeholder JSON files are updated in localized `placeholders` folders
   - Ensure folder structure matches your multistore configuration

</Steps>

<Aside type="note">

The integration between AEM Cloud Service and Edge Delivery Services varies by implementation. Consult your implementation team or Adobe support to understand the specific publishing workflow for your setup. The translated content should align with the folder structure defined in your [multistore setup](/setup/configuration/multistore-setup/).

</Aside>

</Task>

<Task>
### Verify translated content

<Steps>
1. Preview the translated storefront in the target language.
1. Open translated pages in Universal Editor to verify content displays correctly.
1. Check that placeholder JSON files contain translated labels.
1. Test navigation and functionality in the localized version.
1. Make any final adjustments using Universal Editor's editing capabilities.

</Steps>

</Task>

</Tasks>

## Differences from Document Authoring Tool workflow

The Universal Editor localization workflow differs from the Document Authoring Tool (da.live) workflow in several ways:

- **Translation Project Management**: Universal Editor uses AEM Cloud Service translation projects, which provide more advanced workflow management and integration with professional translation services.
- **Content Authoring**: Content is authored and edited directly in Universal Editor rather than in document-based files.
- **Translation Services**: AEM Cloud Service supports enterprise translation service connectors, providing more options for translation workflows.
- **Workflow Integration**: Translation workflows integrate with AEM Cloud Service publishing workflows and can be part of larger content management processes.

## Best practices

- **Consistency**: Use translation memory and glossaries to maintain consistency across translations.
- **Review Process**: Establish a review workflow for translated content before publishing.
- **Folder Structure**: Ensure translated content follows the multistore folder structure (`/en/`, `/fr_ca/`, etc.).
- **Placeholder Files**: Remember to translate placeholder JSON files (`cart.json`, `checkout.json`, `pdp.json`) for complete localization.
- **Testing**: Test translated content in the target locale before going live.

## Troubleshooting

- **Content Not Syncing**: Verify that your AEM Cloud Service integration with Edge Delivery Services is properly configured.
- **Missing Translations**: Check that all content items were added to the translation project.
- **Folder Structure Issues**: Ensure that translated content is published to the correct folder structure matching your multistore configuration.
- **Translation Quality**: Review machine translations and consider human translation for critical content.
