The Universal Editor lets you edit storefront content directly on the rendered page in DA.live — click any element and change it in context.

<Steps>

1. Open your storefront page in [DA.live](https://da.live).
2. Select the **Open in-context editing** button from the toolbar.
3. Click any element on the rendered page to edit text, images, or blocks in context.
4. Use **Sidekick** to preview and publish your changes.

</Steps>
