<Aside type="caution" title="Deprecation notice">
Adobe Commerce no longer onboards new customers onto the Universal Editor. For new storefronts, use [Experience Workspace](/merchants/quick-start/experience-workspace/) instead.

If you already author with the Universal Editor, your project continues to work and this page covers your workflow.
</Aside>

The Universal Editor lets you edit storefront content in the context of the rendered page. Your edits save back into your Document Authoring (DA.live) project, where you can use content orchestration apps such as localization, bulk publish, and Snapshots.

The Universal Editor workflow applies to all Commerce backends, including Platform as a Service (PaaS), Adobe Commerce as a Cloud Service, and Adobe Commerce Optimizer. See the Resources section for setup, workflow steps, and reference.

## Prerequisite

Your storefront must be set up and content initialized in DA.live. See [Create a storefront](/get-started/create-storefront/) for the setup process and <Link href="https://docs.da.live/" text="DA.live documentation" /> to learn the DA.live interface.
