The Universal Editor (UE) lets you edit storefront content directly on the rendered page.

## Prerequisite

Your storefront must be set up and content initialized in DA.live. See [Create a storefront](/get-started/create-storefront/) for the setup process and [DA.live documentation](https://docs.da.live/) to learn the DA.live interface.
