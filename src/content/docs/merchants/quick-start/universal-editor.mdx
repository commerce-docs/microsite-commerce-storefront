The Universal Editor lets you edit storefront content in the context of the rendered page. The content is then saved into your Document Authoring (DA.live) project where you can use most content orchestration apps, such as localization, bulk publish, Snapshots, and more.

The Universal Editor workflow applies to all Commerce backends, including Platform as a Service (PaaS), Adobe Commerce as a Cloud Service, and Adobe Commerce Optimizer. See the Resources section below for setup, workflow steps, and reference.

## Prerequisite

Your storefront must be set up and content initialized in DA.live. See [Create a storefront](/get-started/create-storefront/) for the setup process and <Link href={"https://docs.da.live/"} text={"DA.live documentation"} /> to learn the DA.live interface.
