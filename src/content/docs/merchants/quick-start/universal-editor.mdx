The Universal Editor (UE) lets you edit storefront content directly on the rendered page in Document Authoring (DA.live). The same UE workflow applies to all Commerce backends (Platform as a Service (PaaS), Adobe Commerce as a Cloud Service, Adobe Commerce Optimizer). See the Resources section below for setup, workflow steps, eligibility, and known limitations.

<Aside type="note" title="Prerequisite">
Your storefront must be set up and the content initialized in DA.live. See [Create a storefront](/get-started/create-storefront/) if you have not completed the setup.
</Aside>
