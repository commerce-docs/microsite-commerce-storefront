The [Universal Editor](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/sites/authoring/universal-editor/authoring) enables visual, in-context editing of your storefront content directly on the rendered page. You can edit text, images, blocks, and commerce components with immediate feedback.

<Aside type="note" title="Universal Editor support">
The Commerce boilerplate instrumentation for Universal Editor is still being updated. Not all blocks may be fully supported yet. For the latest support status, see the [boilerplate releases](/releases/changelog/).
</Aside>

## Prerequisites

- Your storefront is created and configured (see [Create a storefront](/get-started/create-storefront/)).
- For the full Universal Editor experience: Your storefront is configured for [AEM Sites authoring](https://www.aem.live/docs/publishing-from-authoring).
- For Document Authoring sites: The [Visual Editor](/merchants/quick-start/visual-editor/) provides a subset of Universal Editor features.

## Choosing your authoring approach

| Approach | Best for | Universal Editor support |
|----------|----------|---------------------------|
| **AEM Sites authoring** | Full Universal Editor with AEM as content source | Full support |
| **Document Authoring (da.live)** | Simpler setup, document-based content | [Visual Editor](/merchants/quick-start/visual-editor/) provides a subset of features |

## Using Universal Editor with AEM Sites

<Steps>

1. **Configure AEM Sites authoring**: Ensure your storefront is set up for [AEM Sites authoring](https://www.aem.live/docs/publishing-from-authoring). This enables the full Universal Editor experience with AEM as the content source.

2. **Open your storefront in Universal Editor**: Navigate to your storefront page URL in the Universal Editor. You can edit text, images, blocks, and commerce components directly on the rendered page with immediate feedback.

3. **Edit content in context**: Click any editable element to modify it. Changes are reflected immediately. Use the Universal Editor interface to manage blocks, configure commerce components, and update page structure.

</Steps>

## Using Visual Editor with Document Authoring

If you use Document Authoring (da.live) instead of AEM Sites, the [Visual Editor](/merchants/quick-start/visual-editor/) provides a subset of Universal Editor features for editing content hosted on da.live. See [Using the Visual Editor](/merchants/quick-start/visual-editor/) for details.
