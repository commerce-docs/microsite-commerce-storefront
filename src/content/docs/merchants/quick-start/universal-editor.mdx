In an existing Universal Editor project, you can edit storefront content while viewing the page as shoppers see it. The editor saves your changes to Document Authoring (DA.live). You can then use Document Authoring tools for translation, scheduling, and publishing.

<Aside type="note" title="Universal Editor remains supported">
Adobe continues to support existing Universal Editor customers and projects already being built with it. Customers who signed Commerce licenses based on Universal Editor features also remain supported.

You can continue your work and move to Experience Workspace on your own timeline.

For new storefronts, use [Experience Workspace](/merchants/quick-start/experience-workspace/) instead. For editor differences, see the [visual editing overview](/merchants/quick-start/choose-visual-editor/).
</Aside>
