Visual editing lets you change storefront content while viewing the page as shoppers see it.

## New storefronts use Experience Workspace

<Term>Experience Workspace</Term> is the visual editor for new Commerce projects. Switching editors does not change how the Commerce features on your page work.

Experience Workspace is in early access and is fully supported for Commerce authoring. The editor is still evolving, so its interface labels and settings can change. Adobe Experience Manager lists it as <Link href="https://www.aem.live/docs/ew/da-is-ew" text="Early-Access Technology" />.

## Existing Universal Editor projects remain supported

<Aside type="note" title="Support policy">
Adobe continues to support the following customers and projects:

- Customers already using the Universal Editor
- Projects already being built with the Universal Editor
- Customers who signed Commerce licenses based on Universal Editor features

You can continue your work and move to Experience Workspace on your own timeline.
</Aside>

## What changes when you move

Before moving an existing Universal Editor project to Experience Workspace, compare these capabilities:

<TableWrapper>

| Capability | Universal Editor (deprecated) | Experience Workspace |
| --- | --- | --- |
| Content source | Document Authoring (DA.live) | Document Authoring (DA.live) |
| Edit content while viewing the storefront page | Yes | Yes |
| Content blocks and Commerce blocks | Yes | Yes |
| Layout, Content, and Split editing modes | — | Yes |
| Tools for translation, scheduling, and publishing | Yes | Yes |
| Commerce systems: platform as a service (PaaS), Adobe Commerce as a Cloud Service, Adobe Commerce Optimizer | Yes | Yes |
| License | Requires an Adobe Experience Manager license | Included with your Commerce storefront on Document Authoring |

</TableWrapper>

For current features and setup instructions, see <Link href="https://www.aem.live/docs/ew/about" text="About Experience Workspace" /> before planning your move.
