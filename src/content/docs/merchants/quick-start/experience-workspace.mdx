<Term>Experience Workspace</Term> is a visual editor for Document Authoring (DA.live) projects. It lets you edit text and images directly on a storefront page's rendered preview or live URL, without opening the underlying document. You see your changes in context, on the same layout shoppers see.

Adobe now recommends Experience Workspace as the default visual editor for new Document Authoring projects, and it includes an integrated AI assistant alongside the canvas for drafting and editing content. See <Link href={"https://www.aem.live/docs/ew/about"} text={"About Experience Workspace"} /> for a full overview of its capabilities and configuration flags.

<Aside type="note" title="Early access">
Experience Workspace is in early access and continues to evolve. This page is also under development and will be updated with full usage instructions specific to the Commerce Storefront.
</Aside>

<Aside type="caution" title="Universal Editor deprecated for DA.live">
The Universal Editor in combination with da.live is no longer supported for new projects, though projects already using it keep their access. Adobe recommends Experience Workspace instead.
</Aside>

## How to use Experience Workspace

Set up your storefront and initialize content in DA.live before you begin. See [Create a storefront](/get-started/create-storefront/) for the setup process.

<Steps>

1. Open a page in your Document Authoring project in edit view, not the folder view.

1. Enable Experience Workspace using one of the following options:

   - Select the toggle for the new authoring experience. This is reversible; use the same toggle to switch back at any time.
   - Use <Link href="https://da.live/app/adobe-rnd/ew-extensions/tools/ew-setup/ew-setup" text="this tool" /> to set Experience Workspace as the default editor for your organization.

</Steps>

DA.live applies Experience Workspace to every folder in your organization once you enable it.

For general DA.live documentation, see <Link href={"https://docs.da.live/"} text={"DA.live documentation"} />.
