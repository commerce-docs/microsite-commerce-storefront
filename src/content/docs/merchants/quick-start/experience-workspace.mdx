<Term>Experience Workspace</Term> lets you edit text and images directly on a storefront page's rendered preview or live URL, without opening the underlying document. Adobe now recommends Experience Workspace as the default visual editor for new Document Authoring (DA.live) projects.

## Prerequisite

Your storefront must be set up and content initialized in DA.live. See [Create a storefront](/get-started/create-storefront/) for the setup process.

## Enable Experience Workspace

<Steps>

1. Open a page in your Document Authoring project in edit view, not the folder view.
1. Select the toggle for the new authoring experience.

</Steps>

DA.live applies Experience Workspace to every folder in your organization once you enable it. Use the same toggle to switch back to the previous authoring experience at any time.

## Experience Workspace and the Universal Editor

The Universal Editor in combination with da.live is no longer supported for new projects; Adobe recommends Experience Workspace instead. Projects already using the Universal Editor with DA.live keep their access.

This does not affect the Universal Editor for AEM Sites Authoring projects, which remains the recommended editor for that path. See [Using the Universal Editor](/merchants/quick-start/universal-editor/) for the AEM Sites Authoring workflow.
