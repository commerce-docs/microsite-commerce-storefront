Use <Term>Experience Workspace</Term> to edit storefront content while viewing the page as shoppers see it. It is an Adobe Experience Manager (AEM) authoring tool for content stored in Document Authoring (DA.live).

You can edit the same content and Commerce block tables you use in the document editor. Switching editors does not change how the Commerce features on your page work.

<Aside type="note" title="Experience Workspace is fully supported">
Adobe supports Experience Workspace for Commerce authoring, including during early access. It is the visual editor for new Commerce projects.

The editor is still evolving, so its interface labels, settings, and behavior can change. Try it on a test page first to get familiar with the editor.

For support details for existing Universal Editor projects, see the [visual editing overview](/merchants/quick-start/choose-visual-editor/).
</Aside>

## Before you begin

Before enabling Experience Workspace, check that you can open, preview, and publish a page in the document editor.

If your storefront is not set up yet, see [Create a storefront](/get-started/create-storefront/). If you're unsure which authoring tool it uses, check with your development team.

## Enable Experience Workspace for your storefront

Open a page in Document Authoring and turn on the Experience Workspace toggle in the upper-right corner. You can also use the <Link href="https://da.live/app/adobe-rnd/ew-extensions/tools/ew-setup/ew-setup" text="Enable Experience Workspace" /> tool.

For manual setup, configuration flags, and Sidekick settings, your team can follow <Link href="https://www.aem.live/docs/ew/about#setup" text="Experience Workspace setup" />, or ask in the <Link href="https://discord.gg/aem-live" text="AEM Discord community" /> if setup does not work as described.
