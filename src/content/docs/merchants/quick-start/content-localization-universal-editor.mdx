<Aside type="caution" title="Not the recommended path for Commerce Storefront">
The Universal Editor in combination with da.live is no longer supported for new projects; Adobe recommends [Experience Workspace](/merchants/quick-start/experience-workspace/) for Document Authoring projects instead. For Commerce-specific localization on Document Authoring, see [Localization (Document Authoring Tool)](/merchants/quick-start/content-localization/).
</Aside>

This localization workflow applies to **AEM Sites Authoring** projects — content authored in AEM as a Cloud Service and published to Edge Delivery Services. Commerce Storefront's own boilerplate does not use this path; for AEM Sites Authoring, use the <Link href="https://github.com/adobe-rnd/aem-boilerplate-xcom" text="xcom boilerplate" /> instead.
