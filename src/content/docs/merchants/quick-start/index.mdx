As an author, you bring together page content and shopping features in your team's Adobe Commerce storefront. Your first goal is to create a test page, preview it, and publish it.

## Where you work

Manage your team's page content in Document Authoring (DA.live). Open Experience Workspace from DA.live to edit pages.

<Diagram
  adaptColors
  caption="Authors manage page content while developers maintain the storefront code."
>
  ![Authors edit storefront page content in Experience Workspace, with content managed in DA.live.
  Developers work in a separate storefront repository created from starter
  code.](./images/author-life.png)
</Diagram>

- **Page content:** Edit text, images, and supported block settings without changing the storefront code.
- **Editing views:** Use Experience Workspace's **Layout**, **Content**, or **Split** view to edit the same underlying page content.
- **Code changes:** Developers maintain your project's code for design and shopping behavior, starting from the storefront starter. Ask them for new layout options or shopping behavior.

Share a preview URL for review before publishing to the live storefront. See [Author and developer tasks](/merchants/blocks/author-and-developer-tasks/) for examples of changes you can make and changes that need a developer.

## How you assemble a page

Build a storefront page by combining content blocks for text and media with Commerce blocks for shopping features.

<Diagram
  adaptColors
  caption="Content blocks and Commerce blocks combine to create a storefront page."
>
  ![Text, images, and videos provide content for blocks such as accordions, cards, and columns.
  Content blocks and Commerce blocks are added to storefront
  pages.](./images/author-building-blocks.png)
</Diagram>

- **Content blocks:** Add text, images, and videos in blocks such as accordions, cards, and columns.
- **Commerce blocks:** Add shopping features such as product lists or a cart. Product lists get names and prices from the connected catalog.
- **Block settings:** Choose from the settings and layout options your project already provides.

For a campaign page, combine an authored headline and promotional image with a product list. See [Content and Commerce blocks](/merchants/blocks/content-commerce-blocks/) for the block types and [How a page comes together](/merchants/quick-start/content-model/) for how content and design work together.

## Create your first page

Follow [Create your first commerce page](/how-tos/create-commerce-page/) to build a test category page with metadata and a Commerce block in Document Authoring (DA.live). Preview it to check the content and layout before publishing.
