As an author, you bring together content and Commerce blocks to create storefront pages in Experience Workspace. Document Authoring (DA.live) manages the page content, while your project's code provides the design and shopping features.

## Where you work

Find and manage your team's page content in Document Authoring (DA.live). Use Experience Workspace to edit those pages.

<Diagram
  adaptColors
  caption="Authors manage page content while developers maintain the storefront code."
>
  ![Authors edit storefront page content in Experience Workspace, with content managed in DA.live.
  Developers work in a separate storefront repository created from starter
  code.](./images/author-life.png)
</Diagram>

- **Page content:** Edit text, images, and supported block settings without changing the storefront code.
- **Editing views:** Use Experience Workspace's **Layout**, **Content**, or **Split** view to edit the same underlying page content.
- **Code changes:** Developers maintain your project's code for design and shopping behavior, starting from the storefront starter. Ask them for new layout options or shopping behavior.

See [Author and developer tasks](/merchants/blocks/author-and-developer-tasks/) for examples of changes you can make and changes that need a developer.

## How you assemble a page

You assemble pages from the blocks your project provides. For example, a category page can combine a headline and promotional image with a product list.

<Diagram
  adaptColors
  caption="Content blocks and Commerce blocks combine to create a storefront page."
>
  ![Text, images, and videos provide content for blocks such as accordions, cards, and columns.
  Content blocks and Commerce blocks are added to storefront
  pages.](./images/author-building-blocks.png)
</Diagram>

- **Content blocks:** Add text, images, and videos in blocks such as accordions, cards, and columns.
- **Commerce blocks:** Add shopping features such as product lists or a cart. Product lists get names and prices from the connected catalog.
- **Block settings:** Choose from the settings and layout options your project already provides.

See [Content and Commerce blocks](/merchants/blocks/content-commerce-blocks/) for the block types and [How a page comes together](/merchants/quick-start/content-model/) for how content and design work together.

## Create your first page

- **Get access:** Ask your team for the DA.live link to your storefront's content, editing and preview access, and a folder for your test page.
- **Create and edit a page:** Follow [Create your first commerce page](/how-tos/create-commerce-page/) to add metadata and a Commerce block to your test category page. Make the table edits in Experience Workspace's **Content** view, then preview the result.
