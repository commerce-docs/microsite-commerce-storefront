Create, preview, and publish pages for an Adobe Commerce storefront. Work in your team's existing storefront with Document Authoring (DA.live), the web application for managing page content.

## Your role in the storefront

Experience Workspace is the editor you open in DA.live to view and edit page content. Developers maintain the code that controls the storefront's design and shopping behavior.

<Diagram
  adaptColors
  caption="Edit page content in Experience Workspace and manage it in DA.live. Developers maintain the storefront code separately."
>
  ![Authors edit storefront page content in Experience Workspace, with content managed in DA.live.
  Developers work in a separate storefront repository created from starter
  code.](./images/author-life.png)
</Diagram>

- Edit text, images, and supported block settings without changing the storefront code.
- Use Experience Workspace's Layout, Content, or Split view to edit the same underlying page content.
- Share a preview URL for review before publishing changes to the live storefront.

The starter provides the project's initial code; everyday content changes happen in your project's authoring tools. If a change needs a new layout option or shopping behavior, ask your development team. See [Author and developer tasks](/merchants/blocks/author-and-developer-tasks/) for examples of each role's responsibilities.

## How you assemble a page

A storefront page combines content blocks for text and media with Commerce blocks for shopping features.

<Diagram
  adaptColors
  caption="Combine content blocks for editorial content with Commerce blocks for shopping features on the same page."
>
  ![Text, images, and videos provide content for blocks such as accordions, cards, and columns.
  Content blocks and Commerce blocks are added to storefront
  pages.](./images/author-building-blocks.png)
</Diagram>

- Add text, images, and videos to content blocks such as cards or columns.
- Add Commerce blocks for shopping features such as product lists or a cart.
- Choose from the block settings and layout options your project already provides.

For example, a campaign page can combine a headline and promotional image with a product list. The headline and promotional image are authored content; product names and prices come from the connected catalog.

See [Content and Commerce blocks](/merchants/blocks/content-commerce-blocks/) for the block types and [How a page comes together](/merchants/quick-start/content-model/) for how content and design work together.

Start with a test page in your team's storefront. Preview it to check the content and layout before publishing.
