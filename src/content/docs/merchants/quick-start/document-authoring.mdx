The Document Authoring tool is the content management system (CMS) at the heart of the Commerce Storefront. It is where your storefront's pages, blocks, and assets are authored, organized, and managed. 

DA.live provides a collaborative environment for content teams to create and structure site content, manage translations, and control publishing workflows. It can integrate with the Universal Editor for in-context editing and with Edge Delivery Services for fast, reliable content delivery. DA.live supports versioning, localization, and multistore management, making it a powerful tool for complex commerce operations.

## Quick Edit and Experience Workspace

Alongside the document view, DA.live offers two ways to edit a storefront page in place, directly on its rendered preview or live URL, without opening the underlying document:

- **Quick Edit** lets you edit text and drag in replacement images directly on the rendered page. See the <Link href={"https://docs.da.live/about/early-access/quick-edit"} text={"Quick Edit early-access guide"} /> for setup details and current limitations.
- **Experience Workspace** builds on the same foundation for fuller in-context authoring (for example, a docked chat assistant alongside the canvas). It is newer than Quick Edit and still evolving; open it from da.live's canvas view for a connected site. See the <Link href={"https://docs.da.live/about/early-access/experience-workspace"} text={"Experience Workspace Documentation"} /> for setup details.

A storefront created with [Site Creator](/get-started/create-storefront/) has both wired up automatically — no manual setup is required to start using them. If you created your site before this landed in the Commerce boilerplate, confirm you have the corresponding Quick Edit code and Experience Workspace flag before using.
