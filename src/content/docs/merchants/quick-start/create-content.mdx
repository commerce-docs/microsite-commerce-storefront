Create and manage storefront page content with Document Authoring (DA.live) and Experience Workspace. The available blocks, images, and other media depend on your project's setup.

See [How a page comes together](/merchants/quick-start/content-model/) for how content authors and page designers combine content and code.

## DA.live (Document Authoring)

DA.live is the web application where content teams manage storefront documents. Each page document contains the text, images, and block settings that authors maintain separately from the storefront code.

To learn the document workflow, start with [Document Authoring](/merchants/quick-start/document-authoring/).

## Experience Workspace

Experience Workspace combines an AI Assistant with three views for editing the same page content:

- **AI Assistant:** Describe what you want to do in natural language. The assistant asks for confirmation before making changes or accessing resources.
- **Layout:** Edit content while viewing the page as shoppers will see it.
- **Content:** Edit the underlying document and its block tables.
- **Split:** Work with the layout and document side by side.

Open the assistant with **Show assistant panel** in the editor menu. If the panel and its icon are unavailable, the assistant may be disabled for your organization or site.

These views do not replace the storefront code that controls shopping behavior. Use your project's existing blocks and layout options, and ask your page designer or developer for changes that need code.

See [Experience Workspace](/merchants/quick-start/experience-workspace/) for storefront setup. For usage instructions, see the <Link href="https://www.aem.live/docs/ew/authoring/assistant" text="AI assistant documentation" /> and <Link href="https://www.aem.live/docs/ew/authoring/editing-docs" text="page authoring documentation" />.

## Digital assets management

Images and other media follow your team's asset workflow. If your storefront integrates Adobe Experience Manager (AEM) Assets, ask your project administrator which assets are available and what access you need.

See [AEM Assets integration](/setup/configuration/aem-assets-configuration/) for the integration requirements. Asset integration is a project setup task, not a step to repeat for each page.

## Content and Commerce blocks

Within these tools, blocks organize text, images, and shopping features on a page. In **Content** view, block tables identify each block and contain its content and settings.

See [Content and Commerce blocks](/merchants/blocks/content-commerce-blocks/) for the authoring model and [Block table structure](/merchants/blocks/block-tables/) for the table format.

## Edge Delivery Services

Edge Delivery Services delivers storefront pages to shoppers. Preview changes to check the content and layout before publishing them to the live storefront.

Follow [Create your first commerce page](/how-tos/create-commerce-page/) to create, preview, and publish a page with the storefront's authoring tools.
