AEM Edge Delivery Services lets you schedule snapshots for publishing at a later date and time. Add multiple pages to a snapshot, and all pages publish simultaneously when the scheduled time arrives. For detailed instructions, see the <Link href="https://main--helix-website--adobe.aem.page/drafts/amol/scheduling" text="Scheduled Publishing Guide" />.

## Overview

Scheduled publishing provides:

- **Planning ahead**: Create and prepare content snapshots that automatically publish at a specified future date and time.
- **Batch publishing**: Add multiple pages to a single snapshot, ensuring they all go live together.
- **Automated workflow**: Set up your organization and site once, then schedule snapshots as needed.

## Prerequisites

Before using scheduled publishing, register your organization and site. You need:

<Steps>
1. **Your organization name** - The name of your AEM organization
2. **Your site name** - The name of your site within the organization
3. **An AEM Admin API token** - Admin-level access token for your org/site
4. **An Admin API Key** - An API key for the scheduler service with permissions to publish snapshots
</Steps>

## Quick Start

### Register Your Organization/Site

Register your organization and site using the registration API. The registration process requires your AEM Admin API token and an Admin API key for the scheduler service.

### Using Scheduled Publishing

After registration, schedule snapshots for publishing:

- **If using Adobe's Document Authoring (da.live)**: Create a snapshot as you normally would and schedule it for publishing.
- **If using other authoring tools**: Use the Snapshot Admin tool to manage snapshots and schedule them for publishing.
