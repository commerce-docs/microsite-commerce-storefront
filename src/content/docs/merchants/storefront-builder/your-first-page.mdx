Learn how to create a complete commerce page by building a shopping cart page. This tutorial covers all the essential elements: page metadata, block configuration, and section metadata.

## What you'll build

A fully functional shopping cart page that includes:
- SEO-optimized page metadata
- The Commerce Cart block with custom configuration
- Styled sections using section metadata

## Prerequisites

- Access to the Document Authoring tool
- Basic familiarity with creating documents in AEM

## Tutorial: Create a cart page

<Steps>

1. **Create a new document**

   In the Document Authoring tool, create a new document named `cart`.

2. **Add page metadata**

   At the top of your document, create a metadata table. This controls page-level settings like title, SEO, and caching:

   | metadata |  |
   |----------|---|
   | Title | Shopping Cart |
   | Robots | noindex, nofollow |
   | Cache-Control | no-store |

   **Why these settings?**
   - **Title**: Appears in browser tabs and search results
   - **Robots**: Prevents search engines from indexing the cart (it's user-specific)
   - **Cache-Control**: Ensures the page is never cached (cart contents change frequently)

3. **Add the Commerce Cart block**

   Create a section with the Commerce Cart block and its configuration:

   | Commerce Cart |  |
   |---------------|---|
   | Hide Heading | false |
   | Max Items | 10 |
   | Hide Attributes | color, size |
   | Enable Item Quantity Update | true |
   | Enable Item Remove | true |
   | Enable Estimate Shipping | true |
   | Start Shopping Url | /products |
   | Checkout Url | /checkout |
   | Enable Updating Product | false |
   | Undo Remove Item | false |

   This configuration:
   - Shows the cart heading
   - Limits display to 10 items
   - Hides color and size attributes
   - Enables quantity updates and item removal
   - Shows shipping estimation
   - Provides links to continue shopping and checkout

4. **Add section metadata**

   Below the Commerce Cart block, add a section metadata table to style the section:

   | Section metadata |  |
   |------------------|---|
   | Style | light |

   This gives the cart section a light background color to distinguish it from the rest of the page.

5. **Add a promotional section (optional)**

   Add another section with content to encourage purchases:

   ---

   ## Free shipping on orders over $50!

   Continue shopping to discover more products.

   | Section metadata |  |
   |------------------|---|
   | Style | highlight |

   The `highlight` style makes this promotional message stand out.

6. **Preview your page**

   Use the preview function to see your cart page in action. You should see:
   - The cart title in the browser tab
   - The Commerce Cart block with your configured options
   - A light background for the cart section
   - A highlighted promotional section

7. **Publish your page**

   When you're satisfied with the preview, publish the page to make it live.

</Steps>

## Troubleshooting

**The block doesn't appear on my page**

Make sure the block name is spelled correctly as `Commerce Cart` (not "cart" or "shopping-cart"). Block names are case-sensitive.

**My configuration options aren't working**

Verify that:
- Each configuration key is spelled exactly as shown (they're case-sensitive)
- The values are formatted correctly (true/false, numbers, URLs)
- There are no extra spaces in the configuration keys

**The section styles aren't applying**

Check that:
- The section metadata table appears directly after the content you want to style
- The `Style` key is capitalized correctly
- The style value is one of the supported options: `light` or `highlight`

**Changes aren't visible after publishing**

- Wait a few moments for the cache to clear
- Try refreshing the page with Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
- Check that the page was published successfully (look for the green success message)
