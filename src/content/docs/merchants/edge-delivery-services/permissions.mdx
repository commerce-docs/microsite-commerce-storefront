## Editing permissions

Editing permissions control who can create and edit content in Document Authoring. Administrators configure these through the DA permissions sheet using a simple `read`, `write`, or `[ ]` (none) model.

**Authors**: Request editing access from your administrator.

**Administrators**: See the <Link href="https://docs.da.live/administrators/guides/permissions" text="Permissions and Security Guide" /> on da.live for setup instructions.

## Preview and publish permissions

Preview and publish permissions control who can preview and publish storefront pages. The AEM Permissions App provides a simple request-and-approve workflow.

**Authors**: When you try to preview or publish a page and see "Not Authorized," click the **Request Access** link in the notification. An administrator receives your request and can approve it.

**Administrators**: Open the Permissions App to view and approve pending requests. For advanced configuration using the Admin API, see <Link href="https://www.aem.live/docs/authentication-setup-authoring" text="Configuring Authentication for Authors" /> on aem.live.

## Site authentication

To restrict access to your entire preview or live site (for example, intranet sites or staging environments), configure token-based site authentication. This requires visitors to authenticate before viewing any content.

See the <Link href="https://main--helix-website--adobe.aem.page/docs/authentication-setup-site" text="Configuring Site Authentication Guide" /> for implementation details.
