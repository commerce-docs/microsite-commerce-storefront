Customers move between account pages through the links in this block. Each block is one group of links. Add one or more of these blocks to the account navigation page on a B2B storefront.


## Configuration

The first row of the block table holds three headings: `label`, `icon`, and `permission`. Each row after it adds one link.

<TableWrapper nowrap={[0]}>

| Column | What to enter |
| --- | --- |
| `label` | The link title on the first line, linked to the page. An optional short description on the second line. |
| `icon` | The name of the icon to show next to the link, such as `Business`. |
| `permission` | Who sees the link: `all` for every signed-in customer, an Adobe Commerce permission ID such as `Magento_Company::users_view` for customers whose company role includes it, or `admin` for Company Administrators only. |

</TableWrapper>

### Important notes

- Company Administrators see every link that uses a permission ID or `admin`, except the company address links described in the notes below.
- When the company address book is turned off, the block hides links that use a company address permission ID from every customer, including Company Administrators.
- When the company address book is turned on, the block hides links to `/customer/address` from customers who cannot view company addresses.
- When the company address book is turned on and two links point to the same page, the block shows only the link that uses a company address permission ID.
- To hide a link when the company address book is turned on, set its permission to `company_address_book_disabled`. The link is then hidden from every customer, including Company Administrators.

## Page setup

Add these blocks to the `/customer/nav` page. Account pages load that page with a `fragment` block. For the links the reference storefront uses, see [Account navigation](/merchants/blocks/b2b/pages/#account-navigation).
