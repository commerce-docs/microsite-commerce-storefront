The Product Reviews block shows approved shopper reviews for one product. Shoppers see each reviewer's name, star rating, review title, review text, and date. Products with more than 20 approved reviews also show page controls. Reviews from real buyers build trust and help shoppers decide.

## What shoppers see

- A **Reviews** heading followed by up to 20 approved reviews.
- Stars and a value for each review, or *Not rated* when the reviewer gave no rating.
- Page controls below the list when there are more reviews.
- *No reviews on this page.* when the product has no approved reviews yet.

Reviews appear only after they are approved in the Admin. When product reviews are turned off for your store, the block stays hidden. The average rating below the product name is part of the Product Details block, not this block.

## Where the block appears

On product pages that the storefront builds automatically from the product SKU, your developer can add the reviews section for you at the end of the page. In that case, you do not need to author anything.

Add the block yourself in these cases:

- Your product page uses an authored Product Details block, for example in a product page template.
- You want reviews on another page, such as a campaign page. Add a `sku` row to choose the product.

If a page already has a Product Reviews block, the storefront does not add a second one.

### Property descriptions

#### sku

The SKU of the product whose reviews to show. Enter it exactly as it appears in your catalog. When you leave it out, the block uses the SKU of the current product page.

Set `sku` when you place the block outside a product page. In the editor preview, the block uses the Product Details block's default SKU unless you set `sku`. Without any SKU, the block stays hidden.

The block shows 20 reviews per page. Page size and starting page are not configurable in the block table.

## Change the labels

The block reads its labels from the `ratings-reviews` placeholders sheet at `placeholders/ratings-reviews.json`. Add a row for each label you want to change:

<TableWrapper nowrap={[0]}>

| Key | Default value |
| --- | --- |
| `Review.title` | Reviews |
| `Review.empty` | No reviews on this page. |
| `Review.unavailable` | Reviews are unavailable. |
| `Review.error` | Unable to load reviews. |
| `Review.retry` | Try again |
| `Review.unrated` | Not rated |
| `Review.author` | By `{{nickname}}` |

</TableWrapper>

Keep `{{nickname}}` in `Review.author`; the storefront replaces it with the reviewer's name. For every key, see the [Ratings and Reviews dictionary](/dropins/ratings-reviews/dictionary/). For steps to edit a placeholders sheet, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
