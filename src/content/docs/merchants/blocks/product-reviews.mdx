The Product Reviews block shows approved shopper reviews for one product. Shoppers see each reviewer's name, star rating, review title, review text, and date. Products with more than 20 approved reviews also show page controls.

## What shoppers see

- A *Reviews* heading followed by up to 20 approved reviews.
- Stars and a value for each review, or *Not rated* when the reviewer gave no rating.
- Page controls below the list when there are more reviews.
- *No reviews on this page.* when the product has no approved reviews yet.
- A **Write review** button above the list, if your developer added it. The button opens a form where shoppers choose a star rating and enter a title, a description, and their name.

Reviews appear only after approval in the Admin, including reviews that shoppers submit through the form.

- *Sign-in*: When guests cannot write reviews, signed-out shoppers see a sign-in prompt instead of the form.
- *Store settings*: When product reviews are turned off for your store, the block stays hidden.
- *Average rating*: The average rating below the product name belongs to the Product Details block, not the Product Reviews block.

<Aside type="note" title="Storefront setup">
A developer must set up the Ratings and Reviews drop-in and the Product Reviews block before you add the block to your content. See the [Ratings and Reviews quick start](/dropins/ratings-reviews/quick-start/).
</Aside>

## Where the block appears

Some product pages are built automatically from the product SKU, its identifier in the catalog. Your developer can add the reviews section to the end of those pages. In that case, you do not need to add the Product Reviews block manually.

Add the block yourself in these cases:

- Your product page uses an authored Product Details block, such as in a product page template.
- You want reviews on another page, such as a campaign page. Add a `sku` row to choose the product.

If a page already has a Product Reviews block, automatic placement does not add a second one.

### Property descriptions

#### sku

Enter the SKU of the product whose reviews to show, exactly as it appears in your catalog. Without a `sku` row, the block uses the current product page's SKU.

- *Other pages*: Add a `sku` row when you place the block outside a product page.
- *Editor preview*: If you omit the `sku` row and the page has no SKU metadata, the block uses the Product Details block's default SKU.
- *Missing SKU*: Without a SKU from any of these sources, the block stays hidden and reports an error in the browser console. Add a valid `sku` row to load reviews.

The block shows 20 reviews per page. The block table has no settings for page size or starting page.

## Change the labels

The block reads its labels from the `ratings-reviews` placeholders sheet at `placeholders/ratings-reviews.json`. Add a row for each label to change:

<TableWrapper nowrap={[0]}>

| Key | Default value |
| --- | --- |
| `Review.title` | Reviews |
| `Review.empty` | No reviews on this page. |
| `Review.unavailable` | Reviews are unavailable. |
| `Review.error` | Unable to load reviews. |
| `Review.retry` | Try again |
| `Review.unrated` | Not rated |
| `Review.author` | By `{{nickname}}` |
| `Global.WriteReview` | Write review |

</TableWrapper>

- *Reviewer name*: Keep `{{nickname}}` in `Review.author`. The storefront replaces this placeholder with the reviewer's name.
- *Button label*: `Global.WriteReview` applies only when your storefront has the **Write review** button.
- *Form text*: The review form uses `WriteReview` keys, such as `WriteReview.successHeading` for the confirmation heading after submission.

For all review labels and messages, see the [Ratings and Reviews dictionary](/dropins/ratings-reviews/dictionary/). For steps to edit a placeholders sheet, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
