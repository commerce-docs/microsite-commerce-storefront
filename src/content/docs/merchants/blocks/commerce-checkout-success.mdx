Customers see the order confirmation and order number through this block after they complete checkout. The Checkout block shows it after an order is placed.

## Requirements

The [Checkout](/merchants/blocks/commerce-checkout/) block must be on your checkout page. Guests and signed-in customers both see this block after they place an order.

## Configuration

No configurations available for this block.

## Page setup

You do not need to add this block to a page. The [Checkout](/merchants/blocks/commerce-checkout/) block shows it in place of the checkout form after a customer places an order. On a B2B storefront, the [Quote Checkout](/merchants/blocks/commerce-b2b-quote-checkout/) block shows it too. When a buyer places a purchase order, both blocks show the [Purchase Order Checkout Success](/merchants/blocks/commerce-b2b-po-checkout-success/) block instead.
