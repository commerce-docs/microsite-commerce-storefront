## Overview

Customize the product detail page layout and information display.

This block integrates with Adobe Commerce to provide a seamless shopping experience for your customers.

## Configuration Options

The following configuration options are available for this block:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `hide-selected-value` | string | 'false' | Controls whether the selected option value is hidden in product options |

### Example Configuration

Create a `product-details` block in your document with this configuration:

| Product Details |
| --- |
| hide-selected-value: 'false' |

## Tips for Merchants

- Use document authoring to configure this block without writing code.
- Test configuration changes in preview before publishing to production.
- Configure product attributes to match your catalog structure.
