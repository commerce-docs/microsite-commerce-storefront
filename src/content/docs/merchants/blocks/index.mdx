Commerce blocks are pre-built shopping features that you add to pages in Document Authoring. Use the B2C and B2B references to find the block for a shopper or business task, then open its page for the exact block name, requirements, placement, and settings.

If you are new to adding and configuring blocks, start with [Build pages](/merchants/authoring/). It explains block tables, metadata, layout options, and placeholders before you use this catalog.

<TableWrapper nowrap={[0]}>

| Topic | Description |
|-------|-------------|
| [B2C Commerce Blocks](/merchants/blocks/b2c/) | Blocks for business-to-consumer storefronts, including cart, checkout, account, and orders |
| [B2B Commerce Blocks](/merchants/blocks/b2b/) | Blocks for business-to-business storefronts, including company management, purchase orders, and quotes |

</TableWrapper>

Authors can choose and configure the blocks that are already available. Changes to a block's design or behavior require code; see [Author and developer tasks](/merchants/blocks/author-and-developer-tasks/) to identify the right owner. Developers can use the [developer Blocks documentation](/blocks/) for implementation guidance.
