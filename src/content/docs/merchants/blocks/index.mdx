B2B commerce blocks are pre-built components that provide B2B functionality for your Adobe Commerce storefront. These blocks work together with B2B drop-ins to enable enterprise commerce features like company management, purchase orders, negotiable quotes, and requisition lists.

<TableWrapper nowrap={[0,1]}>

| Category | Blocks | Description |
|----------|--------|-------------|
| **Checkout & Account** | 9 blocks | B2B-specific checkout and account management blocks including [Account Navigation](/merchants/blocks/commerce-account-nav/), [Checkout Success](/merchants/blocks/commerce-checkout-success/), and [Customer Company](/merchants/blocks/commerce-customer-company/) switcher. |
| **Company Management** | 7 blocks | Company administration blocks for managing [Company Profile](/merchants/blocks/commerce-company-profile/), [Company Users](/merchants/blocks/commerce-company-users/), [Roles & Permissions](/merchants/blocks/commerce-company-roles-permissions/), [Company Structure](/merchants/blocks/commerce-company-structure/), [Company Credit](/merchants/blocks/commerce-company-credit/), [Create Company](/merchants/blocks/commerce-company-create/), and [Accept Invitation](/merchants/blocks/commerce-company-accept-invitation/). |
| **Company Switcher** | 1 block | [Customer Company](/merchants/blocks/commerce-customer-company/) block for company context switching for multi-company users. |
| **Purchase Order** | 13 blocks | Purchase order blocks including [Company POs](/merchants/blocks/commerce-b2b-po-company-purchase-orders/), [Customer POs](/merchants/blocks/commerce-b2b-po-customer-purchase-orders/), [PO Approval Flow](/merchants/blocks/commerce-b2b-po-approval-flow/), [PO Approval Rules](/merchants/blocks/commerce-b2b-po-approval-rules-list/), [PO Comments](/merchants/blocks/commerce-b2b-po-comments-list/), [PO History Log](/merchants/blocks/commerce-b2b-po-history-log/), and [PO Status](/merchants/blocks/commerce-b2b-po-status/). |
| **Quote Management** | 3 blocks | Negotiable quote blocks including [Negotiable Quotes](/merchants/blocks/commerce-b2b-negotiable-quote/), [Quote Checkout](/merchants/blocks/commerce-b2b-quote-checkout/), and [Quote Template](/merchants/blocks/commerce-b2b-negotiable-quote-template/). |
| **Requisition List** | 2 blocks | Requisition list blocks including [Requisition List](/merchants/blocks/commerce-b2b-requisition-list/) and [Requisition List View](/merchants/blocks/commerce-b2b-requisition-list-view/). |

</TableWrapper>

## Requirements

All B2B commerce blocks require:

- Adobe Commerce B2B features enabled in **Stores** > **Configuration** > **General** > **B2B Features**
- Company features enabled for company-related blocks
- Customer authentication for most B2B functionality

See individual block documentation for specific requirements.
