Anyone with a public share link previews a requisition list and adds its items to their own cart through this block. Recipients do not need to sign in or belong to a company. Place it on the page that public share links open.

## Requirements

Customers do not need to sign in to use this block. Public share links come from the [Requisition List View](/merchants/blocks/commerce-b2b-requisition-list-view/) block, which needs company features and requisition lists turned on in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Requisition List**. Buyers can make a list public and share it only when public requisition list sharing is also turned on in Adobe Commerce.

## Configuration

No configurations available for this block.

### Important notes

- If no page exists at the public share link path, every public share link opens a 404 page, including links sent by email. If an administrator changes this path in the Adobe Commerce configuration, move the page to match.
- Use a different page from the one for company share links, which uses the [Requisition List Sharing](/merchants/blocks/commerce-b2b-requisition-list-sharing/) block.
- Recipients can select **Add All to Cart** or **Add Selected to Cart**. They cannot import the list into an account. If a guest has no cart yet, the block creates one.
- If the link has no share token, the block opens the storefront home page. If the token is invalid or expired, the block shows an error message.

## Page setup

Add this block to the `/customer/requisition-list-public-share` page, or to the path your administrator set for public share links. The page contains only this block and a `metadata` table. For the page title and metadata, see [Requisition list pages](/merchants/blocks/b2b/pages/#requisition-lists).

## Labels and messages

The block's labels and messages come from the `requisition-list` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/). For details, see the [SharedRequisitionList container](/dropins-b2b/requisition-list/containers/shared-requisition-list/).
