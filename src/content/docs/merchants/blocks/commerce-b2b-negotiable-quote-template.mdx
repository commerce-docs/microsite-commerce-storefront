Buyers view and manage quote templates, and generate quotes from them, through this block.

## What buyers can do

- See a list of quote templates, and page through it.
- Open a template to see its items, comments, and history. From there, rename, accept, cancel, or delete the template, or send it for review.
- Generate a quote from a template. The storefront then opens the new quote on the `/customer/negotiable-quote` page.

The block shows the list when the page opens without a template ID, and one template when the URL includes a `quoteTemplateId` parameter. For details, see the [ManageNegotiableQuoteTemplate container](/dropins-b2b/quote-management/containers/manage-negotiable-quote-template/) and the [QuoteTemplatesListTable container](/dropins-b2b/quote-management/containers/quote-templates-list-table/).

## Requirements

Customers must log in to access this block. Enable company features and negotiable quotes in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable B2B Quote**.

## Configuration

No configurations available for this block.

## Page setup

Add this block to the `/customer/negotiable-quote-template` page. Use this exact path. When a buyer changes companies while viewing a template, the company switcher in the header opens this path. For the page title and metadata, see [Quote pages](/merchants/blocks/b2b/pages/#quotes).

## Template actions

The actions a buyer sees for a template depend on the template's status. For example, a buyer can delete only a draft template and can generate a quote only from an active template.

## Labels and messages

Most of the block's labels and messages come from the `quote-management` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/). This text is set in code, so you cannot change it in a sheet:

- The **Access Restricted** message, which buyers see when company features are turned off or they do not belong to a company.
- The **No Quote Templates Found** message in the template list.
- The **Select** placeholder in each item's actions menu.
- The messages that appear when a buyer sets a template's expiration date, such as **Expiration date saved successfully**.
