Buyers review and add items to cart from saved requisition lists through this block. Place it on requisition list detail pages.

## Requirements

Customers must log in to access this block. Enable company features and requisition lists in **Stores** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Configuration** > **General** > **B2B Features** > **Enable Requisition List**.

## Configuration

No configurations available for this block.

## Export and print

<Aside type="note" title="Preview availability">
  Export and print are being validated with Requisition List preview
  `2.1.0-preview-20261126103129-7696915`. These instructions do not announce stable release
  availability.
</Aside>

On a nonempty list that they own, signed-in buyers can:

- Select **Export** to download every retrieved line as a CSV with `sku,qty`
  columns. Prices, subtotals, product names, and selected options are not included.
- Select **Print** to open the browser's print dialog for the complete list,
  including product details, selected options, quantities, prices, and subtotals.
  Choose an available PDF destination in that dialog to save a PDF.

Both actions include all list pages, not only selected items or the visible page.
They leave the buyer's current page, selection, and quantities unchanged. Empty
lists do not show these actions. If complete list retrieval fails, the buyer sees
an error instead of receiving a successful partial output. Lists with deleted or
disabled products can fail retrieval.

<Aside type="caution" title="Printed amounts are interim">
  Print uses the current list-view pricing rules. Bundle calculations, custom-option charges, and
  configured or missing-price fallbacks have known limitations. The PDF is not an authoritative
  pricing report. A warning can indicate incomplete product data, but the absence of a warning does
  not establish pricing accuracy.
</Aside>

If printing remains busy after the buyer closes the dialog, a **Reset print
operation** action becomes available after the recovery delay. Close the dialog
before resetting. The storefront never automatically deletes print content
because that delay elapsed.

The preview integration hides the site's direct-body header, main content, and
footer during list printing, while keeping the separate print layout visible.
Custom storefront layouts need equivalent print styles. Developers can find the
styles, exact recovery timing, CSV precautions, and pricing limitations in
[RequisitionListHeader](/dropins-b2b/requisition-list/containers/requisition-list-header/#export-and-print).
