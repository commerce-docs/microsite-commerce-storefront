Buyers review and add items to cart from saved requisition lists through this block. Place it on requisition list detail pages.

## What buyers can do

- See the products in one requisition list.
- Change quantities, delete items, and add selected items to the cart.
- Move or copy items to another list.
- Make the list public or private, when public sharing is turned on.
- Share the list. Private lists need requisition list sharing turned on, and public lists need public sharing turned on. Only company users can share a private list, and an empty list cannot be shared.

The block shows the list named by the `requisitionListUid` parameter in the URL. Other blocks add this parameter when they open the page. For details, see the [RequisitionListView container](/dropins-b2b/requisition-list/containers/requisition-list-view/).

## Requirements

Customers must log in to access this block. Enable company features and requisition lists in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Requisition List**.

## Configuration

No configurations available for this block.

## Page setup

Add this block to the `/customer/requisition-list-view` page. Use this exact path, because other blocks link to it. The page uses the [account page layout](/merchants/blocks/b2b/pages/#account-page-layout). For the page title and metadata, see [Requisition list pages](/merchants/blocks/b2b/pages/#requisition-lists).

## Labels and messages

The block's labels and messages come from the `requisition-list` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
