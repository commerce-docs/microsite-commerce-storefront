Buyers create and manage their requisition lists through this block. Place it on requisition list pages.

## What buyers can do

- See their requisition lists.
- Open a list to manage its items.
- Create, rename, or delete a list, and make a list public when public sharing is turned on.

For details, see the [RequisitionListGrid container](/dropins-b2b/requisition-list/containers/requisition-list-grid/).

## Requirements

Customers must log in to access this block. Enable company features and requisition lists in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Requisition List**.

## Configuration

No configurations available for this block.

## Page setup

Add this block to the `/customer/requisition-lists` page. Use this exact path, because other blocks link to it. The page uses the [account page layout](/merchants/blocks/b2b/pages/#account-page-layout). When a buyer opens a list, this block opens the `/customer/requisition-list-view` page. For the page titles and metadata, see [Requisition list pages](/merchants/blocks/b2b/pages/#requisition-lists).

## Labels and messages

The block's labels and messages come from the `requisition-list` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
