Buyers see a purchase order heading and a link back to all purchase orders through this block.

## What buyers can do

- See a **Purchase order** heading. When another purchase order block on the same page loads the order, the heading also shows the purchase order number.
- Go back to the list of all purchase orders. The block shows this link only on the `/customer/purchase-order-details` page.

## Requirements

The block does not check whether the customer is signed in. The other purchase order blocks on the details page send signed-out customers to the sign-in page. Enable company features in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company**. Turn on purchase orders in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Order Approval Configuration** > **Enable Purchase Orders**, and then for each company in **Customers** > **Companies** > edit the company > **Advanced Settings** > **Enable Purchase Orders**.

## Configuration

No configurations available for this block.

## Page setup

Add this block to the `/customer/purchase-order-details` page. Use this exact path, because other blocks link to it. For the block order, layout, and page metadata, see [Purchase order pages](/merchants/blocks/b2b/pages/#purchase-orders).

## Labels and messages

The heading and the back link come from the `global` [placeholder sheet](/merchants/blocks/placeholder-sheets/), in the `Global.CommercePOHeader.poHeaderTitle` and `Global.CommercePOHeader.backToAllPOs` keys. To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
