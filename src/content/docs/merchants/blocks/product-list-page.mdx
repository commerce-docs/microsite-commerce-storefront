### Property descriptions

**Urlpath**: Specifies the category path to display products from. Use this to create category-specific product listing pages. For example, `/women/dresses` shows products from the dresses category. Set this when creating a dedicated category page. Leave empty for search result pages.

### Important notes

- URL paths must point to valid pages on your site for navigation to work correctly.
