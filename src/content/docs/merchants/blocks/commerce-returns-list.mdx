### Property descriptions

**Minified View**: Controls whether returns are displayed in minified or full view mode. Use `true` for space-constrained layouts like checkout flows. Default: `false`.

### Important notes

- Requires user authentication. Unauthenticated users are automatically redirected to the login page.
