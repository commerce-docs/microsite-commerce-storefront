Customers discover relevant products based on browsing history and preferences through this block. Place it on any page to increase cross-selling.

:::note[Setup required]
Before using this block, see the [Product Recommendations setup guide](/merchants/commerce-blocks/product-recommendations/) for configuration instructions.
:::

### Property descriptions

**Currentsku**: Current product SKU for recommendation context.

**Recid**: Recommendation ID for targeting specific recommendation types.

### Important notes

- Uses default configuration values if custom settings are missing or invalid.
