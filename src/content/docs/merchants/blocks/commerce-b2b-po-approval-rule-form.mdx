Buyers create and edit purchase order approval rules through this block.

## What buyers can do

- Create a new purchase order approval rule, or edit an existing rule.
- Set the rule's name, description, and status, who it applies to (all users or specific roles), the rule type (grand total, shipping cost, or number of SKUs), the condition (such as **is more than**), the amount (or, for number of SKUs, the quantity), and which roles must approve.

For details, see the [ApprovalRuleForm container](/dropins-b2b/purchase-order/containers/approval-rule-form/).

## Requirements

Customers must log in to access this block. Enable company features in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company**. Turn on purchase orders in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Order Approval Configuration** > **Enable Purchase Orders**, and then for each company in **Customers** > **Companies** > edit the company > **Advanced Settings** > **Enable Purchase Orders**. In your storefront configuration, set [`commerce-b2b-enabled`](/setup/configuration/commerce-configuration/#additional-configuration-options) to `true`. If it's missing or `false`, the storefront sends customers to their account page. Customers need the approval rules **Create, Edit, and Delete** permission in their company role. Without this permission, the storefront sends them to their account page. Company administrators don't need this permission.

## Configuration

No configurations available for this block.

## Page setup

Add this block to the `/customer/approval-rule` page. Use this exact path, because other blocks link to it. The page uses the [account page layout](/merchants/blocks/b2b/pages/#account-page-layout). For the page title and metadata, see [Purchase order pages](/merchants/blocks/b2b/pages/#purchase-orders).

## Labels and messages

The block's labels and messages come from the `purchase-order` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/).
