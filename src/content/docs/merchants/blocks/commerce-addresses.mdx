## Configuration

Add this table to your document to configure the block:

<td style="width: 50%; padding: 0.75rem; border: 1px solid var(--sl-color-gray-5);">false</td>
</tr>

### Property descriptions

**minifiedView**: Controls whether addresses are displayed in minified or full view mode. Use `true` for space-constrained layouts like checkout flows. Default: `false`.

### Important notes

- Requires user authentication. Unauthenticated users are automatically redirected to the login page.
