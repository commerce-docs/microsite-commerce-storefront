### Property descriptions

**minified-view**: Controls whether addresses are displayed in minified or full view mode. Use `true` for the short address summary on the account page. The minified view shows only the default addresses, or one address if none is a default, with no edit or remove actions. Default: `false`.

### Important notes

- Requires user authentication. Unauthenticated users are automatically redirected to the login page.

## Company addresses on B2B storefronts

On a B2B storefront, this block can show a company's shared address book instead of the customer's own addresses. Company Administrators turn on the company address book from the [Company Profile](/merchants/blocks/commerce-company-profile/) page. A store administrator can also turn it on in the Admin, in **Customers** > **Companies** > edit the company > **Advanced Settings** > **Enable Company Address Book**. You use the same block and configuration. No extra setup is needed on the page.

The block checks two things for each signed-in customer: whether their company uses the address book, and whether they can view company addresses.

<TableWrapper>

| Company address book | Customer can view company addresses | What the block shows |
|---|---|---|
| Off | Not checked | The customer's own addresses. |
| On | Yes | The company's shared addresses, under the company title from the `account` placeholder sheet. |
| On | No | In full view, the block sends the customer to their account page. In minified view, the block stays empty. |

</TableWrapper>

Company Administrators can always view company addresses. Other company users need the **Company Addresses** permission in their role. To add, edit, or delete company addresses, or to set a default address, they also need the **Add**, **Edit**, **Delete**, or **Set Default Address** permission under it. Set these permissions with the [Company Roles and Permissions](/merchants/blocks/commerce-company-roles-permissions/) block.

The company title comes from the `Account.fullSizeView.Addresses.companyContainerTitle` and `Account.minifiedView.Addresses.companyContainerTitle` keys in the `account` [placeholder sheet](/merchants/blocks/placeholder-sheets/). The reference storefront sets both keys to **Company Addresses**. If your sheet does not have these keys, the block uses the standard **Addresses** title. To change the company title, edit these keys.

For how company addresses work in checkout and quotes, see [Company Address Book](/dropins-b2b/company-management/company-address-book/).

## Page setup

Add this block to the `/customer/address` page with **minified-view** set to `false`. Use this exact path. The address summary on the account page links to it, and the Account Navigation block looks for this path when it decides who sees the Addresses link. To show a short address summary on the `/customer/account` page, add a second Addresses block there with **minified-view** set to `true`.

Both pages show the account navigation beside the page content. On a B2B storefront, follow the [account page layout](/merchants/blocks/b2b/pages/#account-page-layout). On a B2C storefront, the first section holds the [Account Sidebar](/merchants/blocks/commerce-account-sidebar/) block instead of the `/customer/nav` fragment. In the page `metadata` table, set **Template** to a value that includes `Columns` and **Robots** to `noindex, nofollow`.
