In your Adobe Commerce storefront, a <Term>block table</Term> in your document becomes a <Term>Commerce block</Term> (or a <Term>Content block</Term>) on the page. Once you know how the block name row, key-value settings, and optional full-width content rows work, you can add and configure any block on your storefront.

## Example: a block table in your document {#block-table-example}

Read the table from top to bottom:

- The first row (full width, shaded) is the <Term term="Block name row">block name</Term> row. It is usually a single `kebab-case` name such as `commerce-cart` or `targeted-block`. The storefront reads that name to find and load the matching block. In some editors, the name may appear in the first cell with the second cell left empty, but the rule is the same: one clear block identifier.
- Rows with two cells are <Term term="Key-value row">key-value</Term> settings: a setting name in the first column and a value in the second. Many options are optional and use safe defaults if you leave them out. Each block's [reference page](/merchants/blocks/) lists the valid keys, allowed values, and which keys (if any) are required.
- A row with one cell spanning the full width is a <Term term="Merged full-width row">merged full-width row</Term> when the cell holds block content rather than a second key-value setting. The italic row in the example shows that option.

<Aside type="caution" title="Where is my block?">
If a block does not appear on the page when previewed, the most common cause is a block name that does not match the spelling on that block's [reference page](/merchants/blocks/). If the block appears but looks wrong or empty, check the content rules on that block's [reference page](/merchants/blocks/), or use [Personalization setup](/merchants/content-customizations/personalization/) for `targeted-block`.
</Aside>

## Add a block to your document {#add-a-block}

These steps show you how to add a block table to your document in Document Authoring (the web-based editor where you create and update storefront pages).

<Steps>

1. Add a new table to the page.

1. Set the first row to the block name in `kebab-case`, for example, `commerce-cart`.

1. Add the key-value rows that the block's [reference page](/merchants/blocks/) requires or recommends.

1. Preview the page. The block should appear in the section where you placed the table.

1. Publish when the page looks right.

</Steps>

For an end-to-end example that covers metadata, a cart block, and section styling, work through [Your first page](/merchants/quick-start/your-first-page/).
