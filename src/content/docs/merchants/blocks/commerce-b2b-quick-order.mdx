Buyers add many products to the cart at once through this block. They can search for products, enter a list of SKUs, or upload a CSV file.

## Requirements

Enable Quick Order in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Quick Order**. When Quick Order is turned off, the block covers the order form with a message, and buyers cannot use the form. Customers do not need to sign in to use this block.

## Configuration

No configurations available for this block.

### Important notes

- The block adds its own **Quick Order** heading, so you do not need to add one.
- CSV files need exactly two columns, `SKU` and `QTY`, and can have up to 200 rows. Buyers can download a sample file from the block.
- After buyers select **Add to Cart** and the items are added, the storefront opens the cart page.

## Page setup

Add this block to the `/quick-order` page. Use this exact path, because the storefront code checks for it when it sets up product prices and options for Quick Order. For the page title and metadata, see [Quick order page](/merchants/blocks/b2b/pages/#quick-order).

## Labels and messages

The block's labels and messages come from the `quick-order` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). Product prices and options use the `pdp` sheet. To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/). The **Quick Order** heading and the fallback error **Failed to add products to cart.** are set in the block code, so you cannot change them in a sheet. For details, see the [Quick Order drop-in](/dropins-b2b/quick-order/).
