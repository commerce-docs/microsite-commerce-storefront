### Property descriptions

**minifiedView**: Controls whether orders are displayed in minified or full view mode. Use `true` for space-constrained layouts like checkout flows. Default: `false`.

**search**: Shows the order search box on the order history page, so customers can find orders by order number, product name, or product SKU. The search box appears in the full view only. Set to `false` to hide it. Default: `true`.

### Important notes

- Requires user authentication. Unauthenticated users are automatically redirected to the login page.
