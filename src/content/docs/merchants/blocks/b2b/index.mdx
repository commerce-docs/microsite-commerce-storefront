This reference provides a complete list of all B2B commerce blocks available for creating your storefront pages. These blocks power B2B storefronts and provide company management, purchase order workflows, quote negotiation, and requisition list features for business-to-business commerce.

If you are new to Commerce blocks, read [Author and developer tasks](/merchants/blocks/author-and-developer-tasks/) first. It explains drop-ins, blocks, and pages as three layers, what you can change without code, and when to hand off to a developer.

To build the pages that hold these blocks, including the paths, block order, layout, and page metadata for each page, see [B2B storefront pages](/merchants/blocks/b2b/pages/).

## Using commerce blocks

### Adding a block to your page

<Steps>

1. In the Document Authoring tool, create a table with the block name.
1. Add configuration options as key-value pairs in the table.
1. The block will automatically render when the page is published.

</Steps>

If the table parts (block name row, key-value rows, and merged full-width content rows) are new to you, read [Block table structure](/merchants/blocks/block-tables/) and then come back to this reference.

### Block naming conventions

- All B2B commerce blocks start with "Commerce".
- Use the exact spelling shown in this reference.

### Configuration options

Only the [Company Credit](/merchants/blocks/commerce-company-credit/) block reads configuration options. [Account Nav](/merchants/blocks/commerce-account-nav/) uses its table to list links instead. The other B2B blocks have no configuration options.

Configuration keys are not case-sensitive. For example, `show-history` and `Show History` both work.
