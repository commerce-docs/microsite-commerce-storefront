Company users preview requisition lists that other users in their company share with them through this block. Buyers can then import a shared list into their own account. Place it on the page that company share links open.

## Requirements

Customers must log in to access this block. If a customer opens a share link while signed out, the block shows a sign-in form, and the shared list loads after the customer signs in. Share links come from the [Requisition List View](/merchants/blocks/commerce-b2b-requisition-list-view/) block, which needs company features and requisition lists turned on in **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Company** and **Stores** > **Settings** > **Configuration** > **General** > **B2B Features** > **Enable Requisition List**. Buyers can share a list there only when requisition list sharing is also turned on in Adobe Commerce.

## Configuration

No configurations available for this block.

### Important notes

- If an administrator changes the company share link path in the Adobe Commerce configuration, move the page to match. Otherwise, share links open a page that does not exist.
- Buyers see a preview of the shared list first. When they select **Import List**, the list is added to their account, and the storefront opens the list's detail page with a success message.
- If the link has no share token, the block opens the requisition lists page. If the token is invalid or expired, the block shows an error message.
- Public share links, which anyone can open, use a separate page with the [Requisition List Public Share](/merchants/blocks/commerce-b2b-requisition-list-public-share/) block.

## Page setup

Add this block to the `/customer/requisition-list-sharing` page, or to the path your administrator set for company share links. The page contains only this block and a `metadata` table. For the page title and metadata, see [Requisition list pages](/merchants/blocks/b2b/pages/#requisition-lists).

## Labels and messages

The block's labels and messages come from the `requisition-list` [placeholder sheet](/merchants/blocks/placeholder-sheets/#b2b-drop-in-sheets). The sign-in form uses the `auth` sheet. To change them, see [Labels and placeholders](/how-tos/change-labels-and-placeholders/). For details, see the [SharedRequisitionList container](/dropins-b2b/requisition-list/containers/shared-requisition-list/).
