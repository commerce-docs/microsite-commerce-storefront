## Overview

Configure the customer account header navigation.

This block integrates with Adobe Commerce to provide a seamless shopping experience for your customers.

## Configuration Options

The following configuration options are available for this block:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `title` | string | 'My account' | The header title text displayed to users |

### Example Configuration

Create a `commerce-account-header` block in your document with this configuration:

| Account Header |
| --- |
| title: 'My account' |

## Tips for Merchants

- Use document authoring to configure this block without writing code.
- Test configuration changes in preview before publishing to production.
