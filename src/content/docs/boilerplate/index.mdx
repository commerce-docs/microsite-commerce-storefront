This page introduces the AEM Commerce boilerplate. It shows which GitHub repository Adobe supports when you start a new storefront.

The boilerplate (<Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="hlxsites/aem-boilerplate-commerce" />) is a production-ready storefront starter. It combines Edge Delivery Services with Commerce drop-in components so you can ship a storefront without assembling every integration from scratch.

<Aside type="note" title="One supported boilerplate">
  <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce"} text={"aem-boilerplate-commerce"} /> is the only Adobe-supported Commerce starter. Demo stores (Citisignal and similar) are event or showcase forks. They are not kept current and should not be used as a project baseline.
</Aside>

## First steps

<Steps>

1. Review this page so you know which GitHub repo to clone and why demo forks are a bad baseline.

1. If you still need a site, follow [Create a storefront](/get-started/create-storefront/). When you already have a repo, open [Boilerplate getting started](/boilerplate/getting-started/) to run `npm install` and `npm start`, and explore `blocks/`, `scripts/`, and `styles/`.

1. Read [Storefront Architecture](/get-started/architecture/) when you need the full picture of how authoring, blocks, drop-ins, and Commerce APIs connect.

</Steps>
