The AEM Commerce boilerplate is a production-ready storefront starter that integrates Commerce drop-in components with Edge Delivery Services. It includes 29 commerce blocks, configuration templates, and build tools to help you create high-performance storefronts quickly.

<strong>Version: 4.0.1</strong>
</div>

## Getting Started

1. **Clone the repository**: Start with the [AEM Commerce boilerplate](https://github.com/hlxsites/aem-boilerplate-commerce)
2. **Configure your Commerce backend**: See the [Configuration](/boilerplate/configuration/) page
3. **Customize blocks**: Explore the [Commerce blocks](#commerce-blocks) section to understand what's available
4. **Deploy**: Follow the [Edge Delivery Services documentation](https://www.aem.live/docs/) for deployment
