This page orients you to the AEM Commerce boilerplate. It takes about five minutes to read. If you do not have a storefront repository yet, create one in [Create a storefront](/get-started/create-storefront/) (Site Creator or the full tutorial there). When you want commands, local run, folders, and customization strategy for an existing repo, open [Boilerplate getting started](/boilerplate/getting-started/). This overview answers what the repo is, which fork is supported, and gives lookup tables you will use later.

The boilerplate is a production-ready storefront starter. It combines Edge Delivery Services with Commerce drop-in components so you can ship a storefront without assembling every integration from scratch.

Repository: <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="hlxsites/aem-boilerplate-commerce" />

<Aside type="note" title="One supported boilerplate">
  <Link href={"https://github.com/hlxsites/aem-boilerplate-commerce"} text={"aem-boilerplate-commerce"} /> is the only Adobe-supported Commerce starter. Demo stores (Citisignal and similar) are event or showcase forks. They are not kept current and should not be used as a project baseline.
</Aside>

## Your next step

<Steps>

1. Skim this page so you know which GitHub repo to clone and why demo forks are a bad baseline.

1. If you still need a site, follow [Create a storefront](/get-started/create-storefront/). When you already have a repo, open [Boilerplate getting started](/boilerplate/getting-started/) to run `npm install` and `npm start`, and explore `blocks/`, `scripts/`, and `styles/`.

1. Read [Storefront fundamentals](/get-started/architecture/) when you need the full picture of how authoring, blocks, drop-ins, and Commerce APIs connect.

</Steps>

<details>
<summary>Reference — key runtime packages</summary>

The boilerplate ships these packages so drop-ins, analytics, and GraphQL clients work together. You do not need to memorize this table on day one. Open it when you are tracing dependencies or debugging install issues.

<TableWrapper nowrap={[0]}>

| Package | Purpose |
|---------|---------|
| <Link href="https://www.npmjs.com/package/@dropins/tools" text="@dropins/tools" /> | Shared utilities for all drop-ins (GraphQL client, event bus, initializers, UI components) |
| <Link href="https://github.com/adobe/adobe-client-data-layer" text="@adobe/adobe-client-data-layer" /> | Standardized data layer for event collection and analytics |
| <Link href="https://www.npmjs.com/package/@adobe/magento-storefront-event-collector" text="@adobe/magento-storefront-event-collector" /> | Collects Commerce-specific user interaction events |
| <Link href="https://www.npmjs.com/package/@adobe/magento-storefront-events-sdk" text="@adobe/magento-storefront-events-sdk" /> | SDK for sending events to Adobe Commerce for Live Search and Product Recommendations |

</TableWrapper>
