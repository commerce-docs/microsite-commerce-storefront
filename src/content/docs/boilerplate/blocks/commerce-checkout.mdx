## Overview

The **Commerce Checkout** block provides commerce functionality using drop-in components.

## Drop-ins Used

This block uses the following drop-in components:

- `@dropins/tools`
- [`@dropins/storefront-checkout`](/dropins/checkout/)
- [`@dropins/storefront-payment-services`](/dropins/payment-services/)

## Events

This block listens to the following events:

- `order/placed`
- `authenticated`
- `checkout/initialized`
- `checkout/updated`
- `checkout/values`

## Implementation

Block location: `/blocks/commerce-checkout/`
