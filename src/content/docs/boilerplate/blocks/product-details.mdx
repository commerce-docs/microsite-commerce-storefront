## Overview

The **Product Details** block provides commerce functionality using drop-in components.

**Block location**: `blocks/product-details/`

**Files:**
- `product-details.js` - JavaScript decorator and drop-in integration
- `product-details.css` - Block-specific styles



## Drop-ins Used

This block integrates the following drop-in components:

- `@dropins/tools`
- [`@dropins/storefront-pdp`](/dropins/product-details/) - Full documentation
- [`@dropins/storefront-wishlist`](/dropins/wishlist/) - Full documentation


## Implementation

### Containers

The following containers are rendered:

- **pdpRendered**
- **wishlistRender**
- **UI**






## Events

This block listens to the following events:

- `pdp/valid`
- `pdp/values`
- `wishlist/alert`
- `aem/lcp`




## Usage in Commerce Boilerplate

This block is part of the <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="AEM Commerce boilerplate" /> and is ready to use out of the box. For customization guidance, see the relevant drop-in documentation above.
