## Overview

The **Product List Page** block provides commerce functionality using drop-in components.

**Block location**: `blocks/product-list-page/`

**Files:**
- `product-list-page.js` - JavaScript decorator and drop-in integration
- `product-list-page.css` - Block-specific styles



## Drop-ins Used

This block integrates the following drop-in components:

- [`@dropins/storefront-product-discovery`](/dropins/product-discovery/) - Full documentation
- `@dropins/tools`
- [`@dropins/storefront-wishlist`](/dropins/wishlist/) - Full documentation
- [`@dropins/storefront-cart`](/dropins/cart/) - Full documentation
