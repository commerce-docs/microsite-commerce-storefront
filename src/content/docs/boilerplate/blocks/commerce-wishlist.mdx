## Overview

The **Commerce Wishlist** block provides commerce functionality using drop-in components.

## Drop-ins Used

This block uses the following drop-in components:

- [`@dropins/storefront-wishlist`](/dropins/wishlist/)
- [`@dropins/storefront-auth`](/dropins/user-auth/)
- `@dropins/tools`

## Containers

The following containers are rendered:

- **authRenderer**
- **wishlistRenderer**

## Events

This block listens to the following events:

- `authenticated`
- `wishlist/alert`

## Implementation

Block location: `/blocks/commerce-wishlist/`

- **JavaScript**: ✓
- **CSS**: ✓
