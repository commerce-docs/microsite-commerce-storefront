## Overview

The **Commerce Cart** block provides commerce functionality using drop-in components.

## Drop-ins Used

This block uses the following drop-in components:

- `@dropins/tools`
- [`@dropins/storefront-cart`](/dropins/cart/)
- [`@dropins/storefront-wishlist`](/dropins/wishlist/)

## Containers

The following containers are rendered:

- **UI**
- **provider**
- **wishlistRender**

## Events

This block listens to the following events:

- `wishlist/alert`

Block location: `/blocks/commerce-cart/`
