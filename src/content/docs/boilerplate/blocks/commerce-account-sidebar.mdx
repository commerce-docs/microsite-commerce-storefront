## Overview

The **Commerce Account Sidebar** block provides commerce functionality using drop-in components.

**Block location**: `blocks/commerce-account-sidebar/`

**Files:**
- `commerce-account-sidebar.js` - JavaScript decorator and drop-in integration
- `commerce-account-sidebar.css` - Block-specific styles
