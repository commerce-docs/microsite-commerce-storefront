## Overview

The **Commerce Mini Cart** block provides commerce functionality using drop-in components.

## Drop-ins Used

This block uses the following drop-in components:

- [`@dropins/storefront-cart`](/dropins/cart/)
- `@dropins/tools`

## Containers

The following containers are rendered:

- **UI**
- **provider**

## Events

This block listens to the following events:

- `cart/product/added`
- `cart/product/updated`

## Implementation

Block location: `/blocks/commerce-mini-cart/`

- **JavaScript**: ✓
- **CSS**: ✓
