## Overview

The **Commerce Mini Cart** block provides commerce functionality using drop-in components.

**Block location**: `blocks/commerce-mini-cart/`

**Files:**
- `commerce-mini-cart.js` - JavaScript decorator and drop-in integration
- `commerce-mini-cart.css` - Block-specific styles



## Drop-ins Used

This block integrates the following drop-in components:

- [`@dropins/storefront-cart`](/dropins/cart/) - Full documentation
- `@dropins/tools`


## Implementation

### Containers

The following containers are rendered:

- **UI**
- **provider**






## Events

This block listens to the following events:

- `cart/product/added`
- `cart/product/updated`




## Usage in Commerce Boilerplate

This block is part of the <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="AEM Commerce boilerplate" /> and is ready to use out of the box. For customization guidance, see the relevant drop-in documentation above.
