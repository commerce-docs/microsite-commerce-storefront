## Overview

The **Product Recommendations** block provides commerce functionality using drop-in components.

**Block location**: `blocks/product-recommendations/`

**Files:**
- `product-recommendations.js` - JavaScript decorator and drop-in integration
- `product-recommendations.css` - Block-specific styles



## Drop-ins Used

This block integrates the following drop-in components:

- `@dropins/tools`
- [`@dropins/storefront-recommendations`](/dropins/recommendations/) - Full documentation
- [`@dropins/storefront-wishlist`](/dropins/wishlist/) - Full documentation


## Implementation

### Containers

The following containers are rendered:

- **provider**
- **UI**
- **wishlistRender**

This block is part of the <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="AEM Commerce boilerplate" /> and is ready to use out of the box. For customization guidance, see the relevant drop-in documentation above.
