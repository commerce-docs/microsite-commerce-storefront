## Overview

The **Commerce Search Order** block provides commerce functionality using drop-in components.

## Drop-ins Used

This block uses the following drop-in components:

- [`@dropins/storefront-auth`](/dropins/user-auth/)
- [`@dropins/storefront-order`](/dropins/order/)
- `@dropins/tools`

## Containers

The following containers are rendered:

- **authRenderer**
- **orderRenderer**

## Events

This block listens to the following events:

- `order/data`
