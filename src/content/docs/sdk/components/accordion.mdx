Use `Accordion` to group related content into collapsible sections, such as product details or order summaries. Each section is an `AccordionSection` child that a shopper can expand or collapse.

## Import

```js
import { Accordion, AccordionSection } from '@dropins/tools/components.js';
```

`Accordion` also accepts standard `<div>` HTML attributes (for example, `className`), except `icon`.

Each `AccordionSection` takes its own props, including `title`, `ariaLabelTitle` (an accessible label for screen readers when the title is not a string), `defaultOpen` (whether the section starts expanded, defaults to false), `renderContentWhenClosed` (defaults to true), and `onStateChange` (a callback that receives the new open state).

## Example

Render an accordion with a single section. Build the `AccordionSection` children with `h`.

```js
import { Accordion, AccordionSection, provider as UI } from '@dropins/tools/components.js';
import { h } from '@dropins/tools/preact.js';

await UI.render(Accordion, {
  children: [
    h(
      AccordionSection,
      { title: 'Product details', ariaLabelTitle: 'Product details' },
      h('p', {}, 'Short product details should be kept to six lines maximum.'),
    ),
  ],
})(document.querySelector('.accordion'));
```
