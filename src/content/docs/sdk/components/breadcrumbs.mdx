Use `Breadcrumbs` to show a shopper where they are in the catalog hierarchy. Pass an array of category nodes, such as links; the trail renders only when you supply more than one category.

## Import

```js
import { Breadcrumbs } from '@dropins/tools/components.js';
```

## Props

<OptionsTable
compact
  options={[
    ['Prop', 'Type', 'Req?', 'Description'],
    ['categories', 'VNode[]', 'Yes', 'The categories to display in the breadcrumb trail.'],
    ['separator', 'VNode', 'No', 'Icon used to separate items. Defaults to a slash.'],
  ]}
/>

`Breadcrumbs` also accepts standard HTML attributes (for example, `className` and `aria-label`).

## Example

Render a breadcrumb trail of category links, with a custom separator icon.

```js
import { Breadcrumbs, Icon, provider as UI } from '@dropins/tools/components.js';
import { h } from '@dropins/tools/preact.js';

await UI.render(Breadcrumbs, {
  categories: [
    h('a', { href: '/' }, 'Home'),
    h('a', { href: '/men' }, 'Men'),
    h('a', {}, 'Shoes'),
  ],
  separator: h(Icon, { source: 'ChevronRight', size: '16' }),
})(document.querySelector('.breadcrumbs'));
```
