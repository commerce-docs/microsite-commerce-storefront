Use `Divider` to separate and group content or build rhythm and structure. It renders a styled `<hr>` element.

## Import

```js
import { Divider } from '@dropins/tools/components.js';
```

## Props

<OptionsTable
compact
  options={[
    ['Prop', 'Type', 'Req?', 'Description'],
    ['variant', "'primary' | 'secondary'", 'No', 'Change the divider style. Defaults to primary.'],
  ]}
/>

`Divider` also accepts standard HTML attributes (for example, `className`).

## Example

```js
import { Divider, provider as UI } from '@dropins/tools/components.js';

await UI.render(Divider, { variant: 'secondary' })(document.querySelector('.divider'));
```
