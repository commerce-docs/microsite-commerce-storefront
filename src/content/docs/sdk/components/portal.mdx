Use `Portal` to render content into a separate DOM node appended to `document.body`, so overlays such as modals, tooltips, and popovers can escape the parent's layout and stacking constraints. The portal node is created on mount and removed on unmount.

## Import

```js
import { Portal } from '@dropins/tools/components.js';
```

## Example

Render content into the portal root. Build the children with `h`.

```js
import { Portal, provider as UI } from '@dropins/tools/components.js';
import { h } from '@dropins/tools/preact.js';

await UI.render(Portal, {
  children: h('div', { className: 'overlay' }, 'Overlay content'),
})(document.querySelector('.portal-mount'));
```
