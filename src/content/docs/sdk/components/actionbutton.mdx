Use `ActionButton` to let a shopper complete an action or select an item in a workflow. It renders a styled `<button>` that can show a label, an icon, or both.

## Import

```js
import { ActionButton } from '@dropins/tools/components.js';
```

## Props

<OptionsTable
compact
  options={[
    ['Prop', 'Type', 'Req?', 'Description'],

    ['icon', 'VNode', 'No', 'Add an Icon component to the button.'],
    ['active', 'boolean', 'No', 'Render the active state. Defaults to false.'],
    ['disabled', 'boolean', 'No', 'Disable the button. Defaults to false.'],
  ]}
/>

`ActionButton` also accepts standard button HTML attributes (for example, `onClick`, `className`, and `aria-label`), except `icon`.

## Example

Render an action button with a label, an icon, and a click handler. Pass the `icon` prop an `Icon` VNode created with `h`.

```js
import { ActionButton, Icon, provider as UI } from '@dropins/tools/components.js';
import { h } from '@dropins/tools/preact.js';

await UI.render(ActionButton, {
  children: 'Add',
  icon: h(Icon, { source: 'Add' }),
  onClick: () => yourAddItem(),
})(document.querySelector('.action-button'));
```
