Use `InputDate` to capture a date in a form. It builds on the [Input](/sdk/components/input/) component, adding date entry and field-specific validation.

## Import

```js
import { InputDate } from '@dropins/tools/components.js';
```

## Props

<OptionsTable
compact
  options={[
    ['Prop', 'Type', 'Req?', 'Description'],
    ['label', 'string', 'No', 'Displayed field label.'],
    ['name', 'string', 'No', 'Form field identifier.'],
    ['value', 'string', 'No', 'The date value as an ISO date string (for example, 2026-01-15).'],
    ['error', 'string', 'No', 'Field-specific error message.'],
  ]}
/>

`InputDate` inherits the remaining [Input](/sdk/components/input/) props (such as `onChange`, `onBlur`, `disabled`, and `placeholder`), except `error` and `value`, which it redefines above.

## Example

```js
import { InputDate, provider as UI } from '@dropins/tools/components.js';

await UI.render(InputDate, {
  name: 'birthdate',
  label: 'Birthdate',
  value: '2023-07-29',
  onChange: (event) => yourSaveBirthdate(event.target.value),
})(document.querySelector('.birthdate'));
```
