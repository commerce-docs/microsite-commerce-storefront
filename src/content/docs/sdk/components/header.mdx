Use `Header` to render a titled section header with an optional divider and call-to-action. It suits modal, sheet, and fullscreen flows across Commerce drop-ins. The component renders nothing when `title` is empty.

## Import

```js
import { Header } from '@dropins/tools/components.js';
```

## Props

<OptionsTable
compact
  options={[
    ['Prop', 'Type', 'Req?', 'Description'],

    ['size', "'medium' | 'large'", 'No', 'Change the header size. Defaults to medium.'],
    ['divider', 'boolean', 'No', 'Show a divider beneath the title. Defaults to true.'],
    ['cta', 'VNode', 'No', 'A call-to-action element, such as a Button or link, rendered beside the title.'],
    ['level', '1 | 2 | 3 | 4 | 5 | 6', 'No', 'Heading level for the title. Without it, the title renders as a span.'],
  ]}
/>

`Header` also accepts standard HTML attributes (for example, `className`), except `size`.

## Example

Render a header with a title, a heading level, and a call-to-action button:

```js
import { Header, Button, provider as UI } from '@dropins/tools/components.js';
import { h } from '@dropins/tools/preact.js';

await UI.render(Header, {
  title: 'Shipping info',
  size: 'medium',
  level: 2,
  divider: true,
  cta: h(Button, { variant: 'tertiary', children: 'Print order details' }),
})(document.querySelector('.header'));
```
