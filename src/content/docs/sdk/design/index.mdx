The Base design system holds the design tokens behind every SDK component: the color, type, spacing, shape, and grid values that give the components a consistent look. When you skin your storefront with these tokens, your custom UI stays on-brand and matches the drop-ins already in place.

## Topics

- [Colors](/sdk/design/colors/) — Color tokens for hierarchy, state, and brand
- [Typography](/sdk/design/typography/) — Type scale for clear, readable content
- [Spacing](/sdk/design/spacing/) — Spacing scale for consistent visual rhythm
- [Shapes](/sdk/design/shapes/) — Shadows, strokes, and fills that draw attention
- [Grids](/sdk/design/grid/) — Breakpoints, gutters, and columns for responsive layouts
