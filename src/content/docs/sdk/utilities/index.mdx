The utilities are small helper functions that handle common tasks when you work with the SDK, from reading form values and cookies to merging objects and debouncing input. Each one is lightweight and works alongside the SDK's components and core APIs.

## Topics

- [classList](/sdk/utilities/classlist/) — Build CSS class name strings from conditions
- [debounce](/sdk/utilities/debounce/) — Delay a callback until input stops
- [deepmerge](/sdk/utilities/deepmerge/) — Deeply merge two or more objects
- [getCookie](/sdk/utilities/getcookie/) — Read a document cookie by name
- [getFormErrors](/sdk/utilities/getformerrors/) — Collect validation errors from a form
- [getFormValues](/sdk/utilities/getformvalues/) — Read form fields into a JavaScript object
- [getPathValue](/sdk/utilities/getpathvalue/) — Safely read nested values with dot-path keys
