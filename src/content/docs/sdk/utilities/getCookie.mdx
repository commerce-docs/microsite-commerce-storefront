---
title: getCookie
description: Read browser cookie values by name in the Adobe Commerce Storefront SDK so cart, auth, and session helpers can share lightweight client-side state.
---

Takes in a cookie name and returns the value of the cookie.

## Params

Signature: `getCookie(cookieName)`

`cookieName`
: The name of the cookie to get

## Returns

Returns the value of the cookie.

## Examples

```ts
import { getCookie } from '@adobe-commerce/elsie/lib';

const result = getCookie('foo');

console.log(result); // "bar"
```
