The reference section documents the core SDK APIs that every drop-in relies on: how components start up, render, talk to each other, and connect to Commerce services. Reach for these pages when you extend a drop-in or build your own.

## Topics

- [Events](/sdk/reference/events/) — Send and receive messages so drop-ins stay in sync
- [GraphQL](/sdk/reference/graphql/) — Extend a drop-in's GraphQL operations without forking
- [Initializer](/sdk/reference/initializer/) — Configure and start a drop-in package
- [Links](/sdk/reference/links/) — Build composable, accessible storefront navigation
- [reCAPTCHA](/sdk/reference/recaptcha/) — Add bot protection to storefront forms
- [Render](/sdk/reference/render/) — Mount drop-ins in the DOM with a provider
- [Slots](/sdk/reference/slots/) — Insert custom content into drop-in extension points
- [VComponent](/sdk/reference/vcomponent/) — Pass custom headers, footers, and nodes into containers
