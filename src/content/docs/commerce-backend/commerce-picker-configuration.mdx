Before a content author can use the [Commerce Picker](/merchants/storefront-builder/commerce-picker/) extension in Document Authoring, set the root category ID in your project's `config.json` file. The [`plugins.picker.rootCategory`](/setup/configuration/commerce-configuration/#plugins) setting determines which category the picker uses as its initial point when browsing products.

<Steps>
1. In Adobe Commerce Admin, go to **Catalog** > **Categories** and select the category you want the picker to use as its starting point.

   The category ID appears in parentheses after the category name at the top of the page. See <Link href="https://experienceleague.adobe.com/en/docs/commerce-admin/catalog/categories/create/category-create" text="Create categories" /> for more on locating category IDs.

1. Set that ID under `"plugins.picker.rootCategory"` in your project's `config.json` file. Refer to the <Link href="https://main--aem-boilerplate-commerce--hlxsites.aem.live/config.json" text="demo configuration" /> for an example.
</Steps>

Once `config.json` is set, provide the storefront to your content author to finish [installing the Commerce Picker](/merchants/storefront-builder/commerce-picker/#for-the-document-authoring-tool).
