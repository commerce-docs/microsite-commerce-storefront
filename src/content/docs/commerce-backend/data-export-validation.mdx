Data export synchronizes data between an Adobe Commerce instance and connected [Commerce services](/get-started/architecture/commerce-services-and-backends/#commerce-services). Those services are required for drop-in components to work correctly.

Validating the data export is crucial to ensure that the data is correctly synchronized and available for the storefront. You can use the <Link href={"https://experienceleague.adobe.com/en/docs/commerce-admin/systems/data-transfer/data-sync/data-dashboard"} text={"Data Management Dashboard"} /> to monitor the data sync progress for each service.

:::tip[Self-service data export validation]
See the <Link href={"https://experienceleague.adobe.com/en/docs/commerce/saas-data-export/overview"} text={"_SaaS Data Export Guide_"} /> for details and troubleshooting.
:::

Use GraphQL to validate that all products were synchronized and product lookup and search are working. See <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/catalog-service/queries/products/"} text={"GraphQL queries"} /> and <Link href={"https://github.com/magento/adobe-commerce-catalog-service"} text={"Postman sample collection"} /> for queries.

For more complex catalogs, reach out to the Adobe team on <Link href={"https://discord.com/channels/1131492224371277874/1220042081209421945"} text={"Discord"} /> to validate that the exported data is correct. This might require you to provide a database dump or direct access. Please also reach out to the Adobe team if you encounter any currently unsupported use cases, so that they can be enabled in the future.
