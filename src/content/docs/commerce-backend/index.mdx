After you connect your storefront to a Commerce backend in [Create a storefront](/get-started/create-storefront/), use these topics to adjust that connection, secure cross-origin requests, or turn on optional features such as multistore and gated content.

<TableWrapper nowrap={[0]}>

| Topic | What it covers |
|-------|-----------------|
| [Storefront configuration](/setup/configuration/commerce-configuration/) | Connect your storefront to your Commerce backend using the public config or a `config.json` file. |
| [CDN configuration](/setup/configuration/content-delivery-network/) | Set up the CDN that delivers your storefront's content. |
| [CORS Setup](/setup/configuration/cors-setup/) | Configure CORS headers so your storefront's domain can call your Commerce GraphQL endpoint. |
| [CORS Troubleshooting](/setup/configuration/cors-troubleshooting/) | Diagnose and resolve CORS errors between your storefront and your Commerce backend. |
| [AEM Assets integration](/setup/configuration/aem-assets-configuration/) | Display product images managed in AEM Assets instead of Commerce-hosted images. |
| [Enrichment configuration](/setup/configuration/enrichment/) | Configure query.yaml so content authors can add enrichment content to product pages. |
| [Commerce Picker configuration](/setup/configuration/commerce-picker/) | Set the root category ID so content authors can browse the catalog with the Commerce Picker extension. |
| [Gated content](/setup/configuration/gated-content/) | Restrict access to non-Commerce assets, such as images or pages, that customer segments can't control. |
| [Compatibility Package](/setup/configuration/storefront-compatibility/) | Add the package that bridges older Adobe Commerce versions and B2B stores to the storefront. |
| [Price Book ID setup](/setup/configuration/price-book-setup/) | Enable Adobe Commerce Optimizer Price Book ID support for personalized pricing. |
| [Multistore setup](/setup/configuration/multistore-setup/) | Run multiple storefronts for different languages, regions, or brands from one codebase. |
| [Data export validation](/setup/discovery/data-export-validation/) | Confirm that data exports from your Commerce backend are reaching your storefront correctly. |
| [Luma Bridge](/setup/discovery/luma-bridge/) | Migrate a theme-based Adobe Commerce storefront to Edge Delivery Services in phases. |

</TableWrapper>
