Add a block table to a document to place a shopping feature or content element on your page. Your storefront must already support the block you choose; adding a new block implementation requires a developer.

## Before you begin

- Open the page in [Document Authoring](/merchants/quick-start/document-authoring/).
- Find the block name and required settings in the [Commerce block reference](/merchants/blocks/), or use a content block supported by your storefront.
- Make sure you have permission to preview and publish the page.

## Add the block

<Steps>

1. Insert a table where you want the block to appear in the document.
1. Enter the block name in the first row, for example, `commerce-cart`. If the table has two columns, merge the cells in this row.
1. Add the settings required by the block's reference page. Put the setting name in the first column and its value in the second column. Some blocks need only the name row.
1. Preview the page and confirm that the block appears where you placed it.
1. Publish the page when the result looks right.

</Steps>

For examples of settings and merged content rows, see [Block table structure](/merchants/blocks/block-tables/).

## Check the result

Open the published page and confirm that the block appears with the settings you chose. If it does not appear, check the block name and required rows against its reference page.

For an example that also includes page metadata and section styling, follow [Create your first commerce page](/how-tos/create-commerce-page/).
