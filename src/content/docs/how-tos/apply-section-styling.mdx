Apply a supported style to the section around your content or Commerce blocks. Section metadata changes the section's presentation; it does not change an individual block's settings.

## Before you begin

Open the page in [Document Authoring](/merchants/quick-start/document-authoring/) and choose a style supported by your storefront. See [Section metadata](/merchants/blocks/section-metadata/) for the table format and supported property types.

<Aside type="note">
Your developer defines the available styles. Adding a style name to a document does not create its styling. Ask your developer before using a new style.
</Aside>

## Add section metadata

<Steps>

1. Find the section containing the blocks you want to style.
1. Insert a two-column table below those blocks, within the same section. If a section-metadata table already exists, update it instead.
1. Merge the cells in the first row and enter `section-metadata`.
1. Add a row with `Style` in the first cell and the supported style name in the second cell. For example, use `highlight` only if your storefront supports that style.
1. Save your changes and preview the page. Confirm that the intended section has changed, not an adjacent section.
1. Publish the page when the result looks right.

</Steps>

## Check the result

Open the published page and confirm that the style applies to the intended section. If nothing changes, check the style name with your developer and confirm that the metadata table is in the same section as the content.
