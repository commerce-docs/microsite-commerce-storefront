Set a page's title, description, or Commerce properties by adding a metadata table to its document. These settings apply to the page, rather than to one block or section.

## Before you begin

Open your page in [Document Authoring](/merchants/quick-start/document-authoring/). Choose the properties you need from the [Page metadata reference](/merchants/blocks/page-metadata/), and check that you can preview and publish the page.

## Add the metadata table

<Steps>

1. Find the existing metadata table in your document. If there is none, insert a table with two columns above your Commerce blocks.
1. Merge the cells in the first row and enter `metadata`.
1. Add a row for each property. For example, enter `Title` in the first cell and your page title in the second cell.
1. Add a `Description` row with a short description of the page. Keep any existing properties the page needs, such as `sku` or `template`.
1. Save your changes, then preview the page and check its browser-tab title.
1. Publish the page when the title and page content look right.

</Steps>

## Check the result

Open the published page and confirm that its browser-tab title matches the value you entered. Use the [metadata examples](/merchants/blocks/page-metadata/#examples) when you need social-sharing settings, Commerce properties, or a custom template.
