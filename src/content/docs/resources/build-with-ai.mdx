AI-powered editors and agentic coding tools generally have good knowledge of common web patterns, Adobe Commerce concepts, and documentation conventions. However, they may not reflect the newest APIs, drop-in versions, or Edge Delivery Services–specific guidance until their training data or tools are updated.

This guide explains how to give AI tools better context for **Adobe Commerce Storefront** documentation and suggests practical ways to work with the static **context files** this site publishes for machine consumption.

## Context files

This documentation site publishes several **static text bundles** derived from the same source as the pages you see in the browser. They are streamlined for AI and script consumption (Markdown-oriented text), not a replacement for reading the site.

| File | Purpose |
|------|---------|
| [`llms.txt`](https://experienceleague.adobe.com/developer/commerce/storefront/llms.txt) | Index file: overview and links to all documentation sets (full, abridged, and topic bundles under `_llms-txt/`). |
| [`llms-full.txt`](https://experienceleague.adobe.com/developer/commerce/storefront/llms-full.txt) | Complete documentation in one file. |
| [`llms-small.txt`](https://experienceleague.adobe.com/developer/commerce/storefront/llms-small.txt) | Abridged bundle (same content as the full export except the long-form release changelog page). |
| `_llms-txt/*.txt` | Smaller topical exports (for example [drop-ins reference](https://experienceleague.adobe.com/developer/commerce/storefront/_llms-txt/dropins-reference.txt), [tutorials](https://experienceleague.adobe.com/developer/commerce/storefront/_llms-txt/tutorials-reference.txt), [blocks](https://experienceleague.adobe.com/developer/commerce/storefront/_llms-txt/blocks-reference.txt)). All bundle URLs are listed from [`llms.txt`](https://experienceleague.adobe.com/developer/commerce/storefront/llms.txt). |

Some tools can **auto-discover** these files when you provide the documentation site as a context or “docs” source—for example:

`https://experienceleague.adobe.com/developer/commerce/storefront`

These exports are **large** and will consume many tokens if you load them whole into a model context. They are rebuilt when the site is published and are best treated as a **fallback** when an AI tool cannot search or fetch the live documentation. Whenever possible, prefer **browsing or searching** this site on Experience League so you always see the latest edits, navigation, and diagrams.

:::note
Context files are generated at build time from the documentation source in this project. They may lag brief editorial changes until the next deployment.
:::

## Tips

- Start from the [Commerce boilerplate](https://github.com/hlxsites/aem-boilerplate-commerce) and this site’s [Get started](/get-started/) topics when scoping AI-assisted changes.
- Ask tools to **verify** APIs and version-specific behavior against the live docs or your target Commerce environment, not only against a pasted export.
- Use **topic bundles** under `_llms-txt/` when you need a smaller slice (for example drop-ins or tutorials only) instead of pasting the full `llms-full.txt` file.
