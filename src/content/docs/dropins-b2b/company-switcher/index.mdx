The Company Switcher drop-in enables multi-company user access and company context switching for Adobe Commerce storefronts. It also supports company context retrieval and automatic graphql header management.

## Supported Commerce features

The following table provides an overview of the Adobe Commerce features that the Company Switcher drop-in supports:

| Feature | Status |
| ------- | ------ |
| Multi-company user access | <Badge text="Supported" variant="tip" /> |
| Company context switching | <Badge text="Supported" variant="tip" /> |
| Company context retrieval | <Badge text="Supported" variant="tip" /> |
| Automatic GraphQL header management | <Badge text="Supported" variant="tip" /> |
| Customer group header management | <Badge text="Supported" variant="tip" /> |
| Real-time context change events | <Badge text="Supported" variant="tip" /> |
| Data isolation across companies | <Badge text="Supported" variant="tip" /> |
| Permission-based access control | <Badge text="Supported" variant="tip" /> |
| Session persistence | <Badge text="Supported" variant="tip" /> |
| GraphQL API integration | <Badge text="Supported" variant="tip" /> |
