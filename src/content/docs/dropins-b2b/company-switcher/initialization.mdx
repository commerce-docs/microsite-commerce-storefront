## Basic initialization

Initialize the drop-in with default settings:

```javascript title="scripts/initializers/company-switcher.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-company-switcher';

await initializers.mountImmediately(initialize, {});
```

## Language definitions

Override dictionary keys for localization or branding. The `langDefinitions` object maps locale keys to custom strings that override the drop-in's default text.

```javascript title="scripts/initializers/company-switcher.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-company-switcher';

const customStrings = {
  'AddToCart': 'Add to Bag',
  'Checkout': 'Complete Purchase',
  'Price': 'Cost',
};

const langDefinitions = {
  default: customStrings,
};

await initializers.mountImmediately(initialize, { langDefinitions });
```

## Drop-in-specific configuration

The **Company Switcher** drop-in provides additional configuration options beyond the standard `langDefinitions`. These options customize company context management, header injection, and session persistence.

```javascript title="scripts/initializers/company-switcher.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-company-switcher';
import { fetchGraphQl as cartFetchGraphQl } from '@dropins/storefront-cart/api.js';
import { fetchGraphQl as checkoutFetchGraphQl } from '@dropins/storefront-checkout/api.js';

await initializers.mountImmediately(initialize, {
  // Apply company headers to Cart and Checkout GraphQL requests
  fetchGraphQlModules: [cartFetchGraphQl, checkoutFetchGraphQl],
  // Customize header names if needed
  companyHeader: 'X-Adobe-Company',
  customerGroupHeader: 'Magento-Customer-Group',
  // Customize session storage keys if needed
  companySessionStorageKey: 'DROPIN__COMPANYSWITCHER__COMPANY__CONTEXT',
  groupSessionStorageKey: 'DROPIN__COMPANYSWITCHER__GROUP__CONTEXT',
});
```

<Aside type="note">
The `fetchGraphQlModules` array determines which drop-ins will have company context headers automatically applied to their GraphQL requests. This ensures that company-specific data is correctly scoped across your application.
</Aside>



## Configuration types

The following TypeScript definitions show the structure of each configuration object:

### langDefinitions

Maps locale identifiers to dictionaries of key-value pairs. The `default` locale is used as the fallback when no specific locale matches. Each dictionary key corresponds to a text string used in the drop-in UI.

```typescript
langDefinitions?: {
  [locale: string]: {
    [key: string]: string;
  };
};
```
