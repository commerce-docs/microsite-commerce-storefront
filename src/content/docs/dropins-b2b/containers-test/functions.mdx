The Containers Test API functions allow developers to integrate their own internal logic, enabling the creation of custom behaviors and functionality.

## functionName

The `functionName` function [describe what the function does]. The function calls the [`graphqlMutation`](https://developer.adobe.com/commerce/webapi/graphql/schema/) mutation.

```ts
export const functionName = async (
  parameter: ParameterType
): Promise<ReturnType | null>
```

### Returns

Returns a promise that resolves to a `ReturnType` object or null. The `ReturnType` object has the following shape:

```ts
type ReturnType = {
  property1: string;
  property2: number;
  // Add other properties as needed
};
```

### Events

The event bus emits the `event/name` event with the data as the payload.

### Usage

To use this function:

```js
import { functionName } from '@/containers-test/api/functionName';

functionName(parameter);
```
