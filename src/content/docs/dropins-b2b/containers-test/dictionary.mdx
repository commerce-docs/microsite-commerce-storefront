The default Containers Test dictionary includes the default English values for all labels and text common to the Containers Test drop-in component.

## Default keys and values

The dictionary file for Containers Test will be available at:
`@dropins/storefront-containers-test/i18n/en_US.json`

```json
{
  "containers-test": {
    "title": "Containers Test",
    "description": "Description for Containers Test component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-containers-test/i18n/en_US.json.d.ts?raw';
```
:::
