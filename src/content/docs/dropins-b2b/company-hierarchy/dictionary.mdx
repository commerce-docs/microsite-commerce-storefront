The `CompanyHierarchy` container uses dictionary keys from the **Company Management** drop-in. Customize labels and messages during initialization to localize the hierarchy UI or match your brand voice.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Package: @dropins/storefront-company-management</strong>
</div>

## How to customize

Override dictionary values during drop-in initialization. The drop-in deep-merges your custom values with the defaults.

```javascript
import { initialize } from '@dropins/storefront-company-management';

await initialize({
  langDefinitions: {
    en_US: {
      "Company": {
        "CompanyHierarchy": {
          "containerTitle": "Organization Structure",
          "messages": {
            "loading": "Loading organization data..."
          }
        }
      }
    }
  }
});
```

You only need to include the keys you want to change. For multi-language support and advanced patterns, see the [Dictionary customization guide](/dropins/all/dictionaries/).

<Aside type="note">
The container also reuses shared expand and collapse button labels from `Company.CompanyStructure.shared`. See [Company Management dictionary](/dropins-b2b/company-management/dictionary/) for those keys.
</Aside>
