## CompanyHierarchy slots

The slots for the `CompanyHierarchy` container allow you to customize toolbar actions.

```typescript
interface CompanyHierarchyProps {
  slots?: {
    Actions?: SlotProps<HierarchyActionsContext>;
  };
}
```

### HierarchyActionsContext

The `Actions` slot receives the following context properties:

<TableWrapper nowrap={[0,1]}>

| Property | Type | Description |
| --- | --- | --- |
| `expandAll` | `() => void` | Expands all tree nodes. |
| `collapseAll` | `() => void` | Collapses all nodes except the virtual root. |
| `expandedIds` | `Set<string>` | Current set of expanded node IDs. |
| `setExpandedIds` | `(ids: Set<string>) => void` | Programmatically controls expansion state. |
| `treeItemsCount` | `number` | Total number of companies in the hierarchy. |

</TableWrapper>

### Actions slot

The `Actions` slot replaces the default **Expand All** and **Collapse All** buttons. Use it to add custom-styled controls, export actions such as "Export to PDF" or "Print Structure", custom filtering or search above the tree, company count badges or hierarchy statistics, or analytics tracking for expand and collapse events.

#### Example

```js
import { render as provider } from '@dropins/storefront-company-management/render.js';
import { CompanyHierarchy } from '@dropins/storefront-company-management/containers/CompanyHierarchy.js';
import { Button } from '@adobe-commerce/elsie/components';

await provider.render(CompanyHierarchy, {
  withHeader: true,
  slots: {
    Actions: ({ expandAll, collapseAll, treeItemsCount }) => (
      <div className="custom-actions">
        <Button onClick={expandAll}>Open All ({treeItemsCount})</Button>
        <Button onClick={collapseAll}>Close All</Button>
        <Button>Export Structure</Button>
      </div>
    ),
  },
})(block);
```

<Aside type="tip">
When you omit the `Actions` slot, the container renders the default expand and collapse toolbar buttons.
</Aside>
