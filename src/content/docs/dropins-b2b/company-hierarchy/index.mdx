The Company Hierarchy container is part of the <Link href="https://github.com/adobe-commerce/storefront-company-management" text="storefront-company-management" /> drop-in. It gives company administrators an interactive tree view for parent-child company relationships, including drag-and-drop reassignment.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Package: @dropins/storefront-company-management</strong>
</div>

<Aside type="caution">
Company Hierarchy supports only a single level of nesting. A child company cannot have its own child companies.
</Aside>

## Supported Commerce features

The following table provides an overview of the Adobe Commerce features that the Company Hierarchy container supports:

| Feature | Status |
| ------- | ------ |
| Interactive company hierarchy tree | <Badge text="Supported" variant="tip" /> |
| Parent-child company relationships | <Badge text="Supported" variant="tip" /> |
| Drag-and-drop hierarchy reassignment | <Badge text="Supported" variant="tip" /> |
| Expand and collapse tree nodes | <Badge text="Supported" variant="tip" /> |
| Company Administrator access control | <Badge text="Supported" variant="tip" /> |
| Admin badge display | <Badge text="Supported" variant="tip" /> |
