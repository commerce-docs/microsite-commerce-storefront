## Root container

The container root uses the `account-company-hierarchy` class. Pass a custom `className` prop to add your own classes alongside it.

```css
.account-company-hierarchy.custom-hierarchy-styling {
  max-width: 960px;
}
```

## Customization tips

- Root companies use `.company-hierarchy-icon.is-root` and dashed borders on level-2 tree items.
- Selected rows show a brand-colored border on `.acm-tree__item[aria-selected="true"]`.
- Drag handles hide on touch devices through a `(hover: none) and (pointer: coarse)` media query.
- Use the browser DevTools to inspect live class names when you add block-level overrides.
