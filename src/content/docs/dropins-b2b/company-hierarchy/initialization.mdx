The `CompanyHierarchy` container uses the shared **Company Management initializer**. Initialize the drop-in before you render the container so GraphQL endpoints, language definitions, and dictionary values are available.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Package: @dropins/storefront-company-management</strong>
</div>

## Basic initialization

Initialize the drop-in with default settings:

```javascript title="scripts/initializers/company-management.js"
import { initializers } from '@dropins/tools/initializer.js';
import { initialize } from '@dropins/storefront-company-management';

await initializers.mountImmediately(initialize, {});
```

<Aside type="note" title="Shared initializer">
The Company Hierarchy container does not have a separate initializer. Use the same `company-management.js` initializer as other containers in this package. See [Company Management initialization](/dropins-b2b/company-management/initialization/) for full configuration options.
</Aside>

## Dictionary overrides

To customize hierarchy labels and messages, pass `langDefinitions` during initialization. See [Company Hierarchy dictionary](/dropins-b2b/company-hierarchy/dictionary/) for the key paths used by this container.
