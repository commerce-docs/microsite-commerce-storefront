## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. The `CompanyHierarchy` container provides a complete hierarchy tree with drag-and-drop support and can be customized through props and slots.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [CompanyHierarchy](/dropins-b2b/company-hierarchy/containers/company-hierarchy/) | Displays and manages parent-child company relationships in an interactive tree view with drag-and-drop reassignment. |
