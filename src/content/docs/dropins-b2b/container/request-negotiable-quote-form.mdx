The `RequestNegotiableQuoteForm` container renders an authenticated-only form for collecting data to create a negotiable quote. It provides validation and handlers, and exposes slots so you can extend or replace each UI component.

## Supported slots

The `RequestNegotiableQuoteForm` container supports the following slots:

- ErrorBanner
- SuccessBanner
- Title
- CommentField
- QuoteNameField
- AttachFileField

## Example configuration

The following example demonstrates how to render the `RequestNegotiableQuoteForm` container with custom handlers and a few overridden slots:

```js
provider.render(RequestNegotiableQuoteForm, {
  cartId, // required cart identifier used by the request

  // Called when the user submits "Request quote" (non-draft)
  onRequestNegotiableQuote: async ({ cartId, quoteName, comment, isDraft }) => {},

  // Called when the user submits "Save as draft"
  onSaveNegotiableQuote: async ({ cartId, quoteName, comment, isDraft }) => {},

  // Called when files are attached (array of File objects)
  onAttachFiles: async (files) => {},

  onError: ({ error, isFormDisabled, setIsFormDisabled }) => {
    console.error(error);
  },

  slots: {
    // Title slot: render provided text
    Title: (ctx) => {
      const heading = document.createElement('h2');
      heading.textContent = ctx.text;
      ctx.appendChild(heading);
    },

    CommentField: (ctx) => {
      const textarea = document.createElement('textarea');
      textarea.name = 'comment';
      textarea.required = true;
      textarea.disabled = !!ctx.isFormDisabled;
      textarea.value = ctx.value || '';
      // Optionally render ctx.errorMessage near the field
      ctx.appendChild(textarea);
    },

    QuoteNameField: (ctx) => {
      const input = document.createElement('input');
      input.type = 'text';
      input.name = 'quoteName';
      input.required = true;
      input.disabled = !!ctx.isFormDisabled;
      input.value = ctx.value || '';
      // Optionally render ctx.errorMessage near the field
      ctx.appendChild(input);
    },

    AttachFileField: (ctx) => {
      const input = document.createElement('input');
      input.type = 'file';
      input.disabled = !!ctx.isFormDisabled;
      input.onchange = () => {
        const files = Array.from(input.files || []);
        ctx.onChange && ctx.onChange(files);
      };
      ctx.appendChild(input);
    },
  },
})(containerWrapper);
```
