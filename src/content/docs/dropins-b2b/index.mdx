B2B drop-ins are pre-built, customizable UI components that provide complete B2B commerce functionality for your storefront. Each drop-in handles a specific aspect of the business-to-business shopping experience, from company management to purchase order workflows.

## Available B2B drop-ins

<TableWrapper nowrap={[0]}>

| Drop-in | Description |
| ------- | ----------- |
| [Company Management](/dropins-b2b/company-management/) | Enables company profile management and role-based permissions for Adobe Commerce storefronts. |
| [Company Hierarchy](/dropins-b2b/company-hierarchy/) | Displays and manages parent-child company relationships in an interactive tree view for company administrators. |
| [Company Switcher](/dropins-b2b/company-switcher/) | Provides a UI component for users to switch between multiple companies they are associated with. |
| [Purchase Order](/dropins-b2b/purchase-order/) | Manages purchase order workflows, approval rules, and purchase order history for B2B transactions. |
| [Quote Management](/dropins-b2b/quote-management/) | Enables negotiable quotes for B2B customers with quote request, negotiation, and approval workflows. |
| [Quick Order](/dropins-b2b/quick-order/) | Bulk ordering by SKU, search, and CSV upload; Quick Order page and Grid Ordering for configurable products on PDP. |
| [Requisition List](/dropins-b2b/requisition-list/) | Provides tools for creating and managing requisition lists for repeat purchases and bulk ordering. |

</TableWrapper>
