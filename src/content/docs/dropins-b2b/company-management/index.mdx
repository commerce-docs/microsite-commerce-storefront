The Company Management drop-in enables company profile management and role-based permissions for Adobe Commerce storefronts. It also supports legal address management and company contact information.

## Supported Commerce features

The following table provides an overview of the Adobe Commerce features that the Company Management drop-in supports:

| Feature | Status |
| ------- | ------ |
| Company profile management | <Badge text="Supported" variant="tip" /> |
| Role-based permissions | <Badge text="Supported" variant="tip" /> |
| Legal address management | <Badge text="Supported" variant="tip" /> |
| Company contact information | <Badge text="Supported" variant="tip" /> |
| Payment methods configuration | <Badge text="Supported" variant="tip" /> |
| Shipping methods configuration | <Badge text="Supported" variant="tip" /> |
| Multi-language support | <Badge text="Supported" variant="tip" /> |
| Custom regions for international addresses | <Badge text="Supported" variant="tip" /> |
| Email validation | <Badge text="Supported" variant="tip" /> |
| GraphQL API integration | <Badge text="Supported" variant="tip" /> |
| Company hierarchy management | <Badge text="Supported" variant="tip" /> |
| Advanced user role management | <Badge text="Supported" variant="tip" /> |
