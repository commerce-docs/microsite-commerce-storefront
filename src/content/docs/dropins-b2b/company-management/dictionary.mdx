The default Company Management dictionary includes the default English values for all labels and text common to the Company Management drop-in component.

## Default keys and values

The dictionary file for Company Management will be available at:
`@dropins/storefront-company-management/i18n/en_US.json`

```json
{
  "company-management": {
    "title": "Company Management",
    "description": "Description for Company Management component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-company-management/i18n/en_US.json.d.ts?raw';
```
:::
