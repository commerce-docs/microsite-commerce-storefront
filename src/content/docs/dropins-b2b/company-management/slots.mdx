## CompanyProfile slots

The slots for the `CompanyProfile` container allow you to customize its appearance and behavior.

interface CompanyProfileProps {

### CompanyData slot

The `CompanyData` slot allows you to customize the company data display section of the `CompanyProfile` container. The slot receives context with an array of company data properties including name, label, and value for each field.

#### Context properties

The slot receives the following context properties:

- **`companyData`** - Array of company data properties, each containing:
  - `name` - Field name identifier
  - `label` - Display label for the field
  - `value` - Current value of the field

#### Example

```js
import { render as provider } from '@dropins/storefront-company-management/render.js';
import { CompanyProfile } from '@dropins/storefront-company-management/containers/CompanyProfile.js';

await provider.render(CompanyProfile, {
  slots: {
    CompanyData: (ctx) => {
      // Access company data from context
      const { companyData } = ctx;
      
      // Create custom display
      const element = document.createElement('div');
      element.className = 'custom-company-data';
      
      companyData.forEach(item => {
        const field = document.createElement('div');
        field.innerHTML = `<strong>${item.label}:</strong> ${item.value}`;
        element.appendChild(field);
      });
      
      ctx.appendChild(element);
    }
  }
})(block);
```
