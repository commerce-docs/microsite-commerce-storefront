## Slots

This container exposes the following slots for customization:

| Slot | Type | Required | Description |
|------|------|----------|-------------|
| `slots` | `CompanyFormSlots` | No | Object containing custom slot implementations for individual form fields. Use the pattern `CompanyFormInput_{fieldCode}` to customize specific form inputs (e.g., `CompanyFormInput_companyName`, `CompanyFormInput_companyEmail`). |

### Form field slots

The `CompanyFormSlots` type allows you to customize individual form input fields within the registration form. Each slot is keyed by the pattern `CompanyFormInput_{fieldCode}` where `fieldCode` corresponds to the form field you want to customize.

Common field codes include:
- `companyName` - Company name input
- `companyEmail` - Company email input
- `companyAdminFirstName` - Admin first name input
- `companyAdminLastName` - Admin last name input
- `companyAdminEmail` - Admin email input
- `street` - Street address inputs
- `city` - City input
- `region` - Region/state selector
- `postcode` - Postal code input
- `countryCode` - Country selector
- `telephone` - Telephone input

## Usage

The following example demonstrates how to use the `CompanyRegistration` container:

```js
import { render as provider } from '@dropins/storefront-company-management/render.js';
import { CompanyRegistration } from '@dropins/storefront-company-management/containers/CompanyRegistration.js';

await provider.render(CompanyRegistration, {
  isAuthenticated: true,
  onRedirectLogin: () => console.log('RedirectLogin'),
  onRedirectAccount: () => console.log('RedirectAccount'),
  slots: {
    // Customize the company name field
    CompanyFormInput_companyName: (ctx) => {
      const { formData, handleInputChange, errors } = ctx;
      const customInput = document.createElement('input');
      customInput.type = 'text';
      customInput.value = formData.companyName || '';
      customInput.className = 'custom-company-name-input';
      customInput.onchange = (e) => handleInputChange({ companyName: e.target.value });
      ctx.replaceWith(customInput);
    },
    // Customize the company email field  
    CompanyFormInput_companyEmail: (ctx) => {
      const customField = document.createElement('div');
      customField.innerHTML = '<label>Business Email</label><input type="email" />';
      ctx.replaceWith(customField);
    }
  }
})(block);
```
