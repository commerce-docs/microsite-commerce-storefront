The **Company Management** drop-in provides pre-built container components for integrating into your storefront.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Version: 1.0.0-beta19</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [CompanyCredit](/dropins-b2b/company-management/containers/company-credit/) | Displays company credit balance, credit limit, and outstanding balance for B2B companies with credit purchasing. |
| [CompanyProfile](/dropins-b2b/company-management/containers/company-profile/) | Manages company information including name, legal details, VAT/Tax ID, addresses, payment methods, and shipping methods. |
| [CompanyRegistration](/dropins-b2b/company-management/containers/company-registration/) | Provides a form for new company account registration with company details, legal address, and administrator information. |
| [CompanyStructure](/dropins-b2b/company-management/containers/company-structure/) | Displays and manages the organizational hierarchy with teams, users, and their assignments within the company structure. |
| [CompanyUsers](/dropins-b2b/company-management/containers/company-users/) | Manages company users with add, edit, remove, and status change functionality for user administration. |
| [CustomerCompanyInfo](/dropins-b2b/company-management/containers/customer-company-info/) | Displays the customer's current company association and available company information. |
| [RolesAndPermissions](/dropins-b2b/company-management/containers/roles-and-permissions/) | Manages user roles and permissions for controlling access to company features and operations. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
