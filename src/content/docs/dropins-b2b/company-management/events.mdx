## Emits and Listens

These events flow in both directions, enabling a bidirectional data channel between the **Company Management** drop-in and external code:

- **The drop-in emits** these events when its internal state changes (for example, when a user interacts with the UI)
- **The drop-in listens** for these same events from external sources (your storefront code, other drop-ins, or integrations) to update its internal state programmatically

This pattern allows you to both **react to** the drop-in's state changes (by subscribing to events it emits) and **control** the drop-in's state (by emitting events that it listens for). Common use cases include server synchronization, cross-tab updates, analytics integration, and coordinating multiple drop-ins.
