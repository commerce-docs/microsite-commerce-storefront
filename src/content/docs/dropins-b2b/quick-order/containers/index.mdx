The **Quick Order** drop-in provides three main container components that work together on the Quick Order page: **QuickOrderItems**, **QuickOrderMultipleSku**, and **QuickOrderCsvUpload**. A fourth container, **QuickOrderVariantsGrid**, is used on the product detail page for Grid Ordering when that feature is enabled.

## What are containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They communicate via events such as `quick-order/add-items` and `quick-order/loading`; SKUs added in QuickOrderMultipleSku or QuickOrderCsvUpload appear in the QuickOrderItems list.

## Available Containers (Quick Order page)

<TableWrapper nowrap={[0,1]}>

| Container | Description |
| --------- | ----------- |
| [QuickOrderItems](/dropins-b2b/quick-order/containers/quick-order-items/) | Product list with search, quantity editing, product options for configurables, validation, and "Add All to Cart". Listens to `quick-order/add-items` and coordinates with the other two containers. |
| [QuickOrderMultipleSku](/dropins-b2b/quick-order/containers/quick-order-multiple-sku/) | Text area for entering multiple SKUs (comma, space, or newline separated). Parses and deduplicates SKUs, then emits `quick-order/add-items` to add them to the list. |
| [QuickOrderCsvUpload](/dropins-b2b/quick-order/containers/quick-order-csv-upload/) | CSV file upload with required "SKU" and "QTY" columns (max 200 rows). Validates file, parses data, and emits `quick-order/add-items`. Provides sample CSV download. |

</TableWrapper>

## Grid Ordering (PDP)

**QuickOrderVariantsGrid** runs on the product detail page when Grid Ordering is enabled for configurable products. It displays variants in a grid with quantity inputs and bulk add-to-cart. The Product Details block integrates it; see the Product Details drop-in and block configuration for setup.

<Aside type="tip">
Each Quick Order page container is designed to work with the others via events. Render QuickOrderItems, QuickOrderMultipleSku, and QuickOrderCsvUpload in the same block (or page) so that adding SKUs from the text area or CSV updates the central list in QuickOrderItems.
</Aside>
