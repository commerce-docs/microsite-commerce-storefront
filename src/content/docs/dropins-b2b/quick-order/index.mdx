The **Quick Order** B2B drop-in introduces two purchasing workflows for Adobe Storefront designed for B2B buyers who need to place orders quickly and efficiently.

The drop-in delivers two core features:

1. **Quick Order** — A fast product ordering interface that provides functional parity with the Adobe Commerce Quick Order experience. Customers add products to an order list using SKU search, CSV upload, or multiple SKU input.
2. **Grid Ordering** — A new B2B ordering experience exclusive to Adobe Storefront. Buyers add multiple configurable product variants to the cart from a single grid interface.

The drop-in consists of four containers: **QuickOrderCsvUpload**, **QuickOrderItems**, and **QuickOrderMultipleSku** (Quick Order feature); **QuickOrderVariantsGrid** (Grid Ordering feature). The first three containers implement the Quick Order workflow, while QuickOrderVariantsGrid provides the Grid Ordering experience.

The Quick Order feature enables B2B customers to rapidly build an order by entering product SKUs directly, uploading a CSV file with product data, or searching for products. It is designed for buyers who already know the products they want to purchase and need a fast way to add them to the cart without navigating through catalog pages. The implementation provides functional parity with the Adobe Commerce Quick Order experience while leveraging the modular architecture of Adobe Storefront drop-ins.

Containers communicate via the [event bus](/sdk/reference/events), ensuring loose coupling and flexible extensibility. Any container can be replaced with a custom implementation that follows the defined event contracts. By default, Quick Order does not enforce additional permissions or access restrictions beyond your storefront's existing auth.
