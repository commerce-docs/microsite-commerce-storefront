The Quick Order drop-in provides bulk product ordering for B2B storefronts through three coordinated containers: **QuickOrderItems** (product list with search and cart), **QuickOrderMultipleSku** (multiple SKU text entry), and **QuickOrderCsvUpload** (CSV upload). Containers communicate via events. The drop-in also supports **Grid Ordering** for configurable products on the product detail page (PDP) when you enable it via the Product Details block.
