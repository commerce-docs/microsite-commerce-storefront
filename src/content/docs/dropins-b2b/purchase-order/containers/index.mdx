The **Purchase Order** drop-in provides pre-built container components for integrating into your storefront.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Version: 1.0.0-beta2</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [ApprovalRuleDetails](/dropins-b2b/purchase-order/containers/approval-rule-details/) | Displays and manages approval rule configuration including conditions, approvers, and rule metadata. |
| [ApprovalRuleForm](/dropins-b2b/purchase-order/containers/approval-rule-form/) | Provides a form interface for creating new approval rules or editing existing ones with configurable conditions and approvers. |
| [ApprovalRulesList](/dropins-b2b/purchase-order/containers/approval-rules-list/) | Displays all approval rules in a paginated table with filtering, sorting, and management actions including create, edit, and delete. |
| [CompanyPurchaseOrders](/dropins-b2b/purchase-order/containers/company-purchase-orders/) | Displays purchase orders for the entire company including all subordinate users with bulk actions and filtering. |
| [CustomerPurchaseOrders](/dropins-b2b/purchase-order/containers/customer-purchase-orders/) | Displays purchase orders created by the currently logged-in customer with pagination and filtering options. |
| [PurchaseOrderApprovalFlow](/dropins-b2b/purchase-order/containers/purchase-order-approval-flow/) | Displays the approval workflow timeline including approval events, approver roles, status changes, and messages. |
| [PurchaseOrderCommentForm](/dropins-b2b/purchase-order/containers/purchase-order-comment-form/) | Provides a form interface for adding comments to a purchase order during the approval or review process. |
| [PurchaseOrderCommentsList](/dropins-b2b/purchase-order/containers/purchase-order-comments-list/) | Displays all comments on a purchase order with author information, timestamps, and comment text. |
| [PurchaseOrderConfirmation](/dropins-b2b/purchase-order/containers/purchase-order-confirmation/) | Displays a confirmation message after successful purchase order creation with order details and next steps. |
| [PurchaseOrderHistoryLog](/dropins-b2b/purchase-order/containers/purchase-order-history-log/) | Shows a chronological timeline of all actions, status changes, and updates for a purchase order. |
| [PurchaseOrderStatus](/dropins-b2b/purchase-order/containers/purchase-order-status/) | Displays the current purchase order status with available actions such as approve, reject, cancel, or place order based on user permissions. |
| [RequireApprovalPurchaseOrders](/dropins-b2b/purchase-order/containers/require-approval-purchase-orders/) | Displays purchase orders requiring approval from the current user with bulk approve and reject actions. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
