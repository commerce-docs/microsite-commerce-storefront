The **Purchase Order** drop-in provides pre-built container components for integrating into your storefront.

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [ApprovalRuleDetails](/dropins-b2b/purchase-order/containers/approval-rule-details/) | Displays detailed information about a specific approval rule. |
| [ApprovalRuleForm](/dropins-b2b/purchase-order/containers/approval-rule-form/) | Form for creating or editing approval rules. |
| [ApprovalRulesList](/dropins-b2b/purchase-order/containers/approval-rules-list/) | Paginated table of approval rules with create, edit, and view actions. |
| [CompanyPurchaseOrders](/dropins-b2b/purchase-order/containers/company-purchase-orders/) | Paginated table of company-wide purchase orders with filtering and actions. |
| [CustomerPurchaseOrders](/dropins-b2b/purchase-order/containers/customer-purchase-orders/) | Paginated table of customer's purchase orders with filtering and actions. |
| [PurchaseOrderApprovalFlow](/dropins-b2b/purchase-order/containers/purchase-order-approval-flow/) | Displays approval workflow visualization for a purchase order. |
| [PurchaseOrderCommentForm](/dropins-b2b/purchase-order/containers/purchase-order-comment-form/) | Form for adding comments to a purchase order. |
| [PurchaseOrderCommentsList](/dropins-b2b/purchase-order/containers/purchase-order-comments-list/) | Displays conversation history for a purchase order with show more support. |
| [PurchaseOrderConfirmation](/dropins-b2b/purchase-order/containers/purchase-order-confirmation/) | Confirmation screen after purchase order creation showing PO number and details link. |
| [PurchaseOrderHistoryLog](/dropins-b2b/purchase-order/containers/purchase-order-history-log/) | Displays chronological activity log for a purchase order with show more support. |
| [PurchaseOrderStatus](/dropins-b2b/purchase-order/containers/purchase-order-status/) | Displays purchase order status with action buttons (approve, reject, cancel, place order). |
| [RequireApprovalPurchaseOrders](/dropins-b2b/purchase-order/containers/require-approval-purchase-orders/) | Paginated table of purchase orders requiring approval with filtering and actions. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
