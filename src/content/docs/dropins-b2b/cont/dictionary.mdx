The default Cont dictionary includes the default English values for all labels and text common to the Cont drop-in component.

## Default keys and values

The dictionary file for Cont will be available at:
`@dropins/storefront-cont/i18n/en_US.json`

```json
{
  "cont": {
    "title": "Cont",
    "description": "Description for Cont component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-cont/i18n/en_US.json.d.ts?raw';
```
:::
