The default Quote Management dictionary includes the default English values for all labels and text common to the Quote Management drop-in component.

## Default keys and values

The dictionary file for Quote Management will be available at:
`@dropins/storefront-quote-management/i18n/en_US.json`

```json
{
  "quote-management": {
    "title": "Quote Management",
    "description": "Description for Quote Management component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-quote-management/i18n/en_US.json.d.ts?raw';
```
:::
