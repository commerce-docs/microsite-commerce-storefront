The **Quote Management** drop-in provides **7** pre-built container components for integrating into your storefront.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Version: 0.0.1-alpha17</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [ItemsQuoted](/dropins-b2b/quote-management/containers/items-quoted/) | The ItemsQuoted container displays all quoted items with product details, quantities, pricing, and negotiated discounts for an active quote.. |
| [ManageNegotiableQuote](/dropins-b2b/quote-management/containers/manage-negotiable-quote/) | The ManageNegotiableQuote container provides the main interface for managing a negotiable quote including status, actions, and quote details.. |
| [QuoteCommentsList](/dropins-b2b/quote-management/containers/quote-comments-list/) | The QuoteCommentsList container displays all comments and communications between buyer and seller for a negotiable quote.. |
| [QuoteHistoryLog](/dropins-b2b/quote-management/containers/quote-history-log/) | The QuoteHistoryLog container shows the complete history of actions, status changes, and updates for a quote throughout its lifecycle.. |
| [QuotesListTable](/dropins-b2b/quote-management/containers/quotes-list-table/) | The QuotesListTable container displays all quotes in a paginated table with filtering, sorting, and action buttons for quote management.. |
| [RequestNegotiableQuoteForm](/dropins-b2b/quote-management/containers/request-negotiable-quote-form/) | The RequestNegotiableQuoteForm container provides a form for requesting new negotiable quotes with product selection and initial details.. |
| [ShippingAddressDisplay](/dropins-b2b/quote-management/containers/shipping-address-display/) | The ShippingAddressDisplay container shows the selected shipping address for a quote with options to change or add new addresses.. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
