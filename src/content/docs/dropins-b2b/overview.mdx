This section contains B2B-specific drop-in components for Adobe Commerce Storefront. These components are designed to handle business-to-business commerce scenarios and provide specialized functionality for B2B customers.

## Available B2B Drop-ins

The following B2B drop-ins are currently available for Adobe Commerce Storefront:

### Quote Management

A comprehensive B2B quote management system that enables customers to request, manage, and track the status of negotiable quotes directly within the storefront experience.

**Key Features:**
- Request negotiable quotes from cart contents
- Manage quote status and updates
- Product list management with pricing controls
- Quote actions (print, copy, delete, send for review)
- Draft quote saving functionality
- Permission-based access control
- Event-driven architecture for integration

[Learn more about Quote Management →](/dropins-b2b/quote-management/)

For more information about B2B functionality, refer to the [Adobe Commerce B2B documentation](https://experienceleague.adobe.com/docs/commerce-admin/b2b/introduction.html).
