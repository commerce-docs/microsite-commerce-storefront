## Basic Slot Usage

```javascript
// Basic slot implementation
await provider.render(Container, {
  slots: {
    Header: (ctx) => {
      const header = document.createElement('div');
      header.innerHTML = `
        <h2>Custom Header</h2>
        <p>Additional header content</p>
      `;
      ctx.appendChild(header);
    },
    
    Footer: (ctx) => {
      const footer = document.createElement('div');
      footer.className = 'custom-footer';
      footer.textContent = 'Custom footer content';
      ctx.appendChild(footer);
    }
  }
})($container);
```

## Slot Examples

### Header Slot

The Header slot allows you to customize the top section of the component:

```javascript
Header: (ctx) => {
  const header = document.createElement('div');
  header.innerHTML = `
    <h2>Slots Test Header</h2>
    <p>Custom content with data: ${ctx.data?.property}</p>
  `;
  ctx.appendChild(header);
}
```

### Footer Slot

The Footer slot allows you to customize the bottom section of the component:

```javascript
Footer: (ctx) => {
  const footer = document.createElement('div');
  footer.className = 'custom-footer';
  
  const button = document.createElement('button');
  button.textContent = 'Custom Action';
  button.onclick = () => handleCustomAction(ctx.data);
  
  footer.appendChild(button);
  ctx.appendChild(footer);
}
```

### Custom Slot

Example of a custom slot for specific functionality:

```javascript
SlotName: (ctx) => {
  const wrapper = document.createElement('div');
  wrapper.className = 'Slots Test-custom-slot';
  
  const customElement = document.createElement('button');
  customElement.className = 'Slots Test-custom-slot__button';
  customElement.textContent = 'Custom Action';
  customElement.addEventListener('click', () => {
    // Handle custom action
    console.log('Custom slot action:', ctx.data);
  });

  wrapper.appendChild(customElement);
  ctx.appendChild(wrapper);
}
```

## Advanced Slot Usage

### Dynamic Content Updates

Slots can respond to data changes using the `ctx.onChange` method:

```javascript
slots: {
  Header: (ctx) => {
    const header = document.createElement('div');
    header.innerHTML = `<h2>Items: ${ctx.data?.items?.length || 0}</h2>`;
    ctx.appendChild(header);
    
    // Update when data changes
    ctx.onChange((next) => {
      header.innerHTML = `<h2>Items: ${next.data?.items?.length || 0}</h2>`;
    });
  }
}
```

### Conditional Slot Rendering

```javascript
slots: {
  Footer: (ctx) => {
    // Only render if conditions are met
    if (ctx.data?.showFooter) {
      const footer = document.createElement('div');
      footer.innerHTML = `
        <div class="custom-footer">
          <p>Footer content</p>
        </div>
      `;
      ctx.appendChild(footer);
    }
  }
}
```

### Integration with UI Components

```javascript
slots: {
  Header: async (ctx) => {
    const headerWrapper = document.createElement('div');

    const customButton = await UI.render(Button, {
      children: 'Custom Button',
      variant: 'primary',
      onClick: () => handleAction(ctx.data),
    })(headerWrapper);

    ctx.appendChild(headerWrapper);

    ctx.onChange((next) => {
      customButton?.setProps((prev) => ({
        ...prev,
        disabled: !next.data?.isEnabled,
      }));
    });
  }
}
```

## Slot Context

Each slot receives a context object (`ctx`) that provides:

- **`ctx.data`**: Current component data and state
- **`ctx.appendChild(element)`**: Method to add elements to the slot
- **`ctx.replaceWith(element)`**: Method to replace slot content
- **`ctx.onChange(callback)`**: Method to listen for data changes

## Best Practices

1. **Element Creation**: Always create DOM elements and append them using `ctx.appendChild()`
2. **CSS Classes**: Use BEM naming convention for custom slot styles
3. **Event Handling**: Add event listeners directly to created elements
4. **Data Updates**: Use `ctx.onChange()` for dynamic content updates
5. **Performance**: Keep slot logic lightweight for better performance

## Styling Slots

Use CSS to style your custom slot content:

```css title="Slots Test.css"
.Slots Test-custom-slot {

```

## Troubleshooting

### Common Issues

1. **Slot Not Rendering**: Ensure you're using `ctx.appendChild()` or `ctx.replaceWith()`
2. **Styling Not Applied**: Check CSS class names and specificity
3. **Event Handlers Not Working**: Verify event listeners are added to the correct elements
4. **Dynamic Updates Failing**: Make sure you're using `ctx.onChange()` for data-dependent content
