The default Slots Test dictionary includes the default English values for all labels and text common to the Slots Test drop-in component.

## Default keys and values

The dictionary file for Slots Test will be available at:
`@dropins/storefront-slots-test/i18n/en_US.json`

```json
{
  "slots-test": {
    "title": "Slots Test",
    "description": "Description for Slots Test component"
  }
}
```

:::note[Dictionary Import]
To import the actual dictionary file, use:
```js
import dictionary from '@dropins/storefront-slots-test/i18n/en_US.json.d.ts?raw';
```
:::
