The **Requisition List** drop-in provides pre-built container components for integrating into your storefront.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Version: 1.0.0-beta1</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [RequisitionListForm](/dropins-b2b/requisition-list/containers/requisition-list-form/) | Form for creating, editing, or renaming requisition lists. |
| [RequisitionListGrid](/dropins-b2b/requisition-list/containers/requisition-list-grid/) | Grid view of all requisition lists with create, rename, and delete actions. |
| [RequisitionListHeader](/dropins-b2b/requisition-list/containers/requisition-list-header/) | Header for requisition list detail view with back navigation and list actions. |
| [RequisitionListSelector](/dropins-b2b/requisition-list/containers/requisition-list-selector/) | Dropdown selector for adding products to requisition lists with create option. |
| [RequisitionListView](/dropins-b2b/requisition-list/containers/requisition-list-view/) | Detail view of a requisition list showing items with pagination and bulk actions. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
