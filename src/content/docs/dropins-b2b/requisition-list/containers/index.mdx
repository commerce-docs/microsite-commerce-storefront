The **Requisition List** drop-in provides **5** pre-built container components for integrating into your storefront.

<div style="background-color: var(--sl-color-blue-low); border-left: 4px solid var(--sl-color-blue); padding: 0.75rem 1rem; border-radius: 0.25rem; margin: 1rem 0;">
<strong>Version: 1.0.0-beta1</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

<TableWrapper nowrap={[0]}>

| Container | Description |
| --------- | ----------- |
| [RequisitionListForm](/dropins-b2b/requisition-list/containers/requisition-list-form/) | The RequisitionListForm container creates new requisition lists or edits existing ones with name and description fields.. |
| [RequisitionListGrid](/dropins-b2b/requisition-list/containers/requisition-list-grid/) | The RequisitionListGrid container displays all buyer requisition lists in a paginated grid with create, edit, and delete actions.. |
| [RequisitionListHeader](/dropins-b2b/requisition-list/containers/requisition-list-header/) | The RequisitionListHeader container shows the list name, description, and action buttons for managing the list.. |
| [RequisitionListSelector](/dropins-b2b/requisition-list/containers/requisition-list-selector/) | The RequisitionListSelector container provides a dropdown to select which requisition list to add products to from product pages.. |
| [RequisitionListView](/dropins-b2b/requisition-list/containers/requisition-list-view/) | The RequisitionListView container displays the full contents of a requisition list with item details, quantities, and add-to-cart functionality.. |


</TableWrapper>

<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
