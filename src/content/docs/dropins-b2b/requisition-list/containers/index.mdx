## Overview

The **Requisition List** drop-in provides **5** pre-built container components for integrating into your storefront.

<strong>Version: 0.7.0-beta</strong>
</div>

## What are Containers?

Containers are pre-built UI components that combine functionality, state management, and presentation. They provide a complete solution for specific features and can be customized through props, slots, and CSS.

## Available Containers

- [Requisition list form](/dropins-b2b/requisition-list/containers/requisition-list-form/)
- [Requisition list grid](/dropins-b2b/requisition-list/containers/requisition-list-grid/)
- [Requisition list header](/dropins-b2b/requisition-list/containers/requisition-list-header/)
- [Requisition list selector](/dropins-b2b/requisition-list/containers/requisition-list-selector/)
- [Requisition list view](/dropins-b2b/requisition-list/containers/requisition-list-view/)


<Aside type="tip">
Each container is designed to work independently but can be composed together to create comprehensive user experiences.
</Aside>
