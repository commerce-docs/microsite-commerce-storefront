The Requisition List drop-in lets B2B customers manage requisition lists on Adobe Commerce storefronts. It supports multiple lists per account. Company users can add products to a list from product detail pages and product list pages.

## Export and print

In the preview implementation, signed-in buyers can select **Export** or **Print**
from their requisition list header. Both actions retrieve the entire list, not
only the displayed page or selected items. They do not change the buyer's
selection, quantities, or current page.

- **Export** downloads a CSV containing stored SKUs and quantities. It does not
  include prices, subtotals, product names, or selected options.
- **Print** opens the browser print dialog with the list name, description,
  product details, selected options, quantities, prices, and subtotals. Buyers
  can choose a printer or save a PDF using the browser's available destinations.

<Aside type="note" title="Preview availability and pricing">
  These capabilities are available for integration testing in
  `2.1.0-preview-20261126103129-7696915`. This preview does not establish stable release
  availability. Printed amounts use the current list-view pricing rules; they are not authoritative
  configured-line totals or a guarantee of Magento Luma monetary parity.
</Aside>

See [Export and print in the header](/dropins-b2b/requisition-list/containers/requisition-list-header/#export-and-print)
for file format, pricing limitations, recovery behavior, and print integration.

<Aside type="note" title="Quick Order and lists">
  Quick Order in the storefront adds lines to the cart. There is no out-of-the-box API or UI flow to
  bulk-add SKUs from Quick Order straight into an existing requisition or favorites list. If you
  need that path, plan a custom integration rather than assuming the Quick Order surface updates
  requisition lists.
</Aside>
