This page documents GraphQL changes in the `4.8.25` package line for merchants on Adobe Commerce 2.4.8. For the current package line, see [Adobe Commerce 2.4.9](/setup/configuration/storefront-compatibility/v249/).

The Storefront Compatibility Package adds backend changes that storefront drop-ins need on Adobe Commerce 2.4.8. The `4.8.25` package line is mostly GraphQL schema extensions, plus bug fixes. Drop-in components require this package.

<Aside type="note" title="Version and compatibility requirements">
Adobe Commerce 2.4.8 only. Magento Open Source and earlier Adobe Commerce versions are not supported.

Fixes in this package through `4.8.8` are included in Adobe Commerce 2.4.9 core. If you run 2.4.9, see [Adobe Commerce 2.4.9](/setup/configuration/storefront-compatibility/v249/) instead.

On Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer, Adobe installs and updates this package automatically. On Commerce on Cloud or on-premises, you must have an Adobe Commerce Optimizer license and install `4.8.25` with Composer. See [Manual installation](/setup/configuration/storefront-compatibility/install/).
</Aside>

## Major features

Adobe releases new GraphQL queries and mutations across minor versions in each package line. The list below summarizes the full `4.8.25` line. Not every item was introduced in `4.8.25`, even though it is the latest release in the 4.8.x series. For version-specific changes, see the [changelog](/releases/changelog/) and filter for the Storefront Compatibility Package.

The `4.8.25` package line adds the following GraphQL queries and mutations:

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/clear/"} text={"clearWishlist"} /> mutation — Allows all items to be removed from a wishlist in a single action.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-group/"} text={"customerGroup"} /> query — Retrieves information about a specified customer group.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-segments/"} text={"customerSegments"} /> query — Retrieves information about a specified customer segment.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/delete-address-v2"} text={"deleteCustomerAddressV2"} /> mutation — Deletes a customer's billing or shipping address based on the provided customer UID.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-external-customer-token/"} text={"exchangeExternalCustomerToken"} /> mutation — Authenticates users via an integration token and returns both the customer token and associated customer data.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-otp-customer-token/"} text={"exchangeOtpForCustomerToken"} /> mutation — Authenticates admins as customers for seller-assisted buying by exchanging a one-time password (OTP) and email for a customer token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/update-address-v2"} text={"updateCustomerAddressV2"} /> mutation — Updates a customer's billing or shipping address based on the provided customer UID.
