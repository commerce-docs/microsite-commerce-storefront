The Storefront Compatibility Package adds backend changes that drop-in components require on Adobe Commerce 2.4.7. This package provides mostly GraphQL schema extensions and REST endpoints, plus bug fixes.

<Aside type="note" title="Version and compatibility requirements">
Adobe Commerce 2.4.7 only. Magento Open Source is not supported. Lower versions of Adobe Commerce are not supported. This page documents GraphQL and REST changes in the SCP-4.7.x package for merchants on Adobe Commerce 2.4.7. For the latest package, see Adobe Commerce 2.4.9. See the [Storefront Compatibility Package](/setup/configuration/storefront-compatibility/) for Adobe Commerce 2.4.9.

Starting with `4.7.14`, this package line also supports Commerce on Cloud or on-premises with Adobe Commerce Optimizer. Adobe plans to incrementally backport remaining `4.8.x` and `4.9.x` features to this release stream in future releases.

See <Link href="https://experienceleague.adobe.com/en/docs/commerce-operations/release/versions" text="Adobe Commerce Software Lifecycle Policy" /> for current end-of-life dates.

</Aside>


## Major features

Adobe releases new GraphQL queries and mutations across minor versions in each package release. For version-specific changes, see the [changelog](/releases/changelog/) and filter for the Storefront Compatibility Package.

## GraphQL APIs

This package provides the following GraphQL queries and mutations:


- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/wishlist/mutations/clear/"} text={"clearWishlist"} /> mutation - Allows all items to be removed from a wishlist in a single action.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/confirm-cancel-order/"} text={"confirmCancelOrder"} /> mutation - Cancels the specified order for a guest.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/confirm-return/"} text={"confirmReturn"} /> mutation - Confirms a guest or customer return request.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-group/"} text={"customerGroup"} /> query - Retrieves information about specified customer group.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/queries/customer-segments/"} text={"customerSegments"} /> query - Retrieves information about specified customer segment.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/delete-address-v2"} text={"deleteCustomerAddressV2"} /> mutation - Deletes a customer's billing or shipping address based on the provided customer UID.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/exchange-external-customer-token/"} text={"exchangeExternalCustomerToken"} /> mutation - Authenticates users using an integration token and returns both the customer token and associated customer data.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/cart/mutations/estimate-totals/"} text={"estimateTotals"} /> mutation - Estimates totals for cart based on the address.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/generate-token/"} text={"generateCustomerToken"} /> mutation - Creates a new customer token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/queries/guest-order/"} text={"guestOrder"} /> query - Retrieves guest order information for the specified order number, email, and billing last name.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/queries/guest-order-by-token/"} text={"guestOrderByToken"} /> query - Retrieves guest order data associated with a given order token.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/store/queries/recaptcha-form-config/"} text={"recaptchaFormConfig"} /> query - Returns information about the reCaptcha configuration for the specified form type.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/request-guest-order-cancel/"} text={"requestGuestOrderCancel"} /> mutation - Cancels the specified guest order.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/orders/mutations/request-guest-return/"} text={"requestGuestReturn"} /> mutation - Requests a return for a specified order on behalf of a guest.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/resend-confirmation-email/"} text={"resendConfirmationEmail"} /> mutation - Resends a confirmation email to the specified customer upon request.

- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/customer/mutations/update-address-v2"} text={"updateCustomerAddressV2"} /> mutation - Updates a customer's billing or shipping address based on the provided customer UID.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/cart/mutations/select-free-gift/"} text={"selectFreeGift"} /> mutation — Selects a free gift for an eligible cart promotion.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/queries/is-subscribed-product-alert-price/"} text={"isSubscribedProductAlertPrice"} /> query — Checks whether a customer is subscribed to price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/queries/is-subscribed-product-alert-stock/"} text={"isSubscribedProductAlertStock"} /> query — Checks whether a customer is subscribed to stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/subscribe-product-alert-price/"} text={"subscribeProductAlertPrice"} /> mutation — Subscribes a customer to price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/subscribe-product-alert-stock/"} text={"subscribeProductAlertStock"} /> mutation — Subscribes a customer to stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-price/"} text={"unsubscribeProductAlertPrice"} /> mutation — Unsubscribes a customer from price alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-price-all"} text={"unsubscribeProductAlertPriceAll"} /> mutation — Unsubscribes a customer from all price alerts.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-stock/"} text={"unsubscribeProductAlertStock"} /> mutation — Unsubscribes a customer from stock alerts for a product.
- <Link href={"https://developer.adobe.com/commerce/webapi/graphql/schema/products/mutations/unsubscribe-product-alert-stock-all"} text={"unsubscribeProductAlertStockAll"} /> mutation — Unsubscribes a customer from all stock alerts.

## GraphQL API configuration

Adobe Commerce limits the number of field aliases allowed in a single GraphQL request starting in version 2.4.9; this limit isn't enforced on 2.4.7. This package still raises the default for **Maximum Alias Allowed** from `10` to `15`, so the setting is already in place if you upgrade to 2.4.9.

To confirm this setting ahead of an upgrade, go to **Stores** > **Settings** > **Configuration** > **Services** > **Web API** > **GraphQL Input Limits** in the Admin.
