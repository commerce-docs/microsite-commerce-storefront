Adobe Commerce Storefront supports three backend types. Follow only the guidance for your backend—prerequisites and setup differ, and mixing steps causes errors.

- **Commerce PaaS** — Existing Adobe Commerce Cloud or on-premises deployment (no Adobe Commerce as a Cloud Service or Adobe Commerce Optimizer license)
- **Adobe Commerce as a Cloud Service** — Cloud Service customer whose license includes Storefront
- **Adobe Commerce Optimizer** — New Adobe Commerce Optimizer customer, or existing PaaS customer who added Adobe Commerce Optimizer

<Aside type="tip" title="Not sure which backend you have?">
Commerce PaaS = existing cloud or on-premises. Adobe Commerce as a Cloud Service = Customer with Storefront in license. Adobe Commerce Optimizer = Adobe Commerce Optimizer customer or PaaS + Adobe Commerce Optimizer.
</Aside>

## Backend comparison

The following table summarizes the key differences between backend types.

<TableWrapper nowrap={[0]}>

| Feature | Commerce PaaS | Adobe Commerce as a Cloud Service | Adobe Commerce Optimizer |
|---------|---------------|-----------------------------------|--------------------------|
| **License includes Storefront** | No | Yes | Yes |
| **Setup** | Manual install required (see Prerequisites below) | Fully automated | Fully automated |
| **Version** | v2.4.7+ self-managed | Auto-managed | Fully managed SaaS |

</TableWrapper>

### Commerce Platform-as-a-Service (PaaS)

#### Product license

Adobe Commerce Cloud or on-premises (Magento Open Source not supported). Or with the <Link href="https://experienceleague.adobe.com/en/docs/commerce/optimizer/get-started" text="Adobe Commerce Optimizer Connector" />—requires Storefront Compatibility package.

#### Version

v2.4.7 or later

#### Storefront Compatibility package

Required. See [Storefront Compatibility package](/setup/configuration/storefront-compatibility/install/) (2.4.7 or 2.4.8).

#### Storefront services (manual install)

- **Without Adobe Commerce Optimizer Connector:** Data Connection, Services Connector, Catalog Service, Live Search, Product Recommendations. See <Link href="https://experienceleague.adobe.com/en/docs/commerce/user-guides/integration-services/saas" text="Commerce Services Connector" />.
- **With Adobe Commerce Optimizer Connector:** PHP extension on PaaS + Adobe Commerce Optimizer UI configuration. Data Connection support may differ—see connector documentation. {/* TODO: Clarify Data Connection support once ACO Connector documentation is published. */}

<Aside type="note" title="Luma Bridge and Adobe Commerce Optimizer">
Luma Bridge works without an Adobe Commerce Optimizer license or the Adobe Commerce Optimizer Connector on PaaS with a Luma store. Luma Bridge is the session bridge between Edge Delivery Services and a Luma/PHP storefront. It is separate from Adobe Commerce Optimizer, which solves catalog and merchandising problems. With Adobe Commerce Optimizer and the Adobe Commerce Optimizer Connector, Luma Bridge still works for session sharing during migration. See [Luma Bridge](/setup/discovery/luma-bridge/).
</Aside>

## PaaS: required packages and services

Install and configure the following packages and services on Commerce PaaS before creating your storefront. Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer manage these automatically.

<Aside type="note">
**Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer** auto-install and auto-configure everything below. Skip this section if you are not on Commerce PaaS.
</Aside>

### Storefront Compatibility package

Extends the GraphQL schema for cart, checkout, account, and order. See [Storefront Compatibility package](/setup/configuration/storefront-compatibility/install/) (2.4.7 or 2.4.8).

### Storefront services

Read-only catalog data via GraphQL; required for high Lighthouse scores.

| Service | Documentation |
|---------|---------------|
| Data Connection | <Link href="https://experienceleague.adobe.com/en/docs/commerce/data-connection/overview" text="Data Connection Guide" /> |
| Services Connector | <Link href="https://experienceleague.adobe.com/en/docs/commerce/user-guides/integration-services/saas" text="Commerce Services Connector" /> |
| Catalog Service | <Link href="https://experienceleague.adobe.com/en/docs/commerce/catalog-service/guide-overview" text="Catalog Service Guide" /> |
| Live Search | <Link href="https://experienceleague.adobe.com/en/docs/commerce/live-search/overview" text="Live Search" />; [eventing](/setup/analytics/instrumentation/) for headless |
| Product Recommendations | <Link href="https://experienceleague.adobe.com/en/docs/commerce/product-recommendations/developer/events" text="Events" />; [setup](/merchants/blocks/product-recommendations/) |

<Aside type="caution" title="Multiple stores in one Commerce environment">
If you are migrating only one store to Edge Delivery Services in a shared Commerce environment, contact Adobe Commerce Support to ensure that Live Search stays active without disabling Elasticsearch for your other stores.
</Aside>
