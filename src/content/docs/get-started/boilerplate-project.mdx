The AEM Commerce boilerplate is a production-ready storefront starter that combines Edge Delivery Services with Commerce drop-in components. It delivers high performance, straightforward customizations, and rapid content development.

## What is the boilerplate?

The boilerplate provides a complete foundation for building high-performance storefronts:

- **29 pre-built Commerce blocks** wrapping drop-in components for cart, checkout, PDP, PLP, account management, order tracking, and more
- **Edge Delivery Services architecture** with document-based authoring and instant publishing
- **Production-ready configuration** with build tools, PDP metadata generator, and Sidekick integration
- **Modular design** allowing you to use what you need and customize what you don't

**Repository**: <Link href="https://github.com/hlxsites/aem-boilerplate-commerce" text="hlxsites/aem-boilerplate-commerce" />

## Terminology

<Vocabulary>

### Commerce drop-in components

Full-featured shopping components that turn websites into storefronts. [Drop-in components](/setup/discovery/architecture/#drop-in-components) are not primitive components, like Carousels and Galleries. They provide the entire storefront shopping experience for a website using pages and other commerce features.

### Commerce blocks

The integration of Commerce drop-in components into the Edge Delivery Services architecture of JavaScript blocks and document-based authoring. [Commerce blocks](/setup/discovery/architecture/#commerce-blocks) are the components that provide the content and layout for commerce pages in the storefront.

### Content blocks

The Edge Delivery components that provide the content and layout for non-commerce pages in the storefront. These include Cards, Columns, Headers, Footers, and many more. Visit the Adobe Experience Manager <Link href="https://www.aem.live/developer/block-collection" text="Block Collection" /> section for the details.

</Vocabulary>

## How it works

The boilerplate uses a three-layer architecture:

<Diagram type="mermaid" code={`

    A["Document Authoring Layer"]
    B["Block Integration Layer"]
    C["Drop-in Component Layer"]
    D["Adobe Commerce Backend"]
    
    A -->|Configure| B
    B -->|Initialize| C
    C -->|Fetch Data| D
    
    style A fill:#E3F2FD,stroke:#2196F3,stroke-width:2px
    style B fill:#F3E5F5,stroke:#9C27B0,stroke-width:2px
    style C fill:#FFF9C4,stroke:#FBC02D,stroke-width:2px
    style D fill:#E8F5E9,stroke:#4CAF50,stroke-width:2px
`} />

### 1. Document authoring layer
Content authors create pages using simple tables in Microsoft Word, Google Docs, or SharePoint. Each table represents a block on the page.

### 2. Block integration layer
Commerce blocks (in the <Link href="https://github.com/hlxsites/aem-boilerplate-commerce/tree/main/blocks" text="blocks/" /> directory) act as adapters between Edge Delivery Services and Commerce drop-ins. Each block:

- **Receives configuration** from the document table
- **Initializes the drop-in** component with appropriate settings
- **Wraps the drop-in** in a container element that Edge Delivery Services can load
- **Applies styling** specific to your brand

### 3. Drop-in component layer
Drop-in components (in <Link href="https://github.com/hlxsites/aem-boilerplate-commerce/tree/main/scripts/__dropins__" text="scripts/__dropins__/" />) provide the commerce functionality:

- **Product Discovery** - Search, filtering, facets for PLPs
- **Cart & Checkout** - Shopping cart and complete checkout flow
- **Account Management** - Customer login, registration, profile, addresses
- **Order Management** - Order history, tracking, returns
- **Product Details** - PDP with variants, images, add-to-cart
- **Recommendations** - AI-powered product suggestions
- **Wishlist** - Save items for later

These drop-ins connect to your Adobe Commerce backend via APIs.

## Getting started with the boilerplate

### Creating your storefront

To create a new storefront from the boilerplate, you have two options:

<Steps>

1. **Use the Site Creator Tool** (Recommended)  
   Visit the <Link href="https://da.live/app/adobe-commerce/storefront-tools/tools/site-creator/site-creator" text="Site Creator Tool" /> to quickly set up your own copy of code and content.

1. **Follow the step-by-step guide**  
   See [Create a storefront](/get-started/create-storefront/) for a detailed walkthrough of using the GitHub template and configuring your environment.

</Steps>

### Running locally

Once you have your storefront repository on your local machine:

```bash
npm install    # Install dependencies
npm start      # Start local development server
```

Your storefront will be running at `http://localhost:3000`.

### Understanding the flow

<Diagram type="mermaid" code={`

<Steps>

1. **Author creates** a cart page with a "Commerce Cart" table in their document
1. **Edge Delivery Services** transforms the document server-side into HTML with a `<div class="commerce-cart">` element
1. **Browser loads** the HTML page and client-side JavaScript decorates the blocks
1. **Block decorator** (`blocks/commerce-cart/commerce-cart.js`) dynamically loads and initializes the Cart drop-in
1. **Drop-in** connects to Commerce backend via API and renders the cart UI

</Steps>

### Customizing your storefront

- **Brand styling**: Edit `styles/styles.css` for design tokens.
- **Block behavior**: Modify block decorators in `blocks/`.
- **Commerce config**: Update initializers in `scripts/initializers/`.
- **Add/remove blocks**: Use only the commerce blocks you need.

### Keeping your storefront current

As Adobe continues to enhance the boilerplate with new features, security updates, and performance improvements, you'll want to keep your storefront up to date.

#### Track changes

- <Link href="https://github.com/hlxsites/aem-boilerplate-commerce/issues?q=label%3Achangelog+is%3Aclosed" text="Boilerplate Changelog" /> - Major changes and breaking updates.
- [Release notes](/releases/) - Drop-in component releases and updates.

#### Apply updates

Most updates involve simple NPM package upgrades, but some may require integration layer changes. For complete guidance on:
- Upgrading drop-in components.
- Applying selective boilerplate updates.
- Handling breaking changes.
- Migrating between architectural versions.
