How does an authored document become a storefront with real prices, a working cart, and shopper sign-in? The shopper-facing layer is the storefront. It renders the UI and talks to Adobe Commerce and related services through APIs. On Edge Delivery Services (EDS), you build that experience with Commerce blocks, drop-in components, and the Adobe Commerce boilerplate in your Git repository.

Edge Delivery Services is a cloud content delivery network (CDN). It serves pages close to the shopper so latency stays low. Storefronts on EDS often use document-based authoring so merchants can change pages without a full code deploy.

If you are new to Edge Delivery, see the <Link href="https://www.aem.live/docs/" text="AEM documentation" /> (Build, Publish, Launch) and the <Link href="https://www.aem.live/docs/authoring-guide" text="authoring guide" />. For Document Authoring on da.live, see <Link href="https://docs.da.live/" text="Document Authoring documentation" />.
