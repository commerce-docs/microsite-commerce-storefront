## What to look for in the boilerplate

When exploring the boilerplate repository, the key files are:

| File / folder | What it does |
|---|---|
| `scripts/commerce.js` | Initializes the SDK and registers drop-ins |
| `scripts/delayed.js` | Third-party scripts loaded after LCP |
| `styles/styles.css` | Eager (LCP-critical) global styles |
| `styles/lazy-styles.css` | Deferred styles loaded after LCP |
| `blocks/` | EDS content blocks (header, footer, commerce wrappers) |
| `config.json` | Storefront configuration: Commerce API endpoints, headers, and related settings |
