PageSpeed Insights is the most accurate way to audit your storefront's Web Vitals. It uses the same Lighthouse engine as Chrome DevTools, but runs the audit on a real device in a controlled environment.

For implementation-focused guidance, see [Performance best practices](/get-started/performance/).

## Run a PageSpeed Insights audit

<Steps>

1. Go to [pagespeed.web.dev](https://pagespeed.web.dev/).

1. Enter your `.live` storefront URL. Your preview and live URLs follow these patterns:

   - **Preview**: `https://main--{repo}--{owner}.hlx.page/`
   - **Live**: `https://main--{repo}--{owner}.hlx.live/`

1. Click **Analyze** to run the audit.

1. Review the Web Vitals results for mobile and desktop. Aim for Lighthouse scores at or near 100 across Performance, Accessibility, Best Practices, and SEO.

</Steps>
