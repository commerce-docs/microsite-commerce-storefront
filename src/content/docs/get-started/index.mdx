With Adobe Commerce Storefront, you build a shopping experience for your brand on top of existing features for product discovery, cart, checkout, and accounts. You can adapt these features or create new ones instead of implementing every shopping flow from scratch.

## Your role as a storefront developer

Your work focuses on the storefront's code and shopping features. Content authors create and edit the pages shoppers see.

<Diagram caption="Your storefront starts with the Adobe Commerce boilerplate's existing shopping features. Developers extend or create features, and authors create and edit pages for shoppers.">
  ![Foundation for Commerce Storefront](images/developer-get-started.png)
</Diagram>

## How your storefront reaches shoppers

You work in a GitHub repository created from the <Term term="Commerce boilerplate">Adobe Commerce boilerplate</Term>. Authors manage page content in <Term>DA.live</Term>, and <Term>Edge Delivery Services</Term> publishes and delivers the content and code to shoppers.

<Diagram caption="Your storefront runs in the shopper's browser, using content and code delivered by Edge Delivery Services and live data from Commerce APIs.">
	![Content and code delivered to the storefront, with Commerce API requests and responses and a shopping experience for shoppers](images/storefront-tools.png)
</Diagram>

The included <Term term="Drop-in components">drop-in components</Term> provide ready-made shopping interfaces, such as cart and checkout, that connect to your Commerce services.

## How blocks and drop-ins form storefront pages

<Term>Commerce blocks</Term> add shopping features to pages, while content blocks add text, images, and layout. Commerce blocks can use drop-in components and the Storefront SDK (software development kit), which provides shared user interface (UI) components and tools.

<Diagram caption="Storefront pages combine shopping features from Commerce blocks with content and layout from content blocks. Commerce blocks can use drop-in components and the Storefront SDK.">
  ![SDK components and drop-ins support Commerce blocks, which combine with content blocks to form storefront pages](images/storefront-page-parts.png)
</Diagram>

## Create and preview your first storefront

Your first goal is a working local preview connected to your Commerce catalog. Follow [Create a storefront](/get-started/create-storefront/) to create your project and add starter content, then [run your storefront locally](/boilerplate/#running-locally).

Before you begin, check [Prerequisites](/get-started/before-you-start/) for the accounts and tools you need. Review [Backend options](/get-started/backends/) and [Licensing requirements](/licensing/) to confirm the Commerce services and drop-ins available to your project.
