Adobe Commerce storefronts support the browsers and devices listed below. Support ranges are tied to specific boilerplate suite versions.

## Identify your boilerplate suite

Browser support is tied to specific boilerplate suite versions. To determine which suite you're using, check your `package.json` file for the `@dropins/tools` version:

- **Suite 4 (October 14, 2025)**: `@dropins/tools@~1.5.0`
- **Suite 3 (August 12, 2025)**: `@dropins/tools@1.3.0`
- **Suite 2 (June 25, 2025)**: `@dropins/tools@0.42.0`

## Known issues

For the browsers listed below, the product listing page loads in a single product column and does not support responsiveness:

- Chrome: 100–104
- Firefox: 108 and 109
- Opera: 91 or earlier

## Test your storefront

Test browser compatibility using the Commerce boilerplate reference site: <Link href="https://www.aemshop.net/" text="https://www.aemshop.net/" />

## Browser testing recommendations

When testing your storefront, test against these targets:

- The minimum supported version of each major browser
- The latest version of each major browser
- Both desktop and mobile devices
- Responsive behavior across different screen sizes
- Product listing pages displaying correctly in multiple columns
