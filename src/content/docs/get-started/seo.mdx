## Background

Edge Delivery Services and the Commerce Storefront combine document-driven pages with catalog experiences that often load product data after the initial server response. That split is powerful for performance, but it introduces SEO risks if crawlers, canonical signals, and metadata are not aligned: for example, folder-mapped PDPs can look similar in initial HTML without the right metadata strategy. Even "real" (not folder-mapped) pages can result in SEO issues if canonical metadata is missing or inconsistent.

Commerce-specific rules (SKUs, configurable products, multi-store URLs) add another layer on top of the platform defaults described on <Link href="https://www.aem.live/docs/seo-geo" text="AEM.live" />.
