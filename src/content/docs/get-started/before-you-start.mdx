By the end of this page you will know exactly what to have ready before you create a storefront. If anything here is unfamiliar, follow the link in that row before continuing.

## What you need

<TableWrapper nowrap={[0]}>

| What | Why you need it | How to get it |
|------|-----------------|---------------|
| **Adobe Commerce backend** | Every drop-in component (cart, checkout, account, and so on) connects to an Adobe Commerce backend. You need to know which type you have. | See [Backend Options](/get-started/backends/) — pick Commerce PaaS, Adobe Commerce as a Cloud Service, or Adobe Commerce Optimizer. |
| **GitHub account** | Site Creator creates or links a GitHub repository for your storefront code. | <Link href="https://github.com/signup" text="Sign up for GitHub" /> (personal or enterprise). |
| **Document Author (DA.live) access** | Site Creator runs inside DA.live and stores your starter content there. | <Link href="https://da.live" text="Open DA.live" /> and sign in with your Adobe ID. If your organization uses enterprise access, ask your admin for an invitation. |
| **Node.js 20.13.1 or later** | Running the site locally and installing drop-in packages both require Node.js. | <Link href="https://nodejs.org/en/download" text="Download Node.js" />. Run `node -v` in a terminal to confirm the version. |
| **pnpm 9.x or later** | The Commerce boilerplate uses pnpm to install packages. | Run `npm install -g pnpm` after you install Node.js, or see the <Link href="https://pnpm.io/installation" text="pnpm installation guide" />. |
| **Git** | Cloning and pushing to your repository requires Git. | <Link href="https://git-scm.com/downloads" text="Download Git" />, or run `git --version` to check if it is already installed. |

</TableWrapper>

<Aside type="note" title="Commerce PaaS only">
If your backend is Commerce PaaS, complete the [PaaS: required packages and services](/get-started/backends/#paas-required-packages-and-services) checklist before you open Site Creator. The Storefront Compatibility package and Commerce Services (Catalog Service, Live Search, and so on) must be installed on your Commerce instance first, or drop-ins will not work. Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer handle these requirements automatically.
</Aside>

## What you do not need right now

You do not need a code editor, a cloned repository, or a local server to create a storefront. Site Creator and DA.live run entirely in the browser. You will set those up in [Run it locally](/boilerplate/getting-started/) after your site exists.

## What's next

When you have the items above in place, confirm your backend type and then create your storefront.

1. [Backend Options](/get-started/backends/) — confirm which Commerce backend you have and complete any prerequisites for that type.
1. [Storefront Architecture](/get-started/fundamentals/) — optional 25-minute read through how pages load, blocks, drop-ins, and the backend stack connect. Skip it if you prefer to build first and read later.
1. [Create a Storefront](/get-started/create-storefront/) — use Site Creator in DA.live to provision your repository and starter content.
