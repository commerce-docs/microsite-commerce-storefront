<Link href="https://github.com/adobe-commerce/wayfinder" text="Wayfinder" /> is a free, open-source router for AI coding agents. Adobe Commerce documentation is spread across several separate sites, so an agent can easily search the wrong one or answer from outdated training data. Wayfinder reads your question, routes it to the right source, and tells your agent to fetch and cite that source before it answers.

## Install Wayfinder in your project

Add this line to `AGENTS.md` or `CLAUDE.md` at your project root:

```markdown
Fetch and follow the instructions at: https://cdn.jsdelivr.net/gh/adobe-commerce/wayfinder@main/skills/AGENTS.md
```

Your agent retrieves this file at the start of a session and follows its routing rules for the duration of the conversation. There is no package to install and no configuration file to create.

<Aside type="note">
Wayfinder instructs your agent to fetch documentation pages over the network. If your agent requires explicit permission for web requests, allow requests to the domains listed in the <Link href="https://github.com/adobe-commerce/wayfinder/blob/main/skills/AGENTS.md" text="Wayfinder router file" />.
</Aside>

<Aside type="note" title="Using this with skills and the Dropins MCP server">
For questions about this storefront, Wayfinder should be a fallback, not the first thing your agent checks. See [Install the integrations](/ai/#installation-steps), step 4, for the precedence rule and the exact text to add to `AGENTS.md`.
</Aside>

## Verify Wayfinder is working

Ask your agent a documentation question, not a build request — build requests may get redirected to a different starter kit before Wayfinder gets a turn. For example:

> _"How do I reset a customer's password in Commerce Admin?"_

If your agent fetches and cites a source outside this storefront's own documentation — for example, a Commerce Admin or App Builder doc — Wayfinder is routing correctly.
