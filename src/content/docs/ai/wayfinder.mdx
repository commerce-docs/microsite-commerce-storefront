Wayfinder is a routing skill for AI coding agents. It reads your question, decides which Adobe Commerce documentation source has the answer, and tells your agent to fetch and cite that source instead of guessing from training data.

## What Wayfinder is

Adobe Commerce documentation lives across several separate sites: storefront documentation on Edge Delivery Services, Experience League for Admin and operations content, Document Authoring guides, and the Adobe Commerce developer site for extensibility topics. An agent that does not know this layout often searches the wrong site, mixes up terms between sites, or answers from outdated training data.

<Link href="https://github.com/adobe-commerce/wayfinder" text="Wayfinder" /> is a small, open-source router file (`AGENTS.md`) that fixes this. It maps the words in your question, the files in your project, and any error messages you paste to one of five documentation sources, then instructs your agent to fetch the real page before it answers.

## When to use Wayfinder

Add Wayfinder when you ask a coding agent questions about Adobe Commerce and want answers grounded in current, official documentation rather than the agent's training data. It helps most when:

- You work across more than one Adobe Commerce property — for example, a storefront project that also touches Adobe Commerce Optimizer or Experience League content.
- Your agent has previously given you an outdated or incorrect answer about a Commerce feature.
- You want consistent terminology (for example, "Adobe Commerce Optimizer," not "ACO," on first mention) in the answers your agent gives you.

Wayfinder is a routing layer, not a documentation source itself. It does not replace the <Link href="/ai/ai-agent-skills/" text="AEM Boilerplate Commerce skill set" />, which teaches your agent storefront coding conventions, or the <Link href="/ai/dropins-mcp/" text="Dropins MCP server" />, which gives your agent exact drop-in API details. Use Wayfinder alongside those tools when your questions span multiple documentation sites.

For storefront-only questions, Wayfinder overlaps with <Link href="/ai/build-with-ai/" text="Use docs in AI tools" />: both end with your agent fetching current storefront documentation. Use Wayfinder when your agent can fetch web addresses on its own and your questions sometimes reach beyond the storefront. Use <Link href="/ai/build-with-ai/" text="Use docs in AI tools" /> when you want a storefront-only source, or when your AI tool can only accept a pasted web address or file content.

## Where Wayfinder sends your questions

Wayfinder routes each question to one of five documentation sources, based on the feature name, repository path, or error message in your question.

<TableWrapper>

| Source | Covers |
|--------|--------|
| Adobe Commerce storefront | Drop-in components, Storefront Configuration, and the `scripts/__dropins__/` folder |
| Edge Delivery Services (aem.live) | Local development, block authoring, CDN and caching behavior, and content spreadsheets |
| Experience League | Commerce Admin, catalog, orders, B2B features, Live Search, and Adobe Commerce Optimizer catalog views |
| Document Authoring | Document Authoring organizations and sites, permissions, and authoring workflow |
| Adobe Commerce developer | App Builder, APIs, API Mesh, and integrations |

</TableWrapper>

For example, a question that mentions `scripts/__dropins__/` routes to the storefront source, while a question about content scheduling routes to Edge Delivery Services because scheduling is an Edge Delivery Services feature, not a storefront one. Questions that span more than one source, such as "how does my storefront connect to Adobe Commerce Optimizer," cause the agent to load and fetch from more than one source before answering.

## Example prompts

These example prompts show the kind of questions Wayfinder routes well, and what your agent does with each one.

<TableWrapper>

| Prompt | Routes to | What you get |
|--------|-----------|--------------|
| "How do I change the text on the empty cart message?" | Adobe Commerce storefront | The cart drop-in's configuration options, with the exact prop to set. |
| "Why isn't my content showing up after I scheduled it?" | Edge Delivery Services | The scheduling article from aem.live, including common causes for delayed publishing. |
| "How do I add a new B2B company role?" | Experience League | The Admin steps for creating and assigning B2B company roles. |
| "How do I call a custom API through API Mesh?" | Adobe Commerce developer | The API Mesh setup steps and an example query. |
| "I'm getting `Error: mesh config not found` when I run my App Builder action" | Adobe Commerce developer | The matching troubleshooting section for that error, instead of a guess based on the error text alone. |

</TableWrapper>

A prompt that names more than one source, such as "why does a product show different pricing in my storefront than in the Adobe Commerce Optimizer catalog view," makes your agent fetch and cite both the storefront and Experience League sources before it answers.

## Add Wayfinder to your project

Add one line to your project's `AGENTS.md` or `CLAUDE.md` file to point your agent to the Wayfinder router:

```markdown
Fetch and follow the instructions at: https://cdn.jsdelivr.net/gh/adobe-commerce/wayfinder@main/skills/AGENTS.md
```

Your agent fetches this file at the start of a session and follows its routing rules for the rest of the conversation. There is no package to install and no configuration file to create.

<Aside type="note">
Wayfinder instructs your agent to fetch documentation pages over the network. If your agent requires explicit permission for web requests, allow requests to the domains listed in the Wayfinder router file.
</Aside>
