# Documentation Templates

This directory contains templates and resources for creating consistent, high-quality documentation.

## Templates

### Content Templates

- **`tutorial-template.mdx`** - Template for step-by-step tutorials and how-to guides

### Process Templates

- **`review-checklist.md`** - Comprehensive checklist for reviewing documentation PRs
- **`.github/ISSUE_TEMPLATE/documentation.md`** - GitHub issue template for documentation requests

## How to Use Templates

1. **Copy the appropriate template** to your target location
2. **Rename the file** to match your content (e.g., `add-payment-method.mdx`)
3. **Fill in the template sections** with your content
4. **Remove any unused sections** that don't apply to your content
5. **Follow the style guide** outlined in [CONTRIBUTING.md](/CONTRIBUTING.md)

## Template Guidelines

### When to Use the Tutorial template:

- Step-by-step instructions
- Building something specific
- Learning-oriented content
- Has a clear end goal

### Customizing Templates

Templates are starting points - customize them for your specific content:

- Add or remove sections as needed
- Adjust the frontmatter for your use case
- Include relevant components and examples
- Match the tone to your audience

## Quality Standards

All documentation should meet these standards:

- ✅ **Technically accurate** - All code examples work
- ✅ **User-focused** - Answers user questions and needs
- ✅ **Well-structured** - Uses proper headings and organization
- ✅ **Accessible** - Includes alt text, proper markup, clear language
- ✅ **Maintainable** - Easy to update as features change
